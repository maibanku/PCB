# 12-06 去耦优化

> 所属 [[12-SI-PI分析]]。基于目标阻抗和频段需求，自动选择并优化去耦电容的容值/ESR/ESL 与摆放位置，让 PDN 全频段满足目标阻抗。

## 目标（要实现什么）
- 输入目标阻抗曲线（来自 [[05-PI电源平面]]）和频率范围（典型 1kHz-1GHz），输出电容组合方案
- 电容模型：C + ESR + ESL（含安装电感，~1-2nH 视焊盘/过孔），频响曲线呈 V 形
- 多电容并联优化：自动搜索 C/ESR/ESL 组合，让合成阻抗 < Ztarget 全频段
- 电容摆放位置优化：靠近 IC 电源引脚，最小化回路电感（嵌入式电容 / BC 电介质评估）
- 数量最小化：在满足阻抗约束下，去耦电容总数最少（BOM 成本优化）
- 推荐电容值分布（如 100nF + 10nF + 1nF + 10μF），覆盖低/中/高频段
- 与 BOM（[[13-制造输出/07-BOM输出]]）+ 供应链（E2）联动：仅推荐库存可购的电容

## 关键点
- ESL（等效串联电感）是高频段去耦效果的瓶颈，决定自谐振频率 fSR = 1/(2π√(LC))
- 安装电感（mounting inductance）由焊盘 → 过孔 → 平面回流路径决定，比电容本身 ESL 大一个量级
- 多电容"反谐振峰"（anti-resonance peak）：两个电容不同自谐振频率之间会出现阻抗尖峰，需谨慎搭配
- 嵌入式电容（embedded capacitance，如 Buried Capacitance 材料）可显著降低高频阻抗，高端设计可选
- 推荐算法：遗传算法 / 局部搜索，约束为器件库 + 库存 + 板面积

## 输入 / 输出
- **入**：目标阻抗曲线（[[05-PI电源平面]]）、IC 电源引脚位置、电容器件库（含 ESR/ESL）、库存/价格
- **出**：去耦电容清单（容值/数量/封装/料号）、摆放位置（PCB 标注）、合成阻抗曲线

## 依赖
- **上游**：[[05-PI电源平面]]、C3-PCB 编辑器、C1 元件库、E2 供应链（库存/价格）
- **下游**：BOM 输出、PI 综合报告
