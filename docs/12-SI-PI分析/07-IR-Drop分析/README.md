# 12-07 IR-Drop分析

> 所属 [[12-SI-PI分析]]。计算电源平面/走线在 DC 负载下的电压降与电流密度分布，确保 IC 电源引脚处电压不低于最小工作电压，并避免局部过热。

## 目标（要实现什么）
- DC 稳态分析：基于电源平面/走线几何 + 铜厚 + 各 IC 工作电流，求解电压分布（有限元/有限差分）
- 输出电压分布 heatmap（彩色图，红=低压区）、电流密度 heatmap（A/mm²）
- 在 IC 电源引脚处检查：V_drop < 允许跌落（如 5% Vcc，3.3V → 3.13V 是底线）
- 电流密度合规：检查是否超过铜的安全载流（IPC-2152 / IPC-2221 标准，~20-30 A/mm² 温升 10°C）
- 识别瓶颈：窄段、过孔数量不足、单点连接、neck-down 区域
- 推荐改进：加宽铜皮、增加过孔数量、加铜厚（1oz → 2oz）、加散热铜皮/散热孔
- 静态 + 动态：支持瞬态负载（如 DDR burst）下的最坏 IR Drop 估算

## 关键点
- DC 仿真用 FEM 或 FDM 求解拉普拉斯方程（∇·σ∇V = 0），边界条件为电压源与电流阱
- 过孔电流能力：单个 0.3mm 过孔 ~1-2A（10°C 温升），大电流需多过孔并联（电源���块处尤其）
- 铜厚影响：1oz（35μm）vs 2oz（70μm）载流能力约翻倍，但成本上升
- 温升与电流密度（IPC-2152）：考虑铜厚、相邻热源、风冷/自然冷却条件
- 与 [[05-PI电源平面]] 互补：IR Drop 看 DC（mV 级），PI 看 AC（mΩ 阻抗），两者共同决定 PDN 质量

## 输入 / 输出
- **入**：平面/走线几何（C3 PCB）、铜厚、各 IC 工作电流（datasheet）、电压源点（VRM 引脚）
- **出**：电压 heatmap、电流密度 heatmap、IC 引脚处最小电压表、瓶颈标注、改进建议

## 依赖
- **上游**：[[05-PI电源平面]]、C3-PCB 编辑器、器件库（电流参数）
- **下游**：PI 综合报告、AI 审查（E1）
