# 12-08 叠层规则联动

> 所属 [[12-SI-PI分析]]。作为 SI/PI 分析的"单一真相源"，统一管理叠层定义（材质、铜厚、介质厚、Dk/Df），并自动派生阻抗规则、线宽规则、过孔规则等约束。

## 目标（要实现什么）
- 提供可视化叠层编辑器：显示铜层/介质层/阻焊层堆叠，可调厚度、铜厚（1/2/1oz/2oz）、材质
- 材质库：常见 PCB 基材（FR-4、高 Tg FR-4、Rogers、Megtron 6、Isola）的 Dk/Df vs 频率参数表
- 叠层预设（layer stackup presets）：4 层、6 层、8 层常见叠层（如 6 层 4 信 2 电、地平面密贴等）
- 阻抗规则派生：选目标阻抗（如 50Ω 单端、100Ω 差分）→ 自动反推各层线宽/线距 → 写入约束管理器
- 过孔规则联动：根据叠层自动生成通孔/盲/埋孔规则（最小孔径、aspect ratio、盲孔层范围）
- 工厂能力（fabricator capability）绑定：检查叠层是否满足当前合作工厂的最小介质厚、铜厚、HDI 等级
- 叠层变更触发 SI/PI 重算：与 [[01-SI阻抗分析]]、[[05-PI电源平面]] 等联动通知

## 关键点
- 叠层是 SI/PI 分析的输入参数基础（厚度/材质/Dk），一处变更全链路影响
- 阻抗规则与线宽规则应单向派生：叠层 → 阻抗 → 线宽，避免双向循环
- 材质 Dk 随频率变化（FR-4 在 1GHz 约 4.3，10GHz 降至 4.0），高速设计需选频段
- 玻纤效应（glass weave skew）：高速差分对（>10Gbps）需关注玻纤规格（1080/2116/7628）与走线方向
- 工厂能力档案：每个工厂维护一份 yaml 配置（最小线距、最小孔径、铜厚选项、HDI 工艺等级），叠层编辑器加载并校验
- 与 [[13-制造输出/12-制造前检查]] 共享工厂能力档案

## 输入 / 输出
- **入**：材质库、工厂能力档案（来自制造资源）、设计目标（阻抗/电流）
- **出**：叠层定义（XML/JSON）、阻抗规则（写约束管理器）、过孔规则、制造能力合规报告

## 依赖
