# 12-02 串扰分析

> 所属 [[12-SI-PI分析]]。基于平行走线的耦合几何与 IBIS 驱动模型，估算近端/远端串扰（NEXT/FEXT）幅度，找出超阈值的风险线对。

## 目标（要实现什么）
- 检测板上的平行/近似平行走线对（同层或邻层），按耦合长度排序
- 计算容性耦合（Cm）+ 感性耦合（Lm）→ NEXT/FEXT 系数（V/V 或 dB）
- 支持 IBIS 驱动模型激励下的瞬态串扰仿真，输出受害线接收端噪声波形
- 按网络类（如时钟、敏感模拟）设置串扰阈值（典型 5% Vcc 或 50mVpp），超标预警
- 给出优化建议：增大间距、缩短平行段、加屏蔽地线/地过孔、换层、缩短耦合长度
- 与 3D 视图联动：高亮攻击-受害对，可视化串扰热点

## 关键点
- 容性耦合主导远端（上升沿耦合到两端），感性耦合在两端方向相反 → FEXT 可抵消或叠加（与传输方向、回流参考层有关）
- 关键参数：耦合长度 L 与上升时间 tr 的比值（L < tr·v/6 时近似集总耦合）
- 邻层串扰（broadside coupling）易被忽视：相邻信号层垂直布线可显著降低
- 参考层不连续（如跨分割电源平面）会让回流绕远，串扰剧增，需与 [[05-PI电源平面]] 联动告警
- 屏蔽地线（guard trace + 地过孔）可降低 6-15dB，是性价比最高的修法

## 输入 / 输出
- **入**：走线几何（来自 C3）、IBIS 模型（器件库）、串扰阈值（约束）
- **出**：耦合对清单、NEXT/FEXT 报告（CSV/HTML）、超标对 PCB 定位、优化建议
