# 12-04 过孔stub分析

> 所属 [[12-SI-PI分析]]。识别高速信号路径上的过孔 stub（残端），分析其谐振频率与对信号完整性的影响，推荐背钻或改用盲埋孔。

## 目标（要实现什么）
- 自动识别 PCB 上所有信号过孔的 stub 长度（即过孔从信号层穿过到末端层外的无用铜柱段）
- 计算每条 stub 的四分之一波长谐振频率（f = c/(4·L·√Dk)），定位在信号工作频率附近的过孔
- 计算过孔的寄生电容/电感与通孔阻抗（典型 25-35Ω，远低于 50Ω），评估阻抗失配
- 输出 S 参数（S11 回波损耗 / S21 插入损耗）vs 频率曲线，标识 -3dB / -10dB 带宽
- 推荐方案：背钻（backdrill）、改用盲孔/埋孔、调整层叠让信号走靠近 stub 末端、加地过孔屏蔽
- 与 C3 PCB 编辑器联动：列表 → PCB 高亮 → 一键跳转修改

## 关键点
- stub 谐振是高速背板/服务器主板的头号 SI 杀手：6Gbps 以上信号即使 10mil stub 也可致命
- 背钻工艺成本：每层 1-2 个背钻孔，需在设计阶段权衡
- via stub 与 via impedance 是两个问题：stub 是频选陷波（吸收特定频率），via impedance 是宽带反射
- 盲/埋孔（HDI）可彻底消除 stub，但成本上升一档
- 工程实践：DDR byte lane 过孔数量多，stub 累积效应需联合 [[03-反射与眼图]] 评估

## 输入 / 输出
- **入**：过孔几何（孔径、焊盘、反焊盘、起始层/结束层）、叠层（Dk）、信号频率
- **出**：stub 长度表、谐振频率、S 参数曲线、PCB 高亮定位、修改建议

## 依赖
- **上游**：C3-PCB 编辑器、[[08-叠层规则联动]]
- **下游**：[[03-反射与眼图]]（网络级仿真输入）、制造工艺（[[13-制造输出]]，背钻标注）
