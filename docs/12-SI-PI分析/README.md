# 12-SI-PI分析

> 对应 **Plan P12**（Phase 3 · 专业补强）。面向中小板高速场景的"够用级"信号完整性（SI）与电源完整性（PI）分析。

## 定位
- **做什么**：SI 侧覆盖阻抗、串扰、反射、过孔 stub、眼图；PI 侧覆盖电源平面完整性、去耦电容优化、IR Drop 压降与目标阻抗；与叠层管理器、约束规则联动，给出报告与优化建议。
- **不做什么**：不追求 Cadence/Altium 高端的全波三维电磁场仿真；不替代专业 SI/PI 工具，而是面向 USB/DDR/高速串行等中小板高速场景做"够用级"前置分析。
- **代码位置**：`eda/si_pi`（见 [[00-总览/03-项目目录结构]]）
