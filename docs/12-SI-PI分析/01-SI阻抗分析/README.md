# 12-01 SI阻抗分析

> 所属 [[12-SI-PI分析]]。基于叠层介质参数与走线几何，计算传输线特征阻抗，验证单端/差分网络是否满足目标阻抗（50/90/100Ω 等）。

## 目标（要实现什么）
- 支持微带线（microstrip）、带状线（stripline）、共面波导（GCPW）等传输线模型的特征阻抗计算
- 提供单端阻抗 Z0 与差分阻抗 Zdiff（含奇/偶模），覆盖 USB2/3、HDMI、PCIe、DDR3/4/5、LVDS、Ethernet 等常见场景
- 输入叠层（铜厚、介质厚度、Dk/Df、阻焊覆盖）+ 线宽/线距，输出阻抗值与误差（±5% / ±10%）
- 与约束管理器联动：自动按目标阻抗反推线宽/线距推荐值，写入线宽规则
- 支持 2D 场求解器（边界元法）作为高精度后备，处理非均匀叠层、邻层耦合、参考层不连续
- 生成每层、每网络类的阻抗表（HTML/CSV 报告），可定位到 PCB 上的相关走线段

## 关键点
- 半解析公式（Polar/GIPC-2152 标准）够用 90% 中低速场景；场求解用于背板、高速串行残留风险点
- 阻抗是几何（线宽/介质厚）+ 介质（Dk）+ 频率（有效 Dk 因趋肤/损耗）的函数，叠层与频率参数化
- 阻焊层（solder mask，Dk≈3.3、厚度 10-20μm）对微带阻抗有 ~3-5Ω 影响，不可忽略
- 蚀刻补偿（etching compensation，梯形截面）：底宽 > 顶宽，影响 ~2-3Ω，由铜厚决定
- 差分耦合随线距增加而减弱（Zdiff → 2·Z0），需用奇模阻抗而非简单 2×

## 输入 / 输出
- **入**：叠层定义（来自 [[08-叠层规则联动]]）、走线几何（来自 C3 PCB 编辑器）、目标阻抗（约束管理器）
- **出**：每层阻抗表、线宽/线距推荐值、超标走线列表、HTML 报告
