# 13-08 装配图与制造图PDF

> 所属 [[13-制造输出]]。生成矢量 PDF 工程图：装配图（贴片位置/位号/极性）、制造图（叠层/钻孔表/尺寸）、钻孔图，供工厂人工核对与归档。

## 目标（要实现什么）
- 多页矢量 PDF 输出（支持 PDF/A 归档、可搜索文字、图层化显示）
- **装配图（Assembly Drawing）**：器件外形 + 位号 + 极性（1 脚/正极）+ 高度区域，按顶层/底层分页
- **制造图（Fabrication Drawing）**：板框尺寸、定位孔、开槽、叠层表（layer stack table）、钻孔表（drill table，孔径/数量/类型）
- **钻孔图（Drill Drawing）**：每种孔径用不同符号标识，含孔位分布 + 统计表
- 标题栏（Title Block）：项目名、版本、日期、设计者、页码、单位、比例尺
- 设计备注（Notes）：特殊工艺说明、IPC 等级、阻抗要求、表面工艺（HASL/ENIG/OSP）
- 输出比例准确：1:1 时支持工厂打印后实物比对；可在 PDF 中嵌入测量标尺
- 支持图层（OCG/PDF Layer）：可选显/隐铜层、丝印、标注、尺寸
- 模板化：标题栏、字体、线宽、注释可配置并保存为模板

## 关键点
- 矢量 PDF（不是位图）便于缩放与归档，工厂可矢量 CAM 提取
- Drill Table 是制造图的灵魂：列出每种刀具/孔径的孔数、plated/non-plated、用途
- 极性标识：二极管/电解电容/IC 1 脚必须明确，否则装配易反
- Title Block 工业标准（ANSI/ASME Y14.35 / Y14.34）：版本管理、修订表（revision block）
- 阻抗要求必须在制造图注明：层叠表 + 阻抗值 + 公差，工厂据此控制
- 表面工艺（finish）：HASL（喷锡）、ENIG（化金）、OSP（有机保焊膜）等需注明
- 与 [[01-Gerber输出]] 数据一致：图纸信息应与 Gerber/Excellon 完全对应

## 输入 / 输出
- **入**：PCB 设计数据、叠层（[[12-SI-PI分析/08-叠层规则联动]]）、钻孔、装配变体
- **出**：多页 PDF 工程图（装配/制造/钻孔）、归档版本

## 依赖
- **上游**：C3-PCB 编辑器、叠层信息、钻孔数据
- **下游**：工厂人工核对、设计归档
