# 13-02 Excellon钻孔

> 所属 [[13-制造输出]]��输出 Excellon 格式钻孔文件（公制/英制），含刀具列表（T1/T2/...）、孔径映射、plated/non-plated 区分，并支持槽孔与盲埋孔分文件。

## 目标（要实现什么）
- 输出 **Excellon 1.0 / 2.0** 格式（M48 头 + 钻孔坐标），工厂通用接收
- 自动生成刀具列表：按孔径分组，每径一把刀（T1=0.2mm、T2=0.25mm...），列明 feed/speed（可选）
- 区分 plated（PTH，沉铜，过孔）与 non-plated（NPTH，定位孔/螺丝孔）→ 不同文件或不同刀
- 支持槽孔（slot hole）：G85 命令 + 槽长/槽宽，或离散点阵列
- 通孔（through-hole）/ 盲孔（blind，从外层到内层）/ 埋孔（buried，内层之间）分别导出
- 单位（mm / inch）+ 坐标精度（3:3 / 3:4）+ 零省略模式（LZ/TZ）可配置
- 配套输出钻孔图（drill drawing）：PDF 标识各孔径分布与刀具表
- 与工厂能力档案（[[13-制造输出/12-制造前检查]]）联动：检查最小孔径、aspect ratio、最小环宽

## 关键点
- Excellon 是事实标准，由 IPC-NC-349 演化；M48 头是增强版（含刀径/进给参数）
- 工厂按刀具上机，合并相近孔径（如 0.29 / 0.30）可减刀数 → 降低成本
- aspect ratio（板厚/孔径）需满足工厂能力（典型 8:1 通孔，1:1 盲孔）
- NPTH 与 PTH 必须分离：NPTH 在沉铜工艺后才钻，否则孔壁会沉铜变成 PTH
- 槽孔：G85 槽（推荐）或线性阵列点钻（旧工艺），需匹配工厂设备
- 盲/埋孔需独立文件 + Z 起止层标注（如 L1-L2、L3-L4）

## 输入 / 输出
- **入**：PCB 孔数据（C3 编辑器，所有 via/pad 孔）、工厂能力档案
- **出**：Excellon 钻孔文件（按孔类型分文件）、刀具表、钻孔图 PDF

## 依赖
- **上游**：C3-PCB 编辑器（孔数据）、工厂能力档案
- **下游**：PCB 工厂、[[13-制造输出/12-制造前检查]]（孔规则验证）
