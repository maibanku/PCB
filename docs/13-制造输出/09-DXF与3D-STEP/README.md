# 13-09 DXF与3D-STEP

> 所属 [[13-制造输出]]。输出机械图 DXF（板框/定位孔/禁布区）与 3D STEP 模型（单板/整机装配），供结构工程师与机械 CAD 协同。

## 目标（要实现什么）
- 输出 DXF（DWG 兼容 R14 / 2010 / 2018）2D 机械图：板框、定位孔、开槽、禁布区、丝印外框
- DXF 单位（mm/inch）、原点（左下/中心）、图层（layer）命名规范化，匹配 SolidWorks / AutoCAD 习惯
- 输出 3D STEP（AP203 / AP214 / AP242）模型：每个器件的 3D 体（来自 C5/库），原点对齐 PCB 坐标
- 整机装配（assembled board）：所有器件就位后的整板 3D 模型；或单板（bare board）仅板+铜
- 可选导出范围：全部器件 / 仅指定器件（如连接器、高度敏感器件）
- STEP 模型精度配置（缝合容差、曲面细分密度），平衡文件大小与精度
- 配套输出 IGES / OBJ / VRML（wrl）作为兼容后备
- 包含属性：器件位号、MPN（作为 STEP 属性或图层名），便于机械 CAD 中识别

## 关键点
- DXF 是机械 CAD 通用格式（AutoCAD 源），EDA ↔ MCAD 必经之路
- 板框 DXF 用于外壳工程师设计配合：定位孔、最大高度区、连接器位置
- STEP AP242（2014+）是最新标准，支持 PMI（产品制造信息），保留装配结构
- 器件 3D 模型来源：器件库（C1 元件库）维护 STEP，原点对齐封装中心 + 高度方向
- 文件体积：含数千器件的整板 STEP 可达 100MB+，需考虑轻量化（简化几何 / 移除非关键特征）
- 模型校准：原点、旋转、缩放（mm vs inch）必须严格一致，否则机械配合错位
- 与 [[10-3D与机械协同]] 双向：可导出供 MCAD，也可从 MCAD 导入外壳 STEP 检查干涉

## 输入 / 输出
- **入**：PCB 板框 + 器件 3D 模型（C1/C5）、机械配置（精度、范围）
- **出**：DXF 板框图、STEP 整机/单板模型、IGES/OBJ 后备

## 依赖
- **上游**：C3-PCB 编辑器、C5 3D 与机械协同、C1 元件库（3D 模型）
- **下游**：机械 CAD 工程师、装配干涉检查（C5）
