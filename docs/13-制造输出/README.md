# 13-制造输出

> 对应 **Plan P13**（Phase 2 · MVP 闭环）。端到端可生产主线的终点——一键产出"开箱即造"的完整生产数据包。

## 定位
- **做什么**：输出 Gerber/钻孔/坐标/钢网等传统制造文件，输出 IPC-2581/ODB++ 一体化智能制造数据包；产出 BOM、装配图/制造图 PDF、DXF 机械图、3D STEP；支持拼板面板化（V-cut/邮票孔/工艺边/阴阳板）；提供输出模板批处理与制造前检查，直连供应链下单。
- **不做什么**：不替代供应链系统本身（下单/订单跟踪属 P21 供应链集成）；不做工厂端 MES/ERP 对接。
- **代码位置**：`eda/manufacturing`（见 [[00-总览/03-项目目录结构]]）
