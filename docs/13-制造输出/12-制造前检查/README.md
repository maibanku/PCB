# 13-12 制造前检查

> 所属 [[13-制造输出]]。在生成 Gerber/IPC-2581 等输出前的前置 DFM 校验，按工厂能力档案比对设计，避免到了工厂才被打回。

## 目标（要实现什么）
- 按工厂能力档案（fabricator capability profile）校验：最小线宽、最小间距、最小环宽、最小孔径、最大板厚、HDI 等级
- DFM 检查项：
  - 阻焊桥（solder mask sliver）最小宽度（典型 3-4mil）
  - 丝印上焊盘（silk on pad）检测
  - 孤立焊盘（isolated pad）检测
  - 最小线宽/间距（按网络类，电源类加严）
  - 最小环宽（annular ring）+ 焊盘与孔径比
- DFA 检查项：
  - 器件间距（最小 0.5mm，波峰焊需更大）
  - 极性器件方向一致性（如钽电容朝向）
  - 器件高度区域（vs 外壳限高区）
  - 波峰焊/回流适配（如 SOIC 朝向）
- DFT 检查项：
  - 测试点覆盖率（每网络是否有测试点）
  - 测试点可达性（无器件遮挡，探针可触）
  - ICT/FCT 夹具适配（探针间距、测试点直径）
- 输出前 Round-trip：自己导出 Gerber → 反向解析 → 与原设计比对（防止静默丢失）
- DFX 报告 + 改进建议（与 D2 DFX 体系联动）
- 工厂能力档案库：每家工厂一份 yaml（嘉立创、华秋、JLCPCB、Multek 等），切换工厂即重跑检查

## 关键点
- 工厂能力档案是 DFM 前置的核心数据：每家工艺不同（HDI 等级、最小线宽、阻焊工艺）
- DFM 前置 ≠ DRC：DRC 看电气连通性，DFM 看可制造性，两者互补
- Round-trip 自校验是防止输出 bug 的最后防线（Gerber 写错或丢图元）
- 测试点覆盖率（DFT）是国产 EDA 相对 KiCad 的补强（详见 D2 DFX 体系）
- 阻焊桥（solder mask sliver）：两焊盘间阻焊间隔，太小工厂无法制作（阻焊油墨会桥连）
- 与 [[12-SI-PI分析/08-叠层规则联动]]（工厂能力档案）+ D1 DRC + D2 DFX 体系联动
- 报告形式：HTML 分级（错误/警告/信息）+ PCB 高亮定位 + 一键跳转修改

## 输入 / 输出
- **入**：PCB 设计数据、工厂能力档案、DFM/DFA/DFT 规则集
- **出**：DFX 报告（HTML）、问题清单 + PCB 定位、改进建议、Pass/Fail 结论

## 依赖
- **上游**：C3-PCB 编辑器、工厂能力档案（[[12-SI-PI分析/08-叠层规则联动]]）
- **下游**：[[11-输出模板批处理]]（批处理前置）、D2 DFX 体系（共享规则）
