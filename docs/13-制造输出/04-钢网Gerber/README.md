# 13-04 钢网Gerber

> 所属 [[13-制造输出]]。输出 SMT 锡膏印刷用钢网层 Gerber（Top/Bottom），支持按比例缩减、按器件微调，并区分激光切割与电铸钢网工艺。

## 目标（要实现什么）
- 输出钢网层 Gerber：Top Paste、Bottom Paste（仅 SMD 焊盘，含开窗区域）
- 默认开窗 = 焊盘 × 缩减比例（典型 1:1，或缩减 10%、缩减按 IPC-7525 推荐）
- 按器件/封装微调开窗：方形 0603 用 0.5mm × 0.8mm 矩形；功率器件用网格开窗（避免锡珠）；BGA 用圆形按比例
- 工艺类型预设：激光切割钢网（精度高，开窗 = 设计）、电铸钢网（Foil 厚度均匀）、蚀刻钢网（成本低，开窗需补偿）
- 钢网厚度（foil thickness）配置：0.10 / 0.12 / 0.13 / 0.15 / 0.20mm，对应锡膏体积
- Step-down / step-up 钢网：局部减薄或加厚（fine-p pitch BGA 区域减薄）
- 输出锡膏量报告：每焊盘锡膏体积估算，识别过量/不足（IPC-7525 体积公式）
- 与 [[13-制造输出/12-制造前检查]] 联动：检查开窗是否重叠、最小开窗间距

## 关键点
- 锡膏印刷量 = 开窗面积 × 钢网厚度，对焊接良率影响极大（多 → 锡珠，少 → 空焊）
- IPC-7525 是钢网设计标准，给出面积/体积推荐与计算公式
- fine-pitch（< 0.5mm pitch）建议缩减 20-30%，避免桥连
- BGA 开窗：通常圆形 + 缩减（如 0.3mm ball 用 0.28mm 圆孔），过度缩减会缺锡
- 网格开窗（mesh aperture）：大焊盘（如 USB 连接器外壳焊盘）防止锡珠
- Step-down 区域需在钢网 Gerber 之外另行 PDF 工程图说明

## 输入 / 输出
- **入**：焊盘设计（C3 PCB）、缩减规则（按器件/封装）、工艺类型、钢网厚度
- **出**：Top/Bottom 钢网 Gerber、开窗量报告、step-down 标注图（PDF）

## 依赖
- **上游**：C3-PCB 编辑器（焊盘数据）、钢网设计规则（IPC-7525 预设）
- **下游**：钢网制造厂、[[13-制造输出/12-制造前检查]]
