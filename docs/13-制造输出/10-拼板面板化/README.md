# 13-10 拼板面板化

> 所属 [[13-制造输出]]。拼板（Panelization）设计：V-cut、邮票孔、工艺边、阴阳板、自动排列与桥连，生成拼板级 Gerber/钻孔/PnP，供 SMT 与 PCB 厂批量生产。

## 目标（要实现什么）
- 自动 step-repeat：单板 × N × M 排列，自动生成拼板坐标（行/列间距、旋转、镜像）
- **V-cut（V 形刻线）**：板间 V 形槽（剩余厚度 = 板厚的 1/3），可直线分板；规则（最小板边距、V-cut 与板边距离）
- **邮票孔（stamp holes / mouse bites）**：板间用 5-8 个非沉铜小孔（如 0.5mm）阵列，可掰开；适合异形板/不能 V-cut 处
- **桥连（bridge / tab）**：板间留 3-5mm 铜桥连接，掰开后留茬
- **工艺边（tooling / process edge）**：拼板四周加 5-10mm 工艺边，含 tooling hole（Φ3.0）+ fiducial（Φ1.0 圆 + 黑化铜）
- **阴阳板（A/B board / front-to-back）**：正反两面布局不同单板，节省拼板空间
- 异形单板自动互补排列（如圆形板交错布局，提高板材利用率）
- 拼板级数据导出：Gerber（拼板图）、Excellon（拼板孔）、PnP（拼板坐标，器件位置 = 板内 + 板偏移）
- 拼板工艺校验：最小板边距、V-cut 残厚、邮票孔强度、工艺边尺寸

## 关键点
- V-cut 仅能直线、贯穿整板（不能 L 形）；邮票孔灵活但掰开力大
- 邮票孔 5 孔 × Φ0.5mm 是经验值，太少掰不动、太多掰不开
- 工艺边是 SMT 厂贴片机传送带必需（典型 5mm），拼板后必须含
- Fiducial（基准点）：全局 2-3 个 + 局部（精细器件如 BGA 旁 2 个），贴片机视觉对位用
- Tooling hole（定位孔）：Φ3.0/Φ3.5/Φ4.0，工厂夹具定位用，位置在工艺边四角
- 板材利用率（board utilization）= 单板面积 × N / 拼板面积，典型目标 > 75%
- 阴阳板可节省成本但调试复杂，需双面分别装配，常用于小批量多 SKU
- 与 [[03-PickAndPlace坐标]] 联动：拼板 PnP 必须含板偏移（板内 + 拼板坐标）

## 输入 / 输出
- **入**：单板设计（C3 PCB）、拼板配置（N×M、间距、工艺类型）
- **出**：拼板 Gerber/Excellon/PnP、拼板工程图 PDF、利用率报告、工艺校验报告

## 依赖
- **上游**：C3-PCB 编辑器（单板）、[[01-Gerber输出]] / [[02-Excellon钻孔]] / [[03-PickAndPlace坐标]]（数据源）
- **下游**：SMT 厂（贴片）、PCB 厂（拼板制造）
