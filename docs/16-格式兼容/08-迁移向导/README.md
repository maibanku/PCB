# 16-08 迁移向导

> 所属 [[16-格式兼容]]。引导用户从第三方 EDA 一键迁移整个工程 + 库到本品的向导流程。**二期实现**（MVP 仅 KiCad 单文件导入）。

## 目标（要实现什么）
- 一键导入向导：选择源 EDA 工程/库/文件，自动判定格式（扩展名 + 内容嗅探），路由到对应适配器（[[16-01]]~[[16-04]]）
- 多步向导流程：① 选择源 → ② 库映射（自动匹配 + 手动调整）→ ③ 工程结构预览 → ④ 执行迁移 → ⑤ 保真度报告（[[16-09]]）
- 批量迁移：支持目录级批量导入（一个老工程目录 → 一个新工程），含进度条、可中断恢复、断点续传
- 库自动匹配：源库器件 → 内部库 / 在线库的自动匹配（按位号、参数、封装名、MPN）；未匹配项给出交互式匹配建议
- 配置预设：常见迁移路径（如 KiCad→本品、Altium→本品、立创→本品）保存预设，便于反复使用与团队共享
- 迁移日志与可回退：完整迁移日志可追溯；迁移过程产生新工程副本，不污染原文件，失败可回退重试

## 关键点
- 向导 UI 基于 [[04-GUI与编辑器框架]] 的 Wizard 控件（多页 Step + 上一步/下一步 + 完成回调）
- 格式嗅探：扩展名优先，辅以文件头魔数（如 KiCad S-expr 的 `(kicad_sch`、Altium OLE 的 `D0CF11E0`）
- 库映射匹配算法：MPN 精确 > 封装名+参数模糊 > 位号启发；匹配度低于阈值进入人工审核队列
- 与 [[06-元件库]] 的搜索/在线库深度集成，未匹配器件可一键从在线库拉取或新建
- 长任务进度：批量迁移可能持续数分钟，需后台任务（独立线程）+ 进度通知 + 取消令牌

## 输入 / 输出
- **入**：源 EDA 工程/库/文件目录 + 库映射配置（可选预设）
- **出**：新工程副本（含工程树 + 原理图 + PCB + 库）+ 保真度报告 + 迁移日志
