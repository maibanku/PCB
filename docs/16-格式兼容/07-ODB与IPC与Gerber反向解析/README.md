# 16-07 ODB与IPC与Gerber反向解析

> 所属 [[16-格式兼容]]。制造数据包（ODB++ / IPC-2581 / Gerber）反向解析为只读视图，用于核对、归档与工厂回读。**二期实现**。

## 目标（要实现什么）
- **ODB++ 反向解析**：解析 ODB++ 目录结构（`steps/`/`layers/`/`eda_data`/`fonts`/`misc`），还原网络表、器件、几何图层（走线、焊盘、丝印、阻焊、钻孔），加载为只读设计
- **IPC-2581 反向解析**：解析 IPC-2581 单一 XML 文件，还原完整设计数据（叠层、网络、器件、几何、规则、BOM），可读性最强的制造数据格式
- **Gerber 反向重建**：解析 RS-274X 文件集 + Excellon 钻孔 + Pick&Place 坐标，**重建图层与几何**用于查看对照（不可还原完整网络，需推断或对照外部网表）
- 只读视图：解析结果作为只读设计加载到查看器，用于设计归档、制造数据核对、与原始设计对照验证
- 制造数据 DFM 复查：解析后可做制造前 DFM 检查（最小线宽/间距、孤立焊盘、阻焊桥等，复用 [[11-校验与DFX]]）
- 工厂回读：接收工厂反馈的 ODB/IPC 包，与原始设计做差异比对，确认工厂实际生产数据与设计一致（防工艺篡改或工艺偏差）

## 关键点
- ODB++ 是目录结构（`odb/`/`steps/pcb/`），各图层以 gzip 压缩的 XML 或自有 `eda_data` 格式存储；解析需处理多种压缩与编码
- IPC-2581 是单一 XML（可压缩为 `.zip`），schema 公开，是最有希望建立的行业标准（Mentor/Siemens 主推）
- Gerber 反向重建是"有损"过程：Gerber 只有图层几何，无网络信息；可借助网表文件（IPC-D-356）或坐标文件辅助重建网络
- 三种格式均定位为"只读视图"，不提供编辑能力（避免数据丢失风险）；编辑需在原始设计工具进行
- 与 [[13-制造输出]] 的正向输出形成闭环：设计 → 输出 ODB/IPC/Gerber → 反向解析核对

## 输入 / 输出
- **入**：ODB++ 目录 / IPC-2581 XML / Gerber + Excellon + 坐标文件集
- **出**：只读设计视图（含图层、网络、器件、几何）+ DFM 复查报告 + 与原设计的差异比对
