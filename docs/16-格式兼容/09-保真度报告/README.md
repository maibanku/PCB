# 16-09 保真度报告

> 所属 [[16-格式兼容]]。对导入迁移结果进行保真度评估并输出分级报告，避免"看似成功实则丢数据"的隐性风险。**二期实现**。

## 目标（要实现什么）
- 元素级保真度评估：每个图元/对象给出三态（完美转换 / 部分转换 / 丢失），含原因（如"源格式特性 X 本品暂不支持"）
- 库映射覆盖率：器件、引脚、封装、3D 模型的匹配率与未匹配清单，量化指标（如 95% 器件匹配，3% 需人工核对）
- 设计规则保真度：源设计规则（间距/线宽/层叠/网络类约束）迁移到内部约束管理器的完整性，未映射规则列出
- 几何精度评估：图形偏差量化报告（如样条曲线转多段线的拟合误差、Arc 离散化的最大误差、文字字体替换差异）
- 报告输出：HTML/PDF/JSON 报告，分级问题清单 + 定位跳转（点击问题跳到对应对象）+ 修复建议
- 不让用户在"看似成功实则丢数据"里踩坑：未确认的关键问题进入待办清单，迁移结果在用户审核前标记为"草稿"，未审核不可用于生产

## 关键点
- 保真度评估在适配器层（[[16-格式兼容/01-KiCad格式]]~[[16-格式兼容/07-ODB与IPC与Gerber反向解析]]）产生原始数据，本子功能负责聚合、分级、报告渲染
- 三态模型扩展为五级：完美 / 等价（语义相同表示不同）/ 部分（保留主要属性）/ 降级（精度损失）/ 丢失
- 报告设计参考行业实践（如 Altium 的 Importer Log、KiCad 的 Migration Notes），增强定位跳转与可操作性
- 关键问题阈值：电源网络丢失、差分对极性反转、Pin Map 错配等"致命"问题强制阻断生产流程
- 报告随工程保存（`.migration_report.json`），可被 [[17-协作与版本]] 评审引用

## 输入 / 输出
- **入**：各适配器产出的元素级评估数据 + 库映射结果 + 几何偏差数据
- **出**：HTML/PDF/JSON 保真度报告 + 待办清单 + 工程草稿状态标记
