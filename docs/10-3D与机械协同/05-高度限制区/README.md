# 10-05 高度限制区

> 所属 [[10-3D与机械协同]]。在 PCB 上定义空间高度约束区（器件 vs 外壳内腔），实时检查器件越界并给违例提示。

## 目标（要实现什么）
- 区域定义：在 PCB 编辑器画多边形/矩形高度限制区，可按层/区域分组（如外壳凹槽下方、连接器开窗区）。
- 高度约束：每区域设最大高度上限（mm），可分段（区域内不同子段不同上限）。
- 与外壳联动：从 10-04 导入外壳 STEP 自动生成"内腔包络"，反推到 PCB 上方为高度限制区。
- 实时违例检查：器件 3D 高度 > 区域上限时，在 PCB 与 3D 视图同步标红 + 弹提示。
- 与 DFA 规则联动：高度违例自动作为 11-07 DFA 的一条校验项（不重复实现，共享数据）。
- 区域可视化：半透明色块叠在 PCB 上（顶视），3D 视图中以"虚拟天花板"展示。
- 区域规则入命令栈，支持命名/锁定/批注。

## 关键点
- **高度数据来源**：P6 器件库必须填 3D 高度（ZExtent），缺数据时给"高度未知"告警而非默认 0。
- **复杂外壳**：外壳内腔非平面（如斜顶/圆角），高度上限随 XY 位置变化，需采样为高度场或体素。
- **与铺铜/禁布区区分**：高度区是"空间约束"非"电气/物理禁布"，UI 上用独立图层避免混淆。

## 输入 / 输出
- **入**：P6 器件 3D 高度、10-04 外壳装配、用户区域定义。
- **出**：高度违例清单（供 10-03 / 11-07）、区域几何（PCB/3D 显示）。

## 依赖
- **上游**：P6（器件 3D 高度）、10-04（外壳内腔）、P8（PCB 坐标/区域绘制）。
- **下游**：10-03（干涉检查）、11-07（DFA 可装配性校验）。
