# 10-01 3D 查看器

> 所属 [[10-3D与机械协同]]。在 P8c 实时 3D 预览之上提供剖面、测量、爆炸图、器件拾取等专业查看能力，是机械协同的可视化基座。

## 目标（要实现什么）
- 实时渲染整机/单板 3D（基于自研 GPU 抽象：Vulkan 优先 + GL/Metal 后端，借鉴 Godot `RenderingDevice` / `SceneTree`）。
- 视角控制：正交/透视切换、Top/Front/ISO 等预设视图、轨迹球 + WASD 漫游。
- 剖面（clip plane）：任意方向切面，暴露板内层/器件底部，支持双侧剖切。
- 测量工具：点-点距离、边-边距离、面-面角度，吸附到顶点/边/面。
- 爆炸图：按 Z 高度/层/器件分组拆解，可调爆炸系数与动画过渡。
- 器件 Pick：点击 3D 器件 → 高亮并跳转到 PCB 编辑器对应位号（与 P8c 联动）。
- 显示控制：层可见、丝印/阻焊/铜皮/3D 体切换、器件按类着色（电阻/IC/连接器）。
- 相机视角保存/复用（供 06 渲染输出预设）。

## 关键点
- **拾取精度**：3D ray-AABB + 三角形精确相交（参考 Godot 节点 picking），避免误选。
- **性能**：万器件场景用 LOD + 实例化批渲染（如阻容阵列走 instanced draw）。
- **剖切与器件**：剖切面要与器件 3D 模型做网格切片（mesh slice，必要时 CGAL 限截面），不是简单 discard fragment。（Clipper2 是 2D 布尔库，不适用于 3D 体裁切。）

## 输入 / 输出
- **入**：P8c 板框/叠层/器件位姿、P6 器件 3D 模型、10-02 导入的外壳 STEP。
- **出**：可视化场景、拾取事件（→ PCB 跳转）、测量结果、相机预设（供 10-06）。

## 依赖
- **上游**：P1/P8c（3D 渲染扩展）、P6（器件 3D 模型）、10-02（外部模型）。
- **下游**：10-03（干涉检查需可见性）、10-06（渲染输出消费场景）。
