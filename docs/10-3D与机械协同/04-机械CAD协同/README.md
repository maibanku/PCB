# 10-04 机械 CAD 协同

> 所属 [[10-3D与机械协同]]。对接机械工程师工作流：导入外壳/结构件 STEP，建立装配基准，实现 PCB ↔ 机械的变更同步。

## 目标（要实现什么）
- 外壳 STEP 装配对位：导入外壳后通过基准点/基准面/基准轴与 PCB 板框对齐（3-2-1 定位）。
- 装配基准定义：记录基准坐标系（datum reference frame），支持保存为工程级装配约束。
- 板框 → 机械：PCB 板框（含开槽/定位孔）导出为 STEP/DXF 供机械 CAD 引用为"PCB 占位"。
- 机械定位孔 → PCB：导入机械工程师放置的安装孔/连接器位置，反推到 PCB 坐标系。
- **双向变更同步**：基于 ECO 机制（P14），外壳修改 → 提示 PCB 受影响区域；PCB 板框变更 → 提示机械重新对位。
- 关联约束：尺寸标注（如板到外壳内壁距离）随装配更新，超差告警。
- 协同元数据：版本、修改人、时间戳、变更摘要（Git diff 友好）。

## 关键点
- **坐标系对齐**：PCB 用 mm 左下原点，机械 CAD 可能用 inch 或装配中心，需显式坐标系映射表。
- **基准不漂移**：装配基准（如 4 个安装孔中心）变更影响巨大，必须版本化锁定 + 变更告警。
- **非实时协同**：走"快照 + 文件交换 + ECO"而非实时，与 F1 协作策略一致。

## 输入 / 输出
- **入**：机械工程师的 STEP/DXF（外壳/结构件）、PCB 板框/定位孔（P8）。
- **出**：装配约束模型（基准 + 变换矩阵）、影响清单（受影响器件/区域）、变更日志。

## 依赖
- **上游**：10-02（STEP 导入导出）、P8（板框/定位孔）、P14（ECO）。
- **下游**：10-03（干涉检查用装配结果）、10-05（高度区关联外壳内腔）。
