# 10-06 渲染输出

> 所属 [[10-3D与机械协同]]。把 3D 场景渲染为可交付资产：高清图（PNG/JPG）、矢量 PDF、可交互 3D PDF，供文档/评审/客户展示。

## 目标（要实现什么）
- 高清光栅输出：PNG/JPG/TIFF，支持 4K/8K 分辨率、抗锯齿、透明背景。
- 矢量 PDF：3D 视图矢量化导出（线框/轮廓），打印无损放大。
- 3D PDF（PRC/U3D）：内嵌可旋转缩放的 3D 模型，Adobe Reader 直接交互（对标 Altium 3D PDF）。
- 材质/光照：PBR 材质（金属/粗糙度）、HDR 环境光、多光源，输出接近真实照片级。
- 视角预设：保存多个相机视角（顶视/ISO/爆炸图），一键多视角批量输出。
- 批处理：配置输出模板（分辨率/视角/水印），一键导出全套交付图。
- 元数据嵌入：PDF 中写入工程名/版本/位号清单/装配图标注。

## 关键点
- **离屏渲染**：高分辨率走离屏 framebuffer + 多采样 AA，不依赖实时窗口（参考 Godot `Viewport` 离屏纹理）。
- **3D PDF 标准**：PRC（紧凑）vs U3D（兼容旧 Acrobat）二选一或都生成，注意授权（PRC 开源可用）。
- **可复现**：渲染参数（光照/材质/视角）存入工程，再次出图一致。

## 输入 / 输出
- **入**：10-01 的 3D 场景与相机预设、用户输出配置（模板/水印）。
- **出**：交付图（PNG/JPG/PDF/3D PDF）、装配说明图（含标注）。

## 依赖
- **上游**：10-01（场景/相机）、P6（器件材质）。
- **下游**：用户（设计评审/客户交付/装配文档）、P13（制造输出 / 装配图 PDF）。
