# 10-03 装配干涉检查

> 所属 [[10-3D与机械协同]]。基于器件 3D 体与外壳 STEP 做几何干涉/间隙检测，输出可定位跳转的违例清单，是 DFA 可装配性的几何依据。

## 目标（要实现什么）
- 器件-器件干涉：检测同板器件 3D 包络盒相交（含 Z 高度碰撞）。
- 器件-外壳干涉：与 10-04 导入的外壳 STEP 做布尔相交（B-Rep 或精确三角网格）。
- 间隙检查：器件与外壳/邻器件最小间距 < 阈值（如 0.5mm）时告警。
- 高度碰撞：器件 3D 高度 vs 10-05 高度限制区，超界标红。
- 干涉分级：硬干涉（相交）/ 接触（=0）/ 接近（<间隙阈值），颜色与严重度区分。
- 算法：粗筛 AABB tree / BVH + 精算 GJK / SAT / 三角形精确布尔。
- 干涉列表：双击跳转到 PCB 对应位号、3D 中高亮闪烁违例对。
- 增量检查：仅对 PCB 变更部分重算（与命令栈联动）。

## 关键点
- **两阶段检测**：万器件全两两组合 O(n²) 不可行，必须 AABB/动态 BVH 粗筛 → 精算（参考 Bullet / FCL 库思路）。
- **外壳 STEP 复杂度**：外壳可能数十万面，需预生成加速结构并缓存。
- **降级策略**：精确布尔失败时降级到网格精度（标注"近似结果"），不阻塞流程。

## 输入 / 输出
- **入**：P6 器件 3D 体、P8 板框/位姿、10-04 外壳 STEP、10-05 高度限制区。
- **出**：违例清单（位置/类型/严重度），供 11-07 DFA 消费、UI 面板与 3D 高亮。

## 依赖
- **上游**：10-01（3D 场景）、10-02（外壳模型）、10-05（高度区）。
- **下游**：11-07（DFA 可装配性校验）、用户（机械工程师评审）。
