# 10-3D与机械协同

> 对应 **Plan P10**（Phase 3 · 专业补强）。提供 PCB 与机壳的 3D 可视化、机械格式互操作、装配干涉检查与高清渲染输出，打通电子与机械设计边界。

## 定位
- **做什么**：3D 查看器（剖面/测量/爆炸图）；STEP/IGES/OBJ/VRML 导入导出（Assimp）；器件装配干涉检查；机械 CAD 外壳对位协同；高度限制区约束；高清渲染与 3D PDF 输出。
- **不做什么**：不做 PCB 实时 3D 预览本体（属 P8c，本域为其扩展增强）；不做机械零件建模/机械 CAD 编辑器；不做 CFD/热场仿真。
- **代码位置**：`eda/mechanical, scene/3d`（见 [[00-总览/03-项目目录结构]]）

| 02 | [STEP/IGES/OBJ/VRML 导入导出](02-STEP_IGES_OBJ_VRML导入导出/) | 3D 格式互操作（Assimp） | 待实现 |

| 06 | [渲染输出](06-渲染输出/) | 高清渲染、3D PDF 输出 | 待实现 |
