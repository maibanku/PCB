# 07-02 绘制与放置

> 所属 [[07-原理图编辑器]]。提供原理图图元的交互绘制、放置、编辑工具链：栅格吸附、自动连线、正交/任意角度走线、器件放置。

## 目标（要实现什么）
- 工具集（Tool/Mode 切换，借鉴 Godot 编辑器模式机制）：选择、放置器件、画导线、画总线、放网络标号、放电源端口、画层次块、放注释、放图片。
- 栅格吸附：可视化栅格（0.1 英寸 / 1mm / 自定义），吸附模式含器件中心、引脚端点、导线端点、栅格点，可独立开关。
- 导线绘制：正交（H/V/45°）与任意角度模式；自动连线（鼠标点到引脚端点自动延展）；T 型节点自动打节点圆点。
- 器件放置：旋转（R 键 90° 递增）、镜像（X/Y）、位号预占（如 U?）、放置前实时预览。
- 编辑操作：移动、复制、删除、属性编辑（双击进 Inspector）、批量框选、按类型/属性过滤选择。
- 实时连线提示：靠近的引脚/导线端点高亮；未连接引脚端点用小圆圈标记（铺路 ERC）。
- 拖拽保持连通（drag-connected）：拖动器件时连接的导线跟随延伸，不破坏电气连接。

## 关键点
- 工具操作 → 命令栈原子事务（B3），多步可合并（如连续画线段合并为一次 Undo）。
- 吸附判定优先级：引脚 > 导线端点 > 器件中心 > 栅格。
- 自动连线避免重复网络（同两点重复画不产生第二条导线，按连通图合并）。
- 借鉴 Godot 编辑器：节点 Inspector + 工具栏 + 命令面板（Command Palette）。

## 输入 / 输出
- **入**：图元类型（01）、栅格/单位配置（B2）、用户鼠标/键盘输入。
- **出**：编辑后的图元树（已入命令栈），驱动 04-网表 / 05-ERC 重算。

## 依赖
- **上游**：01-原理图图元、B2 几何与吸附、B3 命令栈、C1 元件库。
- **下游**：04-网络表生成、05-ERC（依赖图元拓扑）、09-原理图PDF输出。
