# 07-07 复用模块

> 所属 [[07-原理图编辑器]]。支持带端口的原理图模块复用，可含 PCB 同步复用，降低重复设计成本。

## 目标（要实现什么）
- 复用模块（ReuseBlock）：将一组器件 + 内部连线 + 端口封装为命名模块（如"运放单元"、"电源滤波节"），可独立保存到库。
- 模块端口：明确定义对外电气接口（输入/输出/电源/地），实例化时外部按端口连接。
- 多实例放置：同一模块在同一工程可多次放置，位号自动分配（06-Annotate 联动）。
- 模块库：模块存入元件库（C1 扩展），可跨工程复用；版本化管理 + 依赖锁定。
- 模板/参考设计：内置常见电路模板（去耦节、USB 接口、DDR 端接、ESP32 最小系统等），一键插入。
- PCB 同步复用：模块可含 PCB 端布局/布线模板（"复制布局"），实例化时直接铺到 PCB（与 08-PCB 联动）。
- 修改同步：修改模块模板时，提示用户对所有实例做同步更新或保留为快照。

## 关键点
- 模块 = 子图 + 端口 + 可选 PCB 布局模板的复合资源（借鉴 Godot PackedScene）。
- 实例与模板的关系需明确：链接（跟随更新）vs 拷贝（独立演化）。
- 与 03-层次化设计的边界：层次化是单工程内组织；复用模块是跨工程、可入库的资产。

## 输入 / 输出
- **入**：01-图元（已绘制电路）、C1 元件库（模块库载体）。
- **出**：可复用模块（含端口定义、可选 PCB 模板），供当前工程/其他工程实例化。

## 依赖
- **上游**：01-原理图图元、02-绘制与放置、03-层次化设计、C1 元件库。
- **下游**：06-位号标注（实例编号）、04-网表生成（展开）、08-PCB（PCB 模板同步）。
