# 07-04 网络表生成

> 所属 [[07-原理图编辑器]]。从原理图连通关系导出内部网表（Netlist），并支持通用格式导出，作为原理图到 PCB、仿真的数据桥梁。

## 目标（要实现什么）
- 内部网表数据结构：Net（网络名 + Pin 列表 + 网络类）、Pin 引用（器件位号 + 引脚号）、网络类（Power/GND/Signal/HighSpeed/Diff ...）。
- ��通性解析算法：从图元树中遍历导线/网络标号/电源端口/层次块端口，构建等价类（Union-Find），合并重名网络与跨页网络。
- 层次化展开：将层次块实例化展开为具体器件位号 + 引脚（03-层次化设计）。
- 网络自动命名：未显式命名的网络按"最近位号-引脚"或 Net0001 规则命名；同名网络冲突时报错。
- 网表视图面板：树形/列表展示每条网络、成员引脚；可点击跳转到原理图位置。
- 格式导出：SPICE 网表（供 C4 仿真）、通用 PCB 网表（KiCad/Protel 等格式），供 08-PCB 导入。
- 增量更新：原理图变更时基于脏区只重算受影响子图，万 Pin 级网表更新亚秒级。

## 关键点
- 网表是 C2→C3 的咽喉数据，必须稳定且版本化（关联原理图 schema 版本）。
- Union-Find 求连通分量，对万级引脚规模 O(n·α(n)) 足够。
- 网表生成必须与 ERC 解耦：ERC 报错但网表仍能产出（带警告），保证流程不被卡死。

## 输入 / 输出
- **入**：01-图元（导线、网络标号、电源端口、端口）、03-层次化设计（端口映射）。
- **出**：内部网表对象 + 外部格式文件（SPICE / PCB 网表），供 08-PCB / C4 仿真 / ECO 同步。

## 依赖
- **上游**：01-原理图图元、02-绘制与放置、03-层次化设计。
- **下游**：08-PCB 编辑器（网表导入驱动布局）、C4 仿真、B3 ECO（差异比对基准）。
