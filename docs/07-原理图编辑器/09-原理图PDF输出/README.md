# 07-09 原理图PDF输出

> 所属 [[07-原理图编辑器]]。将原理图导出为 PDF 或图片（PNG/SVG），支持分页、图框、标题栏等归档需求。

## 目标（要实现什么）
- PDF 导出：矢量输出（保留缩放清晰度），支持单页 / 全部页 / 选定页范围。
- 图片导出：PNG（位图，可设 DPI）、SVG（矢量，便于二次编辑）。
- 图框 / 标题栏（Title Block）：内置可定制模板（公司 Logo、项目名、页码、版本、日期、设计者、审核者），位置可配。
- 分页策略：每页一张（默认）、智能跨页（大图自动分页，保留网络连通性标注）。
- 打印预览：所见即所得的预览窗口，支持缩放、翻页、纸张方向（横/纵）、纸张大小（A4/A3/A2/A1/自定义）。
- ERC 标记出图：可选将 ERC 错误/警告位置以图形标记输出（用于评审）。
- 网络高亮：可指定网络名，导出时高亮（用于评审单条信号回路）。
- 黑白 / 彩色模式、灰度模式（兼容复印/打印）。
- 批处理：CLI 命令行无头导出（F4 工具链，CI/CD 友好）。

## 关键点
- PDF 用矢量绘制（直接调渲染层的 2D 绘制命令到 PDF 上下文），保证缩放清晰。
- 字体需嵌入 PDF（HarfBuzz/FreeType 已在 B2/平台层），避免跨机器字体替换。
- 输出尺寸精确（mm 单位），与打印纸张对齐。
- 标题栏字段支持模板变量（${project}、${page}、${date}）。

## 输入 / 输出
- **入**：01-图元、页面布局（B4 工程树）、标题栏模板、用户选项。
- **出**：PDF / PNG / SVG 文件，归档/分享/打印用。

## 依赖
- **上游**：01-原理图图元、B2 渲染与字体、B4 工程页树。
- **下游**：F4 CLI（批处理导出）、归档交付（D 阶段输出伴随材料）。
