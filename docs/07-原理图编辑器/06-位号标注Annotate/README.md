# 07-06 位号标注Annotate

> 所属 [[07-原理图编辑器]]。提供器件位号的自动编排（Annotate）与手动重排，支持按页/按层次编号策略。

## 目标（要实现什么）
- 自动编号：扫描未分配位号（如 U?, R?, C?）的器件，按规则分配唯一位号（U1, U2, R1, R2 ...）。
- 编号策略可配：
  - 顺序（Top-to-Bottom, Left-to-Right）；
  - 按页（每页独立起号或跨页连续）；
  - 按层次块（按层次块实例分组编号，便于多通道）；
  - 起始编号 / 步长（如 100 起、步长 10，留出插入空间）。
- 重排：对已编号器件整体重排（保留间隔策略、清理空号、解决冲突）。
- 前缀自定义：支持非标前缀（如 IC 替代 U、RN 替代 R），按器件类映射。
- 多通道（层次块实例）自动加后缀或独立位号（如 U1A/U1B 或 U1/U2，可配）。
- 位号预览面板：执行前展示"将变更：R3 → R5"列表，确认后入命令栈（可 Undo）。
- 与 PCB 同步：位号变更后通过 ECO（B3）同步到 PCB 端，保持位号一致。

## 关键点
- 编号操作须原子化进入命令栈（B3），可一键撤销。
- 编号空间分前缀独立维护，避免 U/R/C 互窜。
- 多通道实例化策略与 03-层次化设计 / 04-网表展开对齐。

## 输入 / 输出
- **入**：01-图元（器件位号字段）、03-层次块实例信息、用户策略选择。
- **出**：完整编号的器件列表 + ECO 变更日志（供 PCB 同步）。

## 依赖
- **上游**：01-原理图图元、02-绘制与放置、03-层次化设计。
- **下游**：04-网表生成（位号是网表 key）、05-ERC（重复位号检查）、B3 ECO（同步 PCB）。
