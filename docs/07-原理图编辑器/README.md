# 07-原理图编辑器

> 对应 **Plan P7**（Phase 2 · MVP 闭环）。承接元件库与引擎内核，提供从绘制原理图到导出网表、过 ERC、出 PDF 的一站式原理图设计能力。

## 定位
- **做什么**：原理图图元（器件/导线/网络标号/总线/电源端口/层次块/子图/端口/注释/图片）、绘制与放置（栅格吸附、正交/任意角走线）、层次化设计、网络表生成、ERC 电气规则检查、位号标注 Annotate、复用模块、BOM 雏形、原理图 PDF 输出。
- **不做什么**：不做 PCB 物理版图（归 P8）；不做完整 BOM/供应链属性（归 P13/P21，此处仅雏形）；不做仿真（归 P9）；不做原理图↔PCB 双向 ECO 同步（归 P14）。
- **代码位置**：`eda/schematic`（见 [[00-总览/03-项目目录结构]]）
