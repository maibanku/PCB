# 07-03 层次化设计

> 所属 [[07-原理图编辑器]]。支持层次块（HierBlock）、子图（SheetInstance）、端口（Port）连接与跨页网络，实现复杂设计的分页分块组织。

## 目标（要实现什么）
- 层次块（HierBlock）：在父页上放置方框，关联一个子原理图页，标注端口接入点，支持多实例化（同一子图被引用 N 次，如多通道放大器）。
- 端口（Port）：层次块与子图之间的电气接口；输入/输出/双向类型；父图端口 ↔ 子图端口一一映射。
- 跨页网络（Global Net / 跨页标号）：通过同名网络标号或全局电源端口在多页间自动连通，无需画跨页导线。
- 多页管理：原理图页树（页排序、增删、重命名、克隆），每页独立坐标空间，统一标题栏。
- 层次导航：双击层次块跳转子图；面包屑路径显示当前位置（如 TopPage / Analog / Channel3）。
- 层次化网表展开：实例化时按 Instances 自动展开（如 U1, U2, U3 来自同一子图），不重复定义。
- 自顶向下 / 自底向上两种工作流均支持（先画方框→建子图，或先画子图→封装为块）。

## 关键点
- 子图引用采用"模板 + 实例"模型（类似 Godot PackedScene 实例化），修改模板同步影响所有实例。
- 端口映射表是网表生成的关键输入，需保持父/子图端口数量、名称、类型一致（不一致由 ERC 捕获）。
- 层次块实例号自动维护（位号 Annotate 时分配 U1, U2 ...）。

## 输入 / 输出
- **入**：01-图元（层次块、子图、端口）、02-绘制与放置工具。
- **出**：层次化原理图树 + 端口映射表，供 04-网表展开 / 05-ERC 跨页检查 / 06-Annotate。

## 依赖
- **上游**：01-原理图图元、02-绘制与放置、B4 工程与文件系统（页树）。
- **下游**：04-网络表生成（需展开实例）、05-ERC（跨页/层次一致性）、06-位号标注。
