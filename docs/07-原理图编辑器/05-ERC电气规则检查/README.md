# 07-05 ERC电气规则检查

> 所属 [[07-原理图编辑器]]。对原理图做电气规则检查（ERC）：未连接、冲突、电源地、重复位号、悬空引脚等，结果可定位可修复。

## 目标（要实现什么）
- 内置规则集：
  - 未连接引脚（悬空 pin）；
  - 重复位号（如两个 R1）；
  - 网络冲突（如两个 Output 互连、Output 接 Power 类型不匹配）；
  - 多驱动冲突（同一网络多个 Output）；
  - 电源地短路（VCC 直接连 GND 且无负载）；
  - 电源网络未驱动（VCC/GND 无电源端口接入）；
  - 单点网络（仅 1 个 pin，无连接对端）；
  - 层次块端口与子图端口不匹配（03-层次化设计联动）；
  - 差分对极性 / 配对缺失（为 P8b 布线铺路）。
- 引脚电气类型矩阵（Input/Output/Bidirectional/Power/Passive/OpenCollector ...），按矩阵判定合法/警告/错误。
- 自定义规则：类约束表达式或脚本（对接 D1 统一校验框架）。
- 结果面板：分级（Error/Warning/Info）、列表化、点击定位到原理图位置、忽略（Ignore）/批准（Ack）/批量修复建议。
- 实时 ERC（编辑时增量反馈）+ 全图 ERC（一键批检）双模式。
- 规则文件工程级 / 用户级分层覆盖，可分享、云同步。

## 关键点
- ERC 与网表（04）共享图元拓扑，避免重复解析。
- 引脚电气类型来自符号库（C1），符号缺失类型时按 Passive 默认处理并提示。
- 自定义规则交由 D1 统一校验框架，ERC 仅负责原理图层。

## 输入 / 输出
- **入**：01-图元（引脚类型）、03-层次化设计（端口一致性）、规则配置。
- **出**：ERC 报告（错误列表 + 定位信息），驱动用户修复或阻断 04-网表导出。

## 依赖
- **上游**：01-原理图图元、02-绘制与放置、03-层次化设计、C1 元件库（引脚类型）。
- **下游**：D1 统一校验框架（自定义规则）、04-网表生成（错误阻断导出）、09-原理图PDF输出（错误标记）。
