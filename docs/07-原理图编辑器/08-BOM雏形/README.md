# 07-08 BOM雏形

> 所属 [[07-原理图编辑器]]。聚合器件属性生成 BOM 雏形，直供 P13 制造输出与 P21 供应链集成进一步加工。

## 目标（要实现什么）
- BOM 表生成：扫描原理图所有器件，按"位号 + 器件型号 + 数量 + 关键属性"聚合为表（同型号器件合并计数，如 R:10K × 5）。
- 列字段可配：位号、值（Value）、封装（Footprint）、型号（MPN）、厂商（Manufacturer）、描述、用户自定义属性（容差/耐压/精度）。
- 分组规则：按型号合并 / 按 Value+Footprint 合并 / 不合并（每条一行），可切换。
- BOM 雏形视图：表格面板，支持排序、筛选、列编辑（直接改 Value/MPN）、行内校验（缺少 MPN 时标红）。
- 占位符 / 虚拟器件处理：连接器/焊盘等"非采购"器件可标记为 DNP（Do Not Populate），BOM 中区分显示。
- 属性来源：器件库（C1）预置属性优先，原理图内覆写次之（带来源标记）。
- 导出：CSV / Excel，作为 P13 制造输出与 E2 供应链配齐的输入。
- 校验：缺 MPN / 缺封装 / Value 空缺等异常高亮（接入 ERC/D1）。

## 关键点
- BOM 字段是 E2 供应链对接的最小数据集，必须结构化（不靠解析自由文本）。
- 与 04-网表共享器件扫描，避免重复遍历。
- BOM 与原理图双向链接：BOM 中点击行 → 跳到原理图器件；原理图改值 → BOM 增量更新。

## 输入 / 输出
- **入**：01-图元（器件属性）、C1 元件库（MPN/厂商/供应链属性）、06-位号（已编号）。
- **出**：BOM 雏形表 + CSV/Excel 导出文件，供 P13 制造输出 / E2 供应链集成消费。

## 依赖
- **上游**：01-原理图图元、04-网表（共享器件扫描）、06-位号标注、C1 元件库。
- **下游**：P13 制造输出（BOM 文件）、E2 供应链集成（配齐/比价/替代料）、D1 校验（缺料校验）。
