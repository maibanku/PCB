# 15-03 板间信号连通性检查

> 所属 [[15-多板系统级]]。基于连接器/线缆关系与各板网表，校验跨板信号的电气连通性、Pin 映射一致性与差分/电源完整性。

## 目标（要实现什么）
- 系统级连通性校验：构建系统网表（[[15-多板系统级/01-系统级多板设计]] 求解器产出），校验跨板网络电气连通（A 板 Net 经连接器/线缆是否真正到达 B 板目标 Net）
- Pin 映射一致性检查：连接器公母 Pin 数、位号、信号名匹配；发现错配（Pin 数不一致）、遗漏（未映射 Pin）、重复（多对一冲突）
- 差分对完整性：跨板差分对的极性（P/N 不反）、耦合连续、回流参考层一致，无单端化段；等长要求跨板传递
- 电源地完整性：跨板电源域电压一致（+5V 与 +5V 相连，不能 +5V↔+3.3V）；地网络回流连续；共地/分割地（PGND/AGND 桥接）标注校验
- 未连接 / 悬空检测：连接器有 Pin 未在任一板定义网络，给出警告并定位到具体 Pin；NC（No Connect）引脚需显式标注
- 系统级错误报告：错误分级（错误/警告/提示）、列表可定位跳转（跳到对应板/连接器/Pin）、可导出 HTML/PDF 报告

## 关键点
- 复用 [[11-校验与DFX]] 统一校验框架，注册 `SystemLevelRule` 系列规则；结果面板与 ERC/DRC 同构
- 连通性求解本质是图算法：节点 = 各板 Net，边 = 连接器 Pin 映射 + 线缆芯；求连通分量即为系统 Net
- 差分对校验需结合 [[12-SI-PI分析]] 的阻抗连续性约束，避免连接器引入阻抗突变
- 错误定位需双跳转：系统视图高亮连接器，单板视图高亮 Pin/网络

## 输入 / 输出
- **入**：[[15-多板系统级/01-系统级多板设计]] 系统网表、[[15-多板系统级/02-连接器与线缆关系]] 连接器/线缆 Pin 映射、各板网表（P7/P8）
- **出**：系统级校验结果（错误清单 + 定位信息）、HTML/PDF 报告、待办标记可同步回各板
