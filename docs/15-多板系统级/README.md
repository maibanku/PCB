# 15-多板系统级

> 对应 **Plan P15**（Phase 3 · 专业补强）。跨多块 PCB 的系统级设计、连接与连通性校验。

## 定位
- **做什么**：将一个系统拆分为多块 PCB，管理板间连接器、线缆与跨板信号连通性，进行系统级校验。
- **不做什么**：不替代单板级的布局布线与 DRC（由 P5/P8 承担）；不做机械装配仿真。
- **代码位置**：`eda/project, eda/validation`（见 [[00-总览/03-项目目录结构]]）
