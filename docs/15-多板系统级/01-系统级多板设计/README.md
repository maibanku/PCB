# 15-01 系统级多板设计

> 所属 [[15-多板系统级]]。将一个电子系统组织为多块 PCB（母板 + 子卡 / 背板 + 刀片）的整体工程进行管理。

## 目标（要实现什么）
- 一个"系统工程"节点可包含多块 PCB 子板与机械件，以系统树（系统 > 板 > 图页）形式组织，区别于单板工程
- 系统级网表：通过连接器/线缆关系自动贯通各板子网表，形成跨板系统网表（系统 Net = 板内 Net + 跨板连接段）
- 多板工程模板：预置常见系统结构（主板+扩展卡、背板+刀片、母女卡、底板+核心模块），一键创建
- 系统级 BOM 聚合：合并各板 BOM + 线缆 + 连接器 + 结构件，直供 [[21-供应链集成]] 下单
- 板间装配关系：定义板与板的机械装配关系（插槽、固定柱间距、间距约束），驱动 [[10-3D与机械协同]] 的系统级 3D 预览
- 系统配置变体：一个系统工程支持多种配置（高配/低配、不同扩展组合），按变体启停子板与器件

## 关键点
- 系统工程扩展 P5 工程树，新增 `SystemNode` 作为多 `BoardNode` 的父节点；系统树持久化为 `system.eda.json`
- 系统网表求解器：以连接器 Pin 映射为边、各板网络为节点构建图，做连通分量聚类得到系统级网络
- 配置变体（Variant）通过"可选子板 + 可选器件"两段式实现，与 P6 器件变体（Altium 概念）对齐
- 系统级 DRC/DFX 调用 [[11-校验与DFX]] 框架，注册"系统级规则"（如跨板电源域一致、回流路径连续）

## 输入 / 输出
- **入**：各子板工程（P5/P7/P8 产出）+ 连接器/线缆关系（[[15-多板系统级/02-连接器与线缆关系]]）+ 装配关系定义
- **出**：系统工程文件（`*.edasys`）、系统网表、系统级 BOM、系统级装配模型供 3D 预览

## 依赖
- **上游**：[[05-工程与文件系统]]（工程树/格式）、[[07-原理图编辑器]]（板内网表）、[[08-PCB编辑器]]（板内 PCB）
- **下游**：[[15-多板系统级/02-连接器与线缆关系]]（消费板子做连接器映射）、[[15-多板系统级/03-板间信号连通性检查]]（消费系统网表做连通性校验）、[[10-3D与机械协同]]（消费装配关系）、[[21-供应链集成]]（消费系统 BOM）
