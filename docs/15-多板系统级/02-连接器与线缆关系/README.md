# 15-02 连接器与线缆关系

> 所属 [[15-多板系统级]]。定义板间连接器（板对板、线缆连接器）与线缆的对应关系，构建跨板物理与电气连接。

## 目标（要实现什么）
- 在每块 PCB 上指定连接器件（板对板公母、线缆连接器、FPC/排针），关联其 Pin 列表与位号
- 线缆 / 排线定义：电缆类型（单线 / 排线 / 双绞 / 同轴 / FFC）、长度、规格（AWG）、颜色、特征阻抗
- 跨板 Pin-Pin 映射编辑器：可视化界面连接器 A 的 Pin_n → 连接器 B 的 Pin_m（或经电缆芯数映射），自动展开为系统网表
- 线束（Harness）清单：导出线束表（线号、起止端子位号、颜色、长度、规格），供装配厂线束加工使用
- 差分对 / 电源地跨板标注：跨板差分对极性保持、电源地网络跨板标注（PGND/DGND/AGND 等）与等长要求传递
- 连接器库：常见连接器型号库（含 Pin 数、间距、公母、厂商料号），可搜索调用并关联供应链信息

## 关键点
- 连接器作为特殊器件，在 PCB 上是真实器件（有封装/位号），在系统层额外承担"网络桥"角色
- Pin 映射存储为三元组 `(BoardA.ConnA.PinN, Cable/CableSet, BoardB.ConnB.PinM)`，可逆推系统网表
- 线束清单对标行业规范（如军工 JL/ZH 系列线束表、汽车 ISO 19642 / LV214 线束标准），输出 CSV/Excel
- 连接器件扩展 P6 元件库模型，新增 `Connector` 视图与 Pin 映射表（Pin1↔Pin2 物理对应，如 RJ45 1↔8 交叉）

## 输入 / 输出
- **入**：[[15-01]] 各子板及其连接器件（来自 P6/P8）、连接器库（P6）
- **出**：连接器/线缆关系模型（`*.edasys` 内段）、跨板 Pin-Pin 映射表、线束清单（CSV/Excel）
