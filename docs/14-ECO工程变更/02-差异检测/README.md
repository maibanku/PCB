# 14-02 差异检测

> 所属 [[14-ECO工程变更]]。比对原理图与 PCB 的逻辑数据（器件/网络/封装/引脚），自动检测新增、删除、修改、重命名四类差异，作为 ECO 生成的输入。

## 目标（要实现什么）
- 比对维度：
  - **器件级**：原理图器件 vs PCB 器件（按位号 + 内部 ID 双键）
  - **网络级**：原理图网表 vs PCB 网表（按网络名 + 连通性）
  - **封装级**：原理图 footprint 属性 vs PCB 实际封装
  - **引脚级**：器件引脚映射（pin map）
- 检测差异类型：新增（Added）、删除（Removed）、修改（Modified）、重命名（Renamed）
- 匹配算法：位号优先匹配 + 模糊匹配（重命名后追溯，如 R1 → R5）+ 唯一 ID 兜底
- 差异可视化：图形化 diff 视图（类似 Git diff），左右分屏原理图 vs PCB，高亮差异
- 忽略列表：可配置"忽略项"（如电源标志位差异），减少噪音
- 与 ERC/DRC（D1）联动：差异检测前置 ERC，避免因原理图错误导致误判
- 支持"快速 diff"（仅器件/网络名）和"深度 diff"（含引脚/封装/属性），按需选档

## 关键点
- 器件唯一 ID（UUID）是关键：位号会变，ID 不变，是可靠匹配基础
- 网络名差异（如 VCC vs +3.3V）易误判，需"网络别名"机制（如电源标志多别名）
- 引脚映射差异（pin map mismatch）是隐性 bug 来源：原理图 1 脚 vs PCB 不同封装引脚
- 算法效率：万级器件 diff 应秒级完成（参考 git 的 myers diff 算法）
- 重命名追溯：基于位置 + 邻居 + 时间戳的"模糊匹配"，建议而非自动确定
- 与 [[01-原理图PCB双向同步]] 联动：差异检测是同步的前置

## 输入 / 输出
- **入**：原理图数据、PCB 数据、匹配规则、忽略列表
- **出**：差异列表（结构化）、可视化 diff 视图、未匹配项清单

## 依赖

- **下游**：[[03-ECO列表]]（差异转化为 ECO）
