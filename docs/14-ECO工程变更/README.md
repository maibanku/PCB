# 14-ECO工程变更

> 对应 **Plan P14**（Phase 2 · MVP 闭环）。把 ECO（工程变更订单）做成显式、可审查、可回滚的一等公民，贯通原理图 ↔ PCB 双向同步。

## 定位
- **做什么**：原理图变更 → 检测差异 → 生成 ECO 列表 → 选择性应用到 PCB；PCB 变更（改封装/位号等）→ 反向同步回原理图；提供变更预览、选择性应用、变更日志与可回滚审计追踪。
- **不做什么**：不做实时多人协同编辑的冲突合并（协作走 P17）；不替代命令栈本身的 Undo/Redo（P3）。
- **代码位置**：`eda/command`（见 [[00-总览/03-项目目录结构]]）
