# 14-05 变更预览与日志

> 所属 [[14-ECO工程变更]]。应用前图形化预览变更影响（canvas 高亮 + diff），应用后记录完整变更日志（who/when/what/why），供审计与回溯。

## 目标（要实现什么）
- **预览模式**：进入预览后，PCB/原理图 canvas 上：
  - 红色高亮：将被删除的元素
  - 绿色高亮：将新增的元素
  - 黄色高亮：将修改的元素（含 before/after 标注）
- 选中 ECO → canvas 自动跳转并聚焦到相关元素
- diff 视图：左右分屏显示 before/after（原理图 vs PCB、当前 vs 应用后）
- 变更影响范围分析：列出受影响的网络/层/器件/规则
- **变更日志（Change Log）**：每次应用记录：
  - 时间戳（精确到毫秒）
  - 操作者（用户名 / 系统自动）
  - 变更类型与对象（ECO-001: Add Component R5）
  - 变更原因（用户输入或自动从注释）
  - Before/After 值
- 日志持久化：写入工程文件（Git-friendly 文本格式）+ 数据库索引
- 日志导出：CSV / HTML / Markdown，作为变更文档归档
- 日志搜索/过滤：按时间、用户、对象类型筛选

## 关键点
- 预览是降低 ECO 错误的关键：让用户"先看再决定"
- canvas 高亮要高效（LOD + 增量渲染），万级元素不应卡顿
- diff 视图参考 Git 工具（如 Beyond Compare），用户习惯一致
- 变更日志是企业审计要求（ISO 9001 / 功能安全 IEC 61508）：可追溯每次变更
- 日志格式：结构化 JSON（机器可读） + 可读 Markdown（人可读），双格式
- 与 [[06-回滚与审计]] 联动：日志是审计的核心数据源
- 与 F1 Git 集成联动：变更日志可对应 commit message，自动同步

## 输入 / 输出
- **入**：选中的 ECO 列表、当前设计数据
- **出**：预览视图、变更日志（结构化 + 可读）
