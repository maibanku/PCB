# 几何与命令栈实现计划（Geometry & Command Stack）

> 📊 **实现进度**：`[████░░░░░░] 44%` · 4/9 Task · ⚙️ 实现中 · 追踪：[[00-总览/06-前期搭建项目路线]] · 最后更新：2026-07-27

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 按任务逐个实现。步骤使用 `- [ ]` 复选框跟踪。本计划 **Task 1 已完整 TDD 展开**，Task 2~9 为骨架（标题 + 范围 + Files/Interfaces 概要 + `- [ ] 待展开`），进入对应 Task 时再按 Task 1 的粒度细化。

**Goal:** 搭建自研 EDA 的几何内核与命令栈——`int64/nm` 定点图元 + Clipper2 布尔/偏移 + earcut 三角剖分 + 自研 R-tree 空间索引 + 圆弧离散化 + 求交测量 + 事务化 Undo/Redo 命令栈与选择系统，最终产出"一套可被原理图/PCB 编辑器直接消费的几何 API，配合万级图元邻域碰撞查询达标，且所有几何编辑可撤销/可重做"。

**Architecture:** 三层划分。**图元类型层**（`types.h`/`units.h`/`transform.h`/`snap.h`）：纯值类型 POD 结构（`Point`/`Segment`/`Arc`/`Polyline`/`Polygon`/`Path`/`Box`），内部统一 `Coord = int64_t`（单位 nm），用户层 mm/mil/inch 在边界处 `constexpr` 转换；圆弧保留参数（center + radius + 起止角 + ccw），按需离散化。**算法层**（`arc_tessellate`/`boolean`/`offset`/`triangulate`/`index`/`intersect`/`measure`）：自由函数分派，薄 C++ 接口包装第三方——Clipper2 担布尔（unite/subtract/intersect/xor）与偏移（ClipperOffset）、earcut 担三角剖分、R-tree 自研（STR bulk-load + 邻域查询）；业务层只调 `eda::geometry::*`，永不直接 include Clipper2/earcut。**命令栈与选择层**（`eda/command/`）：`Command` 接口（`execute`/`undo`/`redo`/`merge`）+ `UndoStack`（事务化 macro + 内存上限）+ `SelectionSet<T>`（单选/框选/过滤）；命令继承 P2 的 `Object`，属性变更走 `Variant`，所有编辑器共享同一撤销栈。命名空间 `eda::geometry` 与 `eda::command`，头源同目录，include 从仓库根（`#include "eda/geometry/types.h"`）。

**Tech Stack:** C++20（`-std=c++20`）、CMake ≥ 3.20（FetchContent 拉取 Clipper2 / earcut / GoogleTest）、GoogleTest、Clipper2（布尔 + ClipperOffset）、earcut（mapbox/earcut.hpp，header-only）、自研 R-tree（无 Boost 依赖）。

## Global Constraints

- **继承 P1 全局约束**：语言 C++20（MSVC 19.29+ / GCC 11+）、CMake ≥ 3.20、头源同目录、文件名 `snake_case.h`、类型 `PascalCase`、命名空间 `eda::`（本 plan 子空间 `eda::geometry` / `eda::command`）、成员变量尾下划线 `name_`、枚举值 `SCREAMING_CASE`、include 从仓库根解析、约定式提交、Release/Debug 双配置。
- **坐标基础（P3 特有，D1）**：内部全部用 `int64_t`（别名 `eda::geometry::Coord`），单位 nm（纳毫米）。**禁用浮点坐标参与布尔/求交/索引**——浮点仅作显示、测量中间量、圆弧离散化中间量（`PointF`）。理由：Clipper2 原生 int64 实现零精度损失布尔；nm 量程 ±9.2×10⁹ nm ≈ ±9.2 m，分辨率 0.001μm，覆盖任何板尺寸；万级焊盘 DRC 不会累积浮点误差。
- **单位边界转换**：用户层 mm/mil/inch 仅在 API 边界转换（`units.h` 全 `constexpr`），内部流转一律 nm。
- **值类型优先（D2）**：图元为 POD 结构 + 自由函数，**不搞深继承层次**；缓存友好、序列化简单、万级图元 SOA 友好。圆弧保留参数（D3），不预离散。
- **薄包装原则（D4）**：业务层（`eda/schematic`、`eda/pcb`、`eda/validation` 等）永远只调 `eda::geometry::*`，**永不直接 include Clipper2/earcut**。底层实现可替换而不影响业务。
- **所有几何编辑入命令栈**：编辑器对图元的创建/修改/删除必须经 `eda::command::Command` 落地（原子操作、可撤销）；几何内核的纯查询（measure/intersect/query）无需入栈。
- **命令栈与 P2 对象体系集成**：`Command` 继承 P2 的 `Object`（注册到 ClassDB），属性变更命令复用 `set(String, Variant)`；泛用 `SetPropertyCommand` 适用于绝大多数编辑。
- **复杂度目标（万级图元）**：R-tree 邻域查询目标 < P22 基准阈值（10k 图元）；布尔/偏移/剖分对单多边形顶点数线性对数级；自研 R-tree 须与暴力 O(n²) 查询结果交叉验证一致。
- **范围边界**：本 plan 只做 **2D**（3D 归 `eda/mechanical`，P10）；不做设计规则判定（归 `eda/validation`，P11，geometry 只提供几何事实）；不做渲染（归 P1 Canvas2D，本 plan 输出图元交由它栅格化）；不认业务语义（走线/焊盘/网络归 `eda/pcb`、`eda/schematic`）；不引入贝塞尔样条（YAGNI，PCB 用圆弧、原理图用直线）。
- **第三方白名单**：仅允许 Clipper2、earcut、GoogleTest（经 FetchContent）；**不引入 Boost**（R-tree 自研，避免重依赖）。

- [ ] **Step 3: 实现 types.h**

`eda/geometry/types.h`：

```cpp
#pragma once
#include <cstdint>
#include <vector>
#include <span>
#include <algorithm>
#include <cmath>

namespace eda::geometry {

using Coord = int64_t;                 // 内部单位 nm（D1）

struct Point {                         // 整数点（参与布尔/索引/求交）
    Coord x = 0, y = 0;
    bool operator==(const Point&) const = default;
};

struct PointF {                        // 浮点点（显示/测量/离散化中间量，不参与布尔）
    double x = 0, y = 0;
};

struct Segment { Point a, b; };

// 圆弧（D3）：中心 + 半径 + 起止角（弧度）+ 方向
struct Arc {
    Point center{};
    Coord radius = 0;
    double start_angle = 0.0;
    double end_angle = 0.0;
    bool ccw = true;                   // 逆时针为正
};

// 折线（开路径：导线、走线轮廓、未闭合板框段）
struct Polyline {
    std::vector<Point> points;         // 至少 2 点
};

// 多边形（可含孔：外环 + 内环列表）。环方向约定：外环 CCW，孔 CW
struct Polygon {
    std::vector<Point> outer;
    std::vector<std::vector<Point>> holes;
};

// 带宽路径（走线本质：中心线 + 宽度，渲染/DRC 时偏移成 Polygon）
struct Path {
    std::vector<Point> points;
    Coord width = 0;
};

// 轴对齐包围盒（空间索引用）
struct Box {
    Point min{}, max{};

    static Box from_points(std::span<const Point> pts) {
        Box b;
        if (pts.empty()) return b;
        b.min = b.max = pts[0];
        for (const auto& p : pts) {
            b.min.x = std::min(b.min.x, p.x);
            b.min.y = std::min(b.min.y, p.y);
            b.max.x = std::max(b.max.x, p.x);
            b.max.y = std::max(b.max.y, p.y);
        }
        return b;
    }
    bool intersects(const Box& o) const {
        return !(o.min.x > max.x || o.max.x < min.x ||
                 o.min.y > max.y || o.max.y < min.y);
    }
    bool contains(Point p) const {
        return p.x >= min.x && p.x < max.x && p.y >= min.y && p.y < max.y;
    }
    Box merge(const Box& o) const {
        return Box{
            {std::min(min.x, o.min.x), std::min(min.y, o.min.y)},
            {std::max(max.x, o.max.x), std::max(max.y, o.max.y)}};
    }
};

}  // namespace eda::geometry
```

```cpp
namespace eda::geometry {

// 用户层单位 → 内部 nm（D1）。边界处转换，内部一律 nm。
constexpr Coord mm_to_nm(double mm) { return (Coord)(mm * 1e6); }
constexpr Coord mil_to_nm(double mil) { return (Coord)(mil * 25400.0); }
constexpr Coord inch_to_nm(double in) { return (Coord)(in * 25.4e6); }

// nm → 用户层单位（显示、导出）
constexpr double nm_to_mm(Coord nm) { return (double)nm / 1e6; }
constexpr double nm_to_mil(Coord nm) { return (double)nm / 25400.0; }
constexpr double nm_to_inch(Coord nm) { return (double)nm / 25.4e6; }

}  // namespace eda::geometry
```

```cpp
#include <cmath>

namespace eda::geometry {

enum class MirrorAxis { X, Y, ORIGIN };

// 平移（整数精确）
inline Point translate(Point p, Coord dx, Coord dy) { return {p.x + dx, p.y + dy}; }
inline Polyline translate(const Polyline& pl, Coord dx, Coord dy) {
    Polyline r = pl;
    for (auto& pt : r.points) pt = translate(pt, dx, dy);
    return r;
}
inline Polygon translate(const Polygon& pg, Coord dx, Coord dy) {
    Polygon r = pg;
    for (auto& pt : r.outer) pt = translate(pt, dx, dy);
    for (auto& h : r.holes) for (auto& pt : h) pt = translate(pt, dx, dy);
    return r;
}

// 旋转（浮点中间量，四舍五入回 nm；angle 单位弧度）
inline Point rotate(Point p, double angle_rad, Point center) {
    double c = std::cos(angle_rad), s = std::sin(angle_rad);
    double dx = (double)(p.x - center.x);
    double dy = (double)(p.y - center.y);
    return Point{
        (Coord)std::llround(center.x + dx * c - dy * s),
        (Coord)std::llround(center.y + dx * s + dy * c)};
}

// 镜像（整数精确）
inline Point mirror(Point p, MirrorAxis axis) {
    switch (axis) {
        case MirrorAxis::X:      return { p.x, -p.y};
        case MirrorAxis::Y:      return {-p.x,  p.y};
        case MirrorAxis::ORIGIN: return {-p.x, -p.y};
    }
    return p;
}

// 缩放（以 center 为锚，浮点中间量四舍五入）
inline Point scale(Point p, double sx, double sy, Point center) {
    return Point{
        (Coord)std::llround(center.x + (double)(p.x - center.x) * sx),
        (Coord)std::llround(center.y + (double)(p.y - center.y) * sy)};
}

}  // namespace eda::geometry
```

```cpp
#pragma once
#include "eda/geometry/types.h"
#include <cmath>

namespace eda::geometry {

// 网格吸附：把点拉到最近的栅格交点（grid_nm <= 0 时原样返回）
inline Point snap_to_grid(Point p, Coord grid_nm) {
    if (grid_nm <= 0) return p;
    auto snap1 = [](Coord v, Coord g) -> Coord {
        return (Coord)(std::llround((double)v / (double)g) * (double)g);
    };
    return {snap1(p.x, grid_nm), snap1(p.y, grid_nm)};
}

// 角度吸附（弧度；step_rad <= 0 时原样返回）
inline double snap_angle(double angle_rad, double step_rad) {
    if (step_rad <= 0) return angle_rad;
    return std::round(angle_rad / step_rad) * step_rad;
}

// 点吸附到目标点（容差 nm 内才吸附，否则原样返回）
inline Point snap_point(Point p, Point target, Coord tolerance_nm) {
    Coord dx = p.x - target.x, dy = p.y - target.y;
    if (dx * dx + dy * dy <= tolerance_nm * tolerance_nm) return target;
    return p;
}

}  // namespace eda::geometry
```
