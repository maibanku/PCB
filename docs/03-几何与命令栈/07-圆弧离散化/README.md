# 03-07 圆弧离散化

> 所属 [[03-几何与命令栈]]。将参数化圆弧按误差控制离散为折线（Polyline），作为布尔运算与求交前的统一前置处理（Clipper2 不支持弧）。对应 `geometry-几何内核设计.md` §4 arc_tessellate.h。

## 目标（要实现什么）
- 实现 `eda/geometry/arc_tessellate.{h,cpp}`：`tessellate(Arc, tolerance_nm) -> Polyline`
- 容差策略：默认**弦高容差**（sagitta，nm 级可配，建议默认 1000nm = 1μm）；提供角度容差模式备选（1°~5°）
- 自适应采样：大半径弧按弦高反推角度步长（`Δθ ≈ 2·acos(1 - h/r)`），避免固定步长在小弧过密、大弧过疏
- 端点闭合：折线首尾点严格等于弧的起止点（保证后续布尔/求交边界对齐）
- 方向保留：弧的 ccw 方向传递到 Polyline 顶点顺序
- 输出顶点为整数 nm（`Point`），中间计算用 double（`PointF`）

## 关键点
- **D3 决策已定**：圆弧保留参数，按需离散化（不全程离散化丢精度，不贝塞尔近似过复杂）
- **统一前置**：所有含弧的布尔/求交/三角剖分输入先经本模块离散（在 boolean/intersect 内部自动调用）
- **弦高 vs 角度容差**：弦高对 EDA 视觉/制造更直观（板厂公差以弦高给）；首版默认弦高，角度容差作为备选
- **零精度损失保证**：仅对参与布尔/求交的副本离散，原 `Arc` 参数保留，编辑/测量仍用精确参数

## 输入 / 输出
- **入**：`Arc`（参数：center + radius + 起止角 + ccw）+ 容差（nm）
- **出**：`Polyline`（顶点为整数 nm，首尾严格对齐弧端点）
