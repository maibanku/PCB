# 03-几何与命令栈

> 对应 **Plan P3**（Phase 1 · 引擎内核）。自研 EDA 的几何内核：值类型图元、布尔/偏移/剖分、空间索引、求交测量、圆弧离散化，以及事务化命令栈与选择系统，是原理图/PCB 编辑器的计算基石。

## 定位
- **做什么**：定义 int64/nm 精度的值类型图元（Point/Segment/Arc/Polyline/Polygon/Path/Box）；包装 Clipper2（布尔）、ClipperOffset（偏移）、earcut（剖分）；自研轻量 R-tree 空间索引；实现线/弧求交与长度/面积/距离测量；圆弧参数化→折线离散化；事务化 Undo/Redo 命令栈与选择系统。
- **不做什么**：不依赖上层编辑器语义（不认"元件/网络"，只认图元）；不直接驱动渲染（输出图元交由 P1 Canvas2D）；不实现 DRC/ERC 规则（属 P8/P11）。
- **代码位置**：`eda/geometry, eda/command`（见 [[00-总览/03-项目目录结构]]）
