# 18-扩展生态

> 对应 **Plan P18**（Phase 4 · 生态与协作）。围绕插件、脚本、外部接口与市场分发构建可被第三方持续扩展的生态底座。

## 定位
- **做什么**：提供插件加载/沙箱/权限、内嵌脚本语言、外部程序化访问 API，以及主题/图标/符号库/封装/模板的分发市场，让 EDA 能力可被用户与第三方持续扩展。
- **不做什么**：不直接承载具体垂直领域工具实现（由插件自身完成）；不替代核心引擎的确定性保证。
- **代码位置**：`modules/`（见 [[00-总览/03-项目目录结构]]）

## 子功能清单
| 编号 | 子功能 | 说明 | 状态 |
|------|--------|------|------|
| 01 | [插件系统](01-插件系统/) | GDExtension 思路的插件机制 + 沙箱隔离 + 权限管控 | 待实现 |
| 02 | [脚本支持](02-脚本支持/) | 类 GDScript 内嵌脚本或嵌入 Python，面向自动化与轻量扩展 | 待实现 |
| 03 | [外部API](03-外部API/) | 面向脚本/外部程序的程序化访问接口 | 待实现 |
| 04 | [市场](04-市场/) | 主题/图标/符号/封装/模板的发现与分发 | 待实现 |

## 依赖
- **上游**：P2（引擎与对象模型提供扩展点）、P4（UI 框架提供主题/图标集成）
- **下游**：P19（CLI 依赖脚本与 API 实现无头自动化）、P20（AI 辅助可经脚本/API 介入）
