# 18-04 市场

> 所属 [[18-扩展生态]]。提供主题、图标、符号库、封装库、3D 模型、模板、脚本的发现、安装、更新与发布通道，对标 KiCad PCM 与嘉立创扩展市场。

## 目标（要实现什么）
- 提供市场客户端：分类浏览、搜索、预览、版本选择、一键安装/卸载/更新
- 支持多种资源类型：主题/图标、符号库、封装库、3D 模型、工程模板、脚本/插件包
- 支持多源：官方源、企业私有源（自托管）、社区第三方源，可配置并切换镜像
- 安装走 [[18-扩展生态/01-插件系统]] 的权限/沙箱/签名校验流程，资源类（符号/封装）走依赖锁定与版本绑定
- 提供发布者工具：打包、签名、上传、版本管理、changelog 模板
- 与工程协同：工程可声明依赖的市场资源清单，团队拉取时自动恢复（类包管理器 lock 文件）

## 关键点
- 资源类（库/模板）的版本锁定与 [[05-工程与文件系统]] 的工程依赖管理对齐，保证可复现
- 市场客户端须可离线工作（已安装资源完整可用），在线只用于发现/更新
- 签名与来源校验是默认开启的安全底线，未签名第三方资源需显式用户确认
- 鼓励社区共建：格式适配器、规则集也可上架（与 [[16-格式兼容]]、[[11-校验与DFX]] 联动）

## 输入 / 输出
- **入**：市场源清单、资源包（含 manifest/签名）、工程依赖清单
- **出**：本地安装的资源、版本锁定文件、安装/更新审计日志

## 依赖
- **上游**：[[18-扩展生态/01-插件系统]]（安装/沙箱/签名）、P6（元件库为资源类提供载体）、P5（工程依赖锁定）
- **下游**：终端用户（工程师/创客/企业）、社区发布者
