# 18-02 脚本支持

> 所属 [[18-扩展生态]]。提供类 `GDScript` 思路的内嵌轻量脚本与可选 Python 嵌入，面向自动化、自定义 DRC 规则、批处理与教学场景。

## 目标（要实现什么）
- 提供自研轻量脚本（类 GDScript 思路）绑定核心对象/命令栈，支持在编辑器内即时编写并执行
- 提供可选 CPython 嵌入通道（沙箱化），满足需要 numpy/pandas 等生态的复杂自动化与数据分析
- 暴露完整 API：工程树、图元、ERC/DRC 规则、导出、报告等皆可脚本化驱动
- 支持自定义 DRC/ERC 规则脚本（结合 [[20-AI辅助设计/05-AI设计审查]] 提供 AI 解释）
- 支持批处理脚本（一键改位号、批量替换封装、批量导出多板 Gerber 等），可保存为可重放命令
- 提供脚本编辑器（语法高亮、自动补全、调试断点、API 文档悬浮提示）

## 关键点
- 自研脚本与 Python 双轨：默认安全/可控走自研脚本；需要重生态时显式启用 Python 并加权限边界
- 脚本产生的工程变更必须经命令栈，保持可撤销/可审计，与 Copilot 模式一致
- 脚本执行须有资源配额（CPU/内存/时长），防止恶意/错误脚本卡死主循环

## 输入 / 输出
- **入**：核心 API 绑定、用户脚本、批处理任务清单
- **出**：命令栈操作、自定义规则结果、批处理产物（Gerber/PDF/CSV 等）、脚本执行日志

## 依赖
- **上游**：P2（核心对象/命令栈绑定）、P3（几何/规则引擎 API 暴露）；API 表面与 [[18-扩展生态/03-外部API]] 共用（协作关系，非上下游）
- **下游**：[[20-AI辅助设计]]（AI 可生成/解释脚本）、[[19-工具链CLI/01-无头导出]]（CLI 复用脚本运行时）
