# 18-03 外部API

> 所属 [[18-扩展生态]]。提供面向外部进程/语言的程序化访问接口（IPC + 可选 RPC），让 EDA 可被 CI、第三方工具与企业系统远程驱动。

## 目标（要实现什么）
- 提供进程内 API（C ABI 头文件 + C++ 接口）与进程外 API（本地 IPC：Unix Domain Socket / Named Pipe / WebSocket）双通道
- 覆盖关键能力：打开/保存工程、查询/修改图元、触发 ERC/DRC、导出制造文件、读取 BOM、订阅事件
- 提供事件推送机制（图元变更、规则违反、命令栈提交等），外部可订阅而非轮询
- 提供语言绑定骨架（Python/TypeScript/Go），由社区或市场扩展具体语言 SDK
- 支持鉴权与限流（Token、来源校验、调用配额），与 [[22-工程化与非功能/04-安全]] 一致
- 文档化 API 兼容性策略：语义化版本、废弃流程、changelog 自动生成

## 关键点
- 进程外 API 须序列化稳定，避免内部内存布局变化破坏兼容性（schema 版本化）
- 事件流须支持背压（外部慢消费时不应阻塞主循环）
- 与脚本支持共享同一 API 表面，避免两套维护成本

## 输入 / 输出
- **入**：外部调用请求（命令、查询、订阅）、鉴权凭据
- **出**：JSON/二进制结构化响应、事件流、调用日志与指标

## 依赖
- **上游**：P2（核心对象/命令栈）、P5（工程文件系统）；API 表面与 [[18-扩展生态/02-脚本支持]] 共用（协作关系，非上下游）
- **下游**：[[19-工具链CLI/01-无头导出]]（CLI 可基于 IPC API 实现）、企业 PLM/MES 集成方
