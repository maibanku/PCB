# 17-03 图形化diff

> 所属 [[17-协作与版本]]。设计差异的可视化对比，支持工程树/原理图/PCB 的元素级差异高亮。

## 目标（要实现什么）
- 工程树 diff：可视化对比两个版本（或快照 / Git 提交 / 分支）的工程结构差异，列出新增/删除/修改的文件清单
- 原理图 diff：双视图并排或叠加显示，新增/删除/修改的器件、导线、网络标号、层次块高亮，按网络分组聚合差异
- PCB diff：双视图叠加显示，器件移动（向量箭头）、走线变化（新增/删除线段颜色区分）、铺铜变化、设计规则差异
- 元素级差异：每个对象给出属性级差异（位号、坐标、封装、网络、引脚映射等），可展开/折叠查看
- 差异过滤：按对象类型（器件/走线/网络/库/规则）过滤，聚焦关键变更；按变更类型（新增/删除/修改）筛选
- 与 Git 集成：直接 diff 任意两次 commit / 分支 / 工作区与 HEAD，结果在编辑器内查看并支持 cherrypick

## 关键点
- 文本格式（[[05-工程与文件系统]]）保证可做语义 diff（而非纯文本 diff）；解析 JSON 后按对象 ID 匹配
- 对象匹配策略：UID 精确匹配 > 位号+坐标邻近 > 属性相似度；移动 vs 删除+新增的判定阈值
- PCB diff 的叠加视图：旧版本半透明红色 + 新版本半透明绿色，重叠部分为黑色；移动用箭头，缩放用边框
- 三方合并（merge）：基于 [[17-协作与版本/04-轻量云同步]] 云同步冲突场景，提供三方 diff（base/ours/theirs）与逐项选择 UI
- 性能：万级对象 diff 需增量计算 + 虚拟化列表，避免卡顿

## 输入 / 输出
- **入**：两个工程版本（来自 Git/快照/文件）+ diff 选项（视图模式、过滤规则）
- **出**：差异可视化（双视图/叠加）+ 差异清单 + 属性级详情
