# 17-06 工程包分享

> 所属 [[17-协作与版本]]。将工程及其所有依赖打包为单一文件，支持离线移交工厂或同事。

## 目标（要实现什么）
- 完整工程包导出：将工程 + 所有依赖（库、3D 模型、附件、规则预设、字体）打包为单一文件（`.edapkg` 或 `.zip`），离线可开
- 依赖收集：自动扫描工程引用的所有库（本地 / 在线缓存 / 系统库），打包时一并纳入，避免接收方缺库报错
- 选项化打包：可选是否包含 Gerber/制造输出（[[13-制造输出]]）、历史快照（[[17-协作与版本/01-本地快照]]）、评论数据（[[17-协作与版本/05-评论批注评审]]），控制包大小与内容范围
- 包格式开放：包内为标准 zip + 目录约定 + `manifest.json`（清单与 SHA256 校验），其他工具也可解析
- 校验与签名：包内文件 SHA256 校验保证完整性；可选数字签名（基于 RSA/Ed25519）防篡改，接收方导入时验证
- 工厂移交模式：包可直接移交工厂（含制造数据 + BOM + 装配图 + IPC-2581/ODB++），或移交同事（含可编辑工程），按场景预设打包模板

## 关键点
- 依赖扫描：解析工程树所有引用（库 UID、3D 模型路径、附件链接、规则集引用），递归收集
- 包格式约定：`manifest.json` 列出所有文件 + 类型（工程/库/3D/制造数据/评论）+ SHA256 + 版本；`project.edaproj` 入口
- 去重与压缩：相同内容哈希的文件只存一份（库被多工程引用场景）；zip 压缩 + 可选 LZ4/Zstd 加速
- 工厂移交模板：遵循行业实践（如 Gerber + BOM + Pick&Place + 装配图 PDF 的"四件套"），可对接 [[21-供应链集成]] 下单
- 与 [[17-协作与版本/04-轻量云同步]] 云同步协作：包可上传云端生成分享链接，下载后离线打开

## 输入 / 输出
- **入**：工程 + 打包选项（依赖范围、是否含制造数据/历史/评论、签名密钥）
- **出**：工程包文件（`.edapkg`）+ `manifest.json` + 校验和签名
