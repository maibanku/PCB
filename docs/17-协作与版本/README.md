# 17-协作与版本

> 对应 **Plan P17**（Phase 4 · 生态与协作）。设计版本管理与轻量协作能力。

## 定位
- **做什么**：提供本地快照、Git 集成、图形化 diff、轻量云同步、评论批注评审与工程包分享等协作与版本能力。
- **不做什么**：**MVP 不做实时多人协同**，仅提供 Git + 云同步为主的异步协作；实时协同编辑留待后续阶段评估。
- **代码位置**：`eda/collaboration`（见 [[00-总览/03-项目目录结构]]）

| 编号 | 子功能 | 说明 | 状态 |
|------|--------|------|------|
| 01 | [本地快照](01-本地快照/) | 设计快照保存与回溯 | 待实现 |
| 02 | [Git集成](02-Git集成/) | 版本控制集成 | 待实现 |
| 03 | [图形化diff](03-图形化diff/) | 设计差异可视化 | 待实现 |
| 04 | [轻量云同步](04-轻量云同步/) | 跨设备同步 | 待实现 |
| 05 | [评论批注评审](05-评论批注评审/) | 设计评审协作 | 待实现 |
| 06 | [工程包分享](06-工程包分享/) | 工程包导出分享 | 待实现 |

## 依赖

- **下游**：协作产出的快照/diff/包可供导入或回溯
