# 11-03 电气网络分析

> 所属 [[11-校验与DFX]]。在网络/连通性层面做电气分析：断开、悬空、短路、多驱动、电源地完整性等 ERC 之外的深一层校验。

## 目标（要实现什么）
- 连通性分析：每条网络是否完整连通（基于并查集 + 几何连通），断裂处标出断点位置。
- 悬空检测：悬空引脚（未连接 pin）、悬空网络（仅一端）、孤岛铜皮。
- 短路检测：不同网络间意外连通（铜皮溢出、铺铜桥接），含 PCB 与原理图双向交叉验证。
- 多驱动冲突：同一网络多个输出驱动（如两个 push-pull 输出），标注电气冲突。
- 电源/地完整性基础：电源网络是否单点/多点接地、地去耦电容挂载点检查（去耦电容数量/位置）。
- 网络类约束验证：高速网络类（如 `HS_DIFF`）的特殊规则（差分对耦合、长度匹配）合规。
- 层次化展开：层次块/子图的层次网络展开为扁平网络后做上述分析（与 P7 层次化一致）。
- 网络拓扑可视化：以图视图展示网络拓扑（节点 = pin，边 = 连线），辅助排查。

## 关键点
- **图算法**：连通性走 DFS/并查集；多驱动/短路用图着色或集合运算；大型网络（万 Pin）需稀疏图 + 增量更新。
- **与 ERC 边界**：ERC（P7）管"画图语法级"（如电源标号冲突），本模块管"网络语义级"（如连通/拓扑）。
- **铺铜桥接**：动态铺铜后短路是高频 bug，必须铺铜重建后重跑。

## 输入 / 输出
- **入**：P7 网表、P8 PCB 连通图（含铺铜/过孔）、网络类定义。
- **出**：电气违例清单（断点/短路位置/冲突网络）、网络拓扑图、统计（网络数/连通率）。
