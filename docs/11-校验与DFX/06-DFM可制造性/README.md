# 11-06 DFM 可制造性

> 所属 [[11-校验与DFX]]。检查设计是否满足 PCB 制造（光绘/蚀刻/钻孔/阻焊/丝印）工艺约束，避免到工厂才被打回。

## 目标（要实现什么）
- 最小线宽/间距：按层（外/内层）、按网络类检查，低于工厂能力即报错（如嘉立创外层最小 5mil）。
- 阻焊桥检查：相邻焊盘间阻焊桥最小宽度（避免连锡），含 BGA 焊盘阻焊设计。
- 丝印上焊盘：丝印覆盖 SMD 焊盘（影响焊接），含位号/极性点。
- 孤立焊盘/铜皮：无连接的孤立焊盘、易脱落的孤立铜皮（热应力）。
- 钻孔检查：最小孔径、孔环（annular ring）宽度、孔间距、盲埋孔叠孔规则。
- 阻焊/丝印覆盖：阻焊开窗是否覆盖所有需要焊接的焊盘，丝印是否出板框。
- 板边间距：器件/走线距板边/V-cut 最小间距。
- 拼板工艺：V-cut 槽宽/剩余连接、邮票孔阵列、工艺边宽度（与 P13 拼板联动）。

## 关键点
- **工厂能力驱动**：阈值不是硬编码，由 11-05 规则集（绑定工厂）注入，换工厂即换阈值。
- **与 DRC 分工**：DRC（P8）管电气/几何间距合规，DFM 管"造得出"——如阻焊桥属 DFM 而非纯 DRC。
- **建议而非阻断**：部分 DFM 问题是"建议优化"（如丝印上焊盘可焊但难看），分 error vs warning。

## 输入 / 输出
- **入**：P8 PCB 版图（线宽/间距/阻焊/丝印/钻孔）、11-05 工厂规则集。
- **出**：DFM 违例清单（位置/工艺项/严重度），供 11-04 面板、11-09 报告。

## 依赖
- **上游**：P8（PCB 几何/层/钻孔）、11-05（工厂规则集）、P13（拼板几何，运行时注入）。
- **下游**：11-04（面板）、11-09（DFX 报告）。（"制造前检查预演"属 P13 自身前置检查，非 P11 下游，避免 P11↔P13 循环。）
