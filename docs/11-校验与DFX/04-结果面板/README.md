# 11-04 结果面板

> 所属 [[11-校验与DFX]]。统一展示 11-01 校验中心的所有违例，支持分级、定位、忽略、批修建议，是工程师修复问题的主交互界面。

## 目标（要实现什么）
- 分级显示：Error / Warning / Info 三级，颜色与图标区分（与 dataviz 主题色对齐）。
- 分类筛选：按规则类（ERC/DRC/DFM/...）、按网络/位号/层/规则名过滤，支持保存视图。
- 定位跳转：双击违例 → 跳转原理图/PCB 对应位置并放大高亮（含 3D 视图，与 10-01 联动）。
- 忽略/批准：单条或批量忽略（带原因注释、可撤销），忽略项随工程保存，重跑不再报。
- 批量修复建议：常见问题（重复位号、缺去耦、丝印上焊盘）给"一键批修"按钮（入命令栈可撤销）。
- 统计面板：饼图/趋势图（按类/按严重度），支持历次运行对比（参考 dataviz 可视化）。
- 导出：违例清单 CSV/HTML/PDF（与 11-09 DFX 报告分工：本面板是交互，报告是交付）。

## 关键点
- **大列表性能**：万级违例走虚拟列表（参考 Godot `ItemList` virtualized），仅渲染可见行。
- **跳转精度**：违例位置可能是"两焊盘间距"等关系型，跳转时同时高亮双方对象。
- **忽略的版本化**：忽略项入工程 JSON，Git 可见，避免"忽略丢失重跑被骂"。

## 输入 / 输出
- **入**：11-01 / 11-03 / 11-06~08 的违例流、用户过滤/忽略/修复操作。
- **出**：用户修复（命令栈操作）、忽略项（工程配置）、导出文件。

## 依赖
- **上游**：11-01（违例流）、11-03/06/07/08（各域违例）。
- **下游**：用户（工程师修复）、11-09（报告引用统计）。
