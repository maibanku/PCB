# 11-05 规则集预设

> 所属 [[11-校验与DFX]]。内置按工厂能力/板型分类的标准规则集预设，开箱即用并支持派生、对比与云分享。

## 目标（要实现什么）
- 内置工厂预设：嘉立创（JLC）/ 华秋 / 鼎纪 / Seeed / 默认通用，每套对应不同最小线宽/间距/孔径等工艺能力。
- 按**板型**预设：标准多层板 / HDI / 柔性 FPC / 刚挠结合 / 高频板（罗杰斯）等。
- 按**工艺**预设：回流焊 / 波峰焊 / SMT / THT 混装，影响 DFA 规则集。
- 用户自定义：基于预设派生，重命名/修改/锁定，存为工程级或库级规则集。
- 规则集合并与差异对比：图形化 diff（某规则值差异高亮），便于评审。
- 云同步与分享：团队/社区分享规则集（借鉴 F1 协作策略，非实时）。
- 版本化：规则集带版本号，工程绑定特定版本保证可复现。

## 关键点
- **工厂能力直连**：与 E2 供应链集成打通（E2=P21 上线后；MVP 用内置静态工厂能力表）——选定工厂时自动应用其规则集（蓝图 E2 关键设计：设计阶段可见可造性）。
- **不锁定**：预设可被用户覆盖，但给"偏离工厂默认"告警（如线宽低于工厂能力 0.1mm 时提示）。
- **冲突解决**：多规则集叠加时优先级明确（工厂预设 > 板型预设 > 用户规则），冲突给提示。

## 输入 / 输出
- **入**：内置预设库、内置工厂能力数据（MVP；E2 上线后接入供应链实时数据）、用户派生操作。
- **出**：激活的规则集（注入 11-01）、规则差异报告、分享包（文件）。

## 依赖
- **上游**：11-02（自定义规则并入集）。（E2 供应链工厂能力为后置打通：MVP 内置静态工厂能力表；E2=P21 属 Phase 5，上线后联动。）
- **下游**：11-01（执行）、F1（云同步/分享）。
