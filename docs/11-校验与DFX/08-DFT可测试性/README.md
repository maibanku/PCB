# 11-08 DFT 可测试性

> 所属 [[11-校验与DFX]]。检查测试点覆盖率与可达性，适配 ICT/FCT 夹具与探针。MVP 阶段仅基础测试点能力，是相对 KiCad/嘉立创的补强差异化点。

## 目标（要实现什么）
- **MVP 基础**：测试点覆盖率统计（按网络/按节点），列出缺测试点的关键网络（电源/地/关键信号）。
- 测试点放置工具：在 PCB 上放置/编辑测试点（焊盘/过孔型），自动吸附到网络。
- 测试点可达性：单板正面/反面可达分类，器件遮挡判断（与 10-03 干涉数据联动）。
- ICT/FCT 夹具适配：测试点网格间距（如 100mil 标准网格）、夹具避让区、探针行程。
- 探针可达性：器件 3D 高度包络 vs 探针入射方向，避免探头撞器件。
- 测试点间距：相邻测试点最小间距（夹具网格约束）。
- 缺测试点网络提示：未覆盖网络清单 + 建议位置（候选焊盘/过孔），支持一键批量添加。
- 报告：覆盖率百分比、夹具适配表（与 11-09 DFX 报告对接）。

## 关键点
- **MVP 边界**：本域明确 MVP 仅做覆盖率 + 基础可达性，夹具自动生成/探针路径规划留二期（与域根"不做什么"一致）。
- **与 DFM/DFA 区别**：DFT 关注"测得到"，独立于 DFM/DFA 但共享器件 3D / 干涉数据。
- **夹具网格**：传统 ICT 夹具受网格限制（100mil/75mil），现代飞针（flying probe）灵活，规则需可选。

## 输入 / 输出
- **入**：P8 PCB 测试点位置/网络、10-03 干涉（遮挡）、11-05 测试规则集。
- **出**：覆盖率统计、缺测试点网络清单、夹具适配违例（供 11-04 / 11-09）。

## 依赖
- **上游**：P8（测试点焊盘/过孔）、11-05（测试规则）。（10-03 遮挡判断属 P10=Phase 3，MVP 用 2D 器件 footprint 近似，3D 遮挡待 P10 落地后接入。）
- **下游**：11-04（面板）、11-09（DFX 报告）。
