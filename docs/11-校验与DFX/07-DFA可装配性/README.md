# 11-07 DFA 可装配性

> 所属 [[11-校验与DFX]]。检查设计是否满足 SMT/THT 装配工艺约束（器件间距/方向/重量/工艺适配），并消费 10-03 几何干涉结果（MVP 用 2D courtyard/包络盒近似，3D 干涉待 P10 落地后接入）。

## 目标（要实现什么）
- 器件间距：SMD/SMD、SMD/THT 最小间距（贴片机吸嘴/视觉识别需求），按器件类型分级。
- 极性方向一致性：IC1/极性器件方向标记、缺极性点告警；同向器件布局便于贴片。
- 器件重量/尺寸：重型器件（如大电感、变压器）布局位置与固定方式，避免波峰焊掉件。
- 波峰焊/回流适配：THT 侧器件方向（轴向/径向）、工艺边、胶合点；双面 SMT 第二面布局。
- 异型器件处理：连接器、屏蔽罩、纽扣电池座的特殊装配约束（如手工插装预留空间）。
- 器件高度集中区：与 10-05 高度限制区联动，高度超界器件汇总为 DFA 问题。
- 装配顺序建议：基于器件高度/类型的合理贴装顺序（先小后大、先 SMT 后 THT）。
- 消费 10-03 干涉结果：器件-器件/器件-外壳几何干涉作为 DFA 严重违例。

## 关键点
- **与 DFM 分工**：DFM 管"板子造得出"，DFA 管"器件装得上"——两者互补，部分有交集（如器件间距）。
- **工艺驱动**：回流 vs 波峰 vs 混装规则差异大，规则集需绑定装配工艺（与 11-05 联动）。
- **几何与电气协同**：DFA 问题常需 10-03 干涉 + P8 器件属性（高度/类型）联合判断。

## 输入 / 输出
- **入**：P8 器件位姿/类型/高度、10-03 干涉结果、10-05 高度区、11-05 装配规则集。
- **出**：DFA 违例清单（含几何干涉/工艺违例）、装配顺序建议。

## 依赖
- **上游**：P8（器件属性/courtyard）、11-05（装配规则）、10-05（高度区）。（10-03 几何干涉属 P10=Phase 3，MVP 阶段用 2D courtyard/包络盒做装配间距检查，3D 干涉结果待 P10 落地后接入。）
- **下游**：11-04（面板）、11-09（DFX 报告）。
