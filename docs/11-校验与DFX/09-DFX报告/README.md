# 11-09 DFX 报告

> 所属 [[11-校验与DFX]]。汇总 DFM/DFA/DFT 与 ERC/DRC/一致性结果，输出可交付的 DFX 综合报告，含风险评分与改进建议。

## 目标（要实现什么）
- 综合报告：整合 DFM + DFA + DFT + ERC + DRC + 一致性的违例清单（统一 schema），按严重度/分类聚合。
- 风险评分：基于违例数量与严重度加权计算"可生产性评分"（0-100），分级（绿/黄/红）。
- 改进建议：基于规则库为常见违例给出修复建议（如"3 处丝印上焊盘，建议批量移动丝印"）。
- 多格式输出：PDF（含图表）、HTML（交互）、CSV（机读，供工厂系统导入）。
- 与工厂对接：报告可发送给供应链（E2）做"可制造性预确认"，工厂返回意见回填。
- 历史趋势：历次设计/历次校验结果对比（如"本次 DFM 违例比上次减少 40%"），支持 dataviz 趋势图。
- 报告模板：可自定义模板（公司 logo、章节顺序、字段选择），保存复用。
- 摘要页：单页概览（评分/关键指标/红灯项），便于管理层快速决策。

## 关键点
- **交互 vs 交付分工**：11-04 面板是工程师修复交互，本报告是对外（工厂/管理层/客户）的正式交付物。
- **评分模型透明**：评分公式公开可调（用户/企业可自定义权重），避免"黑盒分数"不信任。
- **可复现**：报告内容快照随工程版本锁定，便于追溯（哪一版设计存在哪些问题）。

## 输入 / 输出
- **入**：11-01 / 11-03 / 11-06 / 11-07 / 11-08 的违例数据、用户模板。
- **出**：DFX 综合报告（PDF/HTML/CSV）、风险评分、改进建议清单。
