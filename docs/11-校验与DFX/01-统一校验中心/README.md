# 11-01 统一校验中心

> 所属 [[11-校验与DFX]]。整合 ERC（原理图）、DRC（PCB）、一致性检查（原理图 ↔ PCB）与 DFX 体系为单一入口与统一结果流，是 MVP 可生产闭环的校验收口。

## 目标（要实现什么）
- 统一执行入口：一键运行全部已启用规则（ERC + DRC + 一致性 + DFM/DFA/DFT），进度可见、可取消。
- 规则分类标签：电气（ERC）/ 几何（DRC）/ 一致性 / 制造（DFM）/ 装配（DFA）/ 测试（DFT），可按类开关。
- 增量校验：监听命令栈变更，仅对受影响对象重算（参考 Godot dirty 标记 + 信号传播）。
- 双模式：实时（轻量、即时显示）与全板（完整、批量），用户按需切换。
- 规则引擎抽象：规则插件化（C++ 规则 + 11-02 自定义脚本规则），统一接口 `IRule::check(context)`。
- 与 P7 / P8 集成：直接消费现有 ERC / DRC 实现，不重复造轮子，做"汇总者"而非"实现者"。
- 校验配置入工程：规则启用/参数/忽略项随工程保存，Git diff 可见。

## 关键点
- **一致性检查是核心**：原理图与 PCB 脱节（多/缺器件、位号不符、封装不匹配）是改板主因，必须做透（对标 Altium ECO）。
- **去重与归并**：同一问题被多条规则触发时归并为一条，避免结果面板噪声。
- **性能**：万 Pin 级 DRC 走空间索引（P3 几何引擎 R-tree/四叉树），全板校验目标秒级。

## 输入 / 输出
- **入**：P7 原理图/网表、P8 PCB 版图/设计规则、11-05 规则集、11-02 自定义规则。
- **出**：统一违例流（带分类/定位/严重度），供 11-04 面板展示、11-09 报告汇总。

## 依赖
- **上游**：P7（ERC 基础）、P8（DRC 几何/规则）、11-02（自定义规则）、11-05（规则集）。
- **下游**：11-04（结果面板）、11-09（DFX 报告）、F4（CLI 无头运行，CI/CD）。
