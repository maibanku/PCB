# 11-校验与DFX

> 对应 **Plan P11**（Phase 2 · MVP 闭环）。统一校验中心 + DFX 体系，一站式覆盖 ERC、DRC、一致性检查与可制造/可装配/可测试性分析，是 MVP 可生产闭环的关键收口环节。

## 定位
- **做什么**：统一校验中心（ERC + DRC + 一致性检查）；自定义规则语言（脚本化）；电气网络分析；分级结果面板（定位/忽略/批修建议）；规则集预设；DFM 可制造性、DFA 可装配性、DFT 可测试性（MVP 仅基础测试点）；DFX 综合报告。
- **不做什么**：不做 SI/PI 高速完整性分析（属 P12）；不做热/EMC 仿真；不做良率统计分析；DFT 在 MVP 阶段仅保留基础测试点能力。
- **代码位置**：`eda/validation`（见 [[00-总览/03-项目目录结构]]）
