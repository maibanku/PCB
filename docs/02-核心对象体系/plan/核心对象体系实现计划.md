# 核心对象体系实现计划（Core Object System）

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 按任务逐个实现。步骤使用 `- [ ]` 复选框跟踪；**Task 1 已展开为完整 TDD**，Task 2..6 为骨架占位，进入对应任务时按 Task 1 的详细度展开。

**Goal:** 在 P1 地基之上落地自研 EDA 引擎的运行时类型系统——Object 基类 + 引用计数 + ClassDB 反射 + Variant 动态类型 + Signal 信号槽 + Resource 资源系统 + Node/SceneTree 节点树，最终产出"所有业务对象继承 Object、能注册/查询/按名调用、Signal 析构解绑无悬空、Resource 可 .tres 文本往返、SceneTree 能挂/卸节点并分发 notification/process"的可执行内核。

**Architecture:** 完全对齐 Godot 的对象-反射-Variant-Signal-Resource-Node 体系，落在 P1 已定的 `core/` 与 `scene/` 层下：

| 本计划组件 | 文件位置 | 对齐 Godot | 职责 |
|------------|----------|-----------|------|
| Object 基类 | `core/object/object.{h,cpp}` | `core/object.{h,cpp}` | 所有业务对象根基类：`notification` 生命周期、`set/get` 属性、`set_meta/get_meta` 元数据 |
| RefCounted | `core/object/ref_counted.{h,cpp}` | `core/ref_counted.{h,cpp}` | 引用计数派生；`Ref<T>` 智能指针 |
| ClassDB | `core/object/class_db.{h,cpp}` | `core/class_db.{h,cpp}` | 运行时反射数据库：`GDREGISTER_CLASS` / `bind_method` / `bind_property` / `call` / `instantiate` |
| Variant | `core/variant/variant.{h,cpp}` | `core/variant.{h,cpp}` | tagged union 值载体（NIL/BOOL/INT/FLOAT/STRING/OBJECT，Task 3 扩 ARRAY/DICTIONARY/VECTOR2/COLOR） |
| Signal | `core/object/signal.{h,cpp}` | `core/object/signal.{h,cpp}` | `connect`/`emit`/`disconnect` 观察者；`Callable` 类型擦除 |
| Resource | `core/object/resource.{h,cpp}` | `core/resource.{h,cpp}` | `RefCounted` 派生；`res://` 路径；`ResourceLoader`/`Saver` |
| OS 抽象 | `core/os/os.{h,cpp}` | `core/os/os.{h,cpp}` | 目录/时间/日志最小占位（资源根解析、`OS::get_singleton()`） |
| Node | `scene/main/node.{h,cpp}` | `scene/main/node.{h,cpp}` | `Object` 派生；父子树；`_enter_tree`/`_ready`/`_process`/`_exit_tree` |
| SceneTree | `scene/main/scene_tree.{h,cpp}` | `scene/main/scene_tree.{h,cpp}` | 持有 root；`process(delta)` / `input(event)` 驱动整树 |

**分层依赖（自下而上）**：Variant ↔ Object（最小 Variant 在 Task 1 内联，Task 3 扩展）；ClassDB 依赖 Object + Variant；Signal 依赖 Object（生命周期反向解绑）；Resource 依赖 RefCounted + ClassDB + Variant；Node/SceneTree 依赖 Object + Signal + P1 的主循环与 InputState。`core/os/os.h` 提供 `OS::get_resource_root()` 给 Resource 解析 `res://`。

**Tech Stack:** C++20、CMake ≥ 3.20、GoogleTest（全部继承自 P1）。本计划不引入新第三方依赖。

## Global Constraints

继承 P1 全部约束（见 [[01-引擎地基/plan/引擎地基实现计划]] 的 Global Constraints），并补充 P2 特有条款：

**继承自 P1：**
- **语言**：C++20（`-std=c++20`），MSVC 19.29+ 或 GCC 11+；禁用异常与 RTTI 在引擎核心路径（`-fno-exceptions -fno-rtti`，GoogleTest 子项目独立配置）
- **构建**：CMake ≥ 3.20，复用 P1 顶层 `CMakeLists.txt` 的 FetchContent（GoogleTest）与 `eda::` target 命名
- **目录/命名（对齐 Godot）**：头源同目录、`snake_case.h`、`PascalCase` 类型、`eda::` 命名空间、成员变量尾下划线 `name_`、枚举值 `SCREAMING_CASE`、include 从仓库根
- **代码仓库**：`d:\file\obsibian\个人知识库\项目资料\pcb\eda-engine`（P1 Task 1 已创建）
- **测试**：纯逻辑（Object/RefCounted/Variant/ClassDB/Signal/Resource/Node）用 GoogleTest 单元测试；不依赖 GPU/窗口
- **提交**：约定式提交（`feat:` / `fix:` / `test:` / `docs:` / `chore:`），每个任务结束提交一次

**P2 特有（新增）：**

- **不依赖 RTTI / `dynamic_cast`**：禁用编译器 RTTI；所有向下转换走 `cast_to<T>()`（基于 ClassDB 父类链字符串比较）或编译期已知类型直接 `static_cast`。理由：跨 dynamic library 边界安全（为 F2 插件铺路），且与 Godot 一致
- **反射走 ClassDB 字符串比较**：`is_class(name)` / `cast_to<T>()` 全部基于类名字符串与父类链，绝不使用 `typeid` / `dynamic_cast`
- **引用计数可选**：`Object` 默认手动管理（生命周期由所有者负责，如 SceneTree 持有 Node）；只有 `RefCounted` 派生类才走自动引用计数。`Node` 不继承 `RefCounted`（挂树期间由 SceneTree 持有），`Resource` 继承 `RefCounted`（多对象共享）
- **Variant 错误模型**：类型不匹配的取值不抛异常（引擎核心禁用异常），返回零值/默认值并打日志（日志接入在 `core/os/` 落地后）
- **大对象走指针**：Variant 内部的 `STRING`/`ARRAY`/`DICTIONARY` 在 Task 3 扩展时使用引用计数共享存储（COW 或不可变共享），避免拷贝昂贵；Task 1 的最小 Variant 仅含标量与 `Object*`，无此问题
- **线程模型**：ClassDB 注册阶段在 main 启动单线程完成，运行期只读、无锁查询；Signal 的 connect/disconnect 在主线程完成，emit 重入用快照保护
- **范围边界**：本计划不实现几何/命令栈（属 P3）、不实现 GUI 控件（属 P4）、不实现工程树/IO（属 P5）；Node 仅提供基础树与生命周期，不绑定 Canvas2D 绘制（绘制由 P3/P4 业务节点自驱）

```cpp
class SpyObject : public Object {
public:

class SpyRefCounted : public RefCounted {
public:
    static inline int alive = 0;
    static inline int predelete_calls = 0;
    SpyRefCounted() { ++alive; }
    ~SpyRefCounted() override { --alive; }
    void notification(int what) override {
```

```cpp
#pragma once
#include <cstdint>
#include <string>
#include <variant>

namespace eda {

class Object;  // 前向声明，避免循环

// Variant（Task 1 子集）：承载 P2 核心标量与 Object*。
// Task 3 扩展：ARRAY / DICTIONARY / VECTOR2 / COLOR + Variant::call + JSON 往返。
class Variant {
public:
    enum Type {
        NIL,
        BOOL,
        INT,      // int64_t
        FLOAT,    // double
        STRING,   // std::string
        OBJECT,   // Object*
        // Task 3 待扩展：ARRAY, DICTIONARY, VECTOR2, COLOR
    };

    Variant() : type_(NIL), value_(std::monostate{}) {}
    explicit Variant(bool v) : type_(BOOL), value_(v) {}
    explicit Variant(int64_t v) : type_(INT), value_(v) {}
    explicit Variant(double v) : type_(FLOAT), value_(v) {}
    explicit Variant(const char* v) : type_(STRING), value_(std::string(v)) {}
    explicit Variant(const std::string& v) : type_(STRING), value_(v) {}
    explicit Variant(Object* v) : type_(OBJECT), value_(v) {}

    Type get_type() const { return type_; }
    bool is_nil() const { return type_ == NIL; }

    // 类型不匹配返回零值/默认值（引擎禁用异常，Task 3 接入日志后打 warning）
    bool as_bool() const;
    int64_t as_int() const;
    double as_float() const;
    std::string as_string() const;
    Object* as_object() const;

private:
    Type type_;
    std::variant<std::monostate, bool, int64_t, double, std::string, Object*> value_;
};

}  // namespace eda
```

`core/variant/variant.cpp`（**不**包含 `object.h`，避免循环；`as_object` 仅返回指针无需完整定义）：

```cpp
#include "variant.h"
#include <stdexcept>

namespace eda {

bool Variant::as_bool() const {
    switch (type_) {
        case BOOL:   return std::get<bool>(value_);
        case INT:    return std::get<int64_t>(value_) != 0;
        case FLOAT:  return std::get<double>(value_) != 0.0;
        case STRING: return !std::get<std::string>(value_).empty();
        default:     return false;
    }
}

int64_t Variant::as_int() const {
    switch (type_) {
        case INT:    return std::get<int64_t>(value_);
        case FLOAT:  return static_cast<int64_t>(std::get<double>(value_));
        case BOOL:   return std::get<bool>(value_) ? 1 : 0;
        case STRING: {
            try { return std::stoll(std::get<std::string>(value_)); }
            catch (...) { return 0; }
        }
        default:     return 0;
    }
}

double Variant::as_float() const {
    switch (type_) {
        case FLOAT:  return std::get<double>(value_);
        case INT:    return static_cast<double>(std::get<int64_t>(value_));
        case BOOL:   return std::get<bool>(value_) ? 1.0 : 0.0;
        case STRING: {
            try { return std::stod(std::get<std::string>(value_)); }
            catch (...) { return 0.0; }
        }
        default:     return 0.0;
    }
}

std::string Variant::as_string() const {
    switch (type_) {
        case STRING: return std::get<std::string>(value_);
        case INT:    return std::to_string(std::get<int64_t>(value_));
        case FLOAT:  return std::to_string(std::get<double>(value_));
        case BOOL:   return std::get<bool>(value_) ? "true" : "false";
        default:     return std::string();
    }
}

Object* Variant::as_object() const {
    return type_ == OBJECT ? std::get<Object*>(value_) : nullptr;
}
```

```cpp
#pragma once
#include "core/object/object.h"
#include <atomic>

namespace eda {

// RefCounted —— 引用计数对象（对齐 Godot RefCounted）。
// 引用计数可选：Object 默认手动管理；只有继承 RefCounted 才自动管理。
class RefCounted : public Object {
public:
    static std::string get_class_static() { return "RefCounted"; }
    std::string get_class() const override { return "RefCounted"; }
    bool is_class(const std::string& name) const override {
        return name == "RefCounted" || Object::is_class(name);
    }

    // 引用计数操作。ref 必须配对 unref。
    void ref() { ref_count_.fetch_add(1, std::memory_order_relaxed); }

    // unref：refcount 减 1。归零时：先发 NOTIFICATION_PREDELETE（对象仍存活），
    //        再 delete this。返回 true 表示对象已被销毁，调用方不得再访问。
    bool unref();

    int get_reference_count() const {
        return ref_count_.load(std::memory_order_relaxed);
    }

protected:
    RefCounted() = default;
    ~RefCounted() override = default;

private:
    std::atomic<int> ref_count_{0};
};

}  // namespace eda
```

```cpp
#include "ref_counted.h"

namespace eda {

bool RefCounted::unref() {
    int prev = ref_count_.fetch_sub(1, std::memory_order_acq_rel);
    if (prev <= 1) {
        // refcount 归零：在析构前给对象一次"收到 PREDELETE"的机会
        notification(NOTIFICATION_PREDELETE);
        delete this;
        return true;
    }
    return false;
}
```

```cpp
#pragma once
#include "core/object/ref_counted.h"
#include <type_traits>
#include <utility>

namespace eda {

// Ref<T> —— 引用计数智能指针（对齐 Godot Ref<T>）。
// 要求 T 派生自 RefCounted。拷贝增计数，析构减计数，归零自动销毁。
template <typename T>
class Ref {
    static_assert(std::is_base_of_v<RefCounted, T>,
                  "Ref<T> requires T to derive from eda::RefCounted");
public:
    Ref() = default;
    explicit Ref(T* p) : ptr_(p) { if (ptr_) ptr_->ref(); }
    Ref(const Ref& o) : ptr_(o.ptr_) { if (ptr_) ptr_->ref(); }
    Ref(Ref&& o) noexcept : ptr_(o.ptr_) { o.ptr_ = nullptr; }

    // 上转：Ref<Derived> -> Ref<Base>
    template <typename U, typename = std::enable_if_t<std::is_base_of_v<T, U>>>
    Ref(const Ref<U>& o) : ptr_(o.get()) { if (ptr_) ptr_->ref(); }

    ~Ref() { reset(); }

    Ref& operator=(const Ref& o) {
        if (this != &o && ptr_ != o.ptr_) {
            if (ptr_) ptr_->unref();
            ptr_ = o.ptr_;
            if (ptr_) ptr_->ref();
        }
        return *this;
    }
    Ref& operator=(Ref&& o) noexcept {
        if (this != &o) {
            if (ptr_) ptr_->unref();
            ptr_ = o.ptr_;
            o.ptr_ = nullptr;
        }
        return *this;
    }
    Ref& operator=(T* p) {
        if (ptr_ != p) {
            if (ptr_) ptr_->unref();
            ptr_ = p;
            if (ptr_) ptr_->ref();
        }
        return *this;
    }

    void reset() {
        if (ptr_) { ptr_->unref(); ptr_ = nullptr; }
    }

    T* get() const { return ptr_; }
    T* operator->() const { return ptr_; }
    T& operator*() const { return *ptr_; }
    bool valid() const { return ptr_ != nullptr; }
    explicit operator bool() const { return ptr_ != nullptr; }

    bool operator==(const Ref& o) const { return ptr_ == o.ptr_; }
    bool operator!=(const Ref& o) const { return ptr_ != o.ptr_; }
    bool operator==(T* p) const { return ptr_ == p; }
    bool operator!=(T* p) const { return ptr_ != p; }

private:
    T* ptr_ = nullptr;
    template <typename U> friend class Ref;
};

}  // namespace eda
```

## 验收标准（Definition of Done）

P2 视为完成，当且仅当以下全部条件满足（每条可独立测试）：

### 类型体系

- [ ] **所有业务对象继承 `Object`**：Node、Resource 以及任意自定义 EDA 类型均 `public Object`；通过 `is_class("Object")` 为真验证
- [ ] **`get_class` / `is_class` 走字符串**：禁用 RTTI（`-fno-rtti` 编译通过）；类型识别完全基于类名字符串与 ClassDB 父类链
- [ ] **`cast_to<T>` 替代 `dynamic_cast`**：源码全量检索无 `dynamic_cast`（GoogleTest 子项目除外）

### 引用计数

- [ ] **`RefCounted` 引用计数归零自动销毁**：`Ref<T>` 拷贝增计数、析构减计数；归零时发 `NOTIFICATION_PREDELETE` 再 `delete this`
- [ ] **无悬空 Ref**：所有 `Ref<T>` 出作用域后 `get_reference_count()` 归零，`alive` 计数验证无泄漏
- [ ] **Node 不走引用计数**：Node 继承 Object 而非 RefCounted，挂树期间由 SceneTree 管理生命周期（验证 Node 不在 Ref<T> 中持有）

### ClassDB

- [ ] **`GDREGISTER_CLASS` 能注册类型**：注册后 `ClassDB::is_parent_class(T, Object)` 为真
- [ ] **`instantiate` 按类名构造**：`ClassDB::instantiate("Foo")` 返回 `Foo` 实例，`get_class() == "Foo"`
- [ ] **`call` 按名调用方法**：`ClassDB::call(obj, "bar", args)` 正确分派到 `Foo::bar`
- [ ] **`bind_property` 后 `Object::set/get` 生效**：注册属性后 `obj.set("p", Variant(1))` 返回 true，`obj.get("p").as_int() == 1`
- [ ] **`get_property_list / get_method_list` 可枚举**：返回值包含已注册条目，供 Inspector 使用

### Variant

- [ ] **覆盖 NIL/BOOL/INT/FLOAT/STRING/OBJECT/ARRAY/DICTIONARY/VECTOR2/COLOR**：每种类型可构造、可取值、可 `get_type` 识别
- [ ] **隐式转换矩阵**：`int ↔ float ↔ string` 双向往返误差在 1e-6 内；类型不匹配返回零值（无异常抛出）
- [ ] **JSON 往返**：`Variant::from_json(v.to_json()) == v` 对标量与集合类型成立
- [ ] **`Variant::call`**：持有 `Object*` 时调 `ClassDB::call`；持有非 Object 时返回 NIL

### Signal

- [ ] **`connect` / `emit` / `disconnect` 三件套可用**：emit 触发所有连接的 Callable
- [ ] **析构解绑无悬空**：`Object` 析构后，之前 connect 到它的 Signal 不再持有该对象引用；再次 emit 不崩溃（核心难点，需双向引用清理）
- [ ] **重入安全**：emit 回调中 connect/disconnect 同一 Signal 不导致迭代器失效（快照保护）
- [ ] **deferred 队列**：`ConnectFlags::DEFERRED` 入队，由 SceneTree idle 帧 flush

### Resource

- [ ] **`.tres` 文本序列化往返**：`ResourceSaver::save(r, "res://x.tres")` 后 `ResourceLoader::load("res://x.tres")` 返回等价 Resource（属性、子资源一致）
- [ ] **`ResourceCache` 单实例**：同一 `res://` 路径多次 `load` 返回同一实例（指针相等）
- [ ] **`res://` 解析**：`OS::get_resource_root()` 返回非空，`load("res://foo.tres")` 能找到磁盘文件
- [ ] **Git diff 友好**：`.tres` 输出为稳定 key 顺序的文本（无随机哈希、无二进制段）

### Node / SceneTree

- [ ] **`add_child` / `remove_child` 维护父子树**：`get_parent()` / `get_children()` 一致；环检测（不能 add 自身的祖先）
- [ ] **生命周期顺序**：`_enter_tree` 自顶向下、`_ready` 自底向上；`_exit_tree` 在 `remove_child` 或销毁时触发
- [ ] **`SceneTree::process(delta)` 分发 `_process`**：用扁平列表（非每帧递归），N=10000 节点下单帧 < 1ms（性能断言）
- [ ] **`SceneTree::input(event)` 冒泡**：事件自顶向下，被消费（`accept_event()`）即停
- [ ] **`notification` 整树分发**：`SceneTree::notify(what)` 遍历所有节点调 `notification`
- [ ] **接入 P1 主循环**：`main.cpp` 调用 `SceneTree::process(delta)`；P1 Demo（网格 + 焊盘 + 走线 + 过孔）迁移为节点驱动后行为不变

### 构建与测试

- [ ] **全量构建**：`cmake --build build` 无错误、无警告（`/W4` / `-Wall -Wextra -Wpedantic`）
- [ ] **全量测试 PASS**：`ctest --test-dir build --output-on-failure` 全部通过（含 P1 既有测试 + P2 新增 test_object / test_class_db / test_variant / test_signal / test_resource / test_node_scene_tree）
- [ ] **RTTI/异常关闭**：核心 target 编译选项含 `-fno-rtti -fno-exceptions`（或 MSVC `/GR- /EHs-c-`）；GoogleTest 子项目独立配置不受影响
