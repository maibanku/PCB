# 08-04 放置与布局

> 所属 [[08-PCB编辑器]]。器件/焊盘/过孔等的放置与布局操作：移动/旋转/对齐/分布/推挤/物理碰撞检查。属 P8a。

## 目标（要实现什么）
- 放置对象：器件（Footprint 实例）、焊盘（独立焊盘）、过孔（通孔/盲埋孔）、丝印图形、尺寸标注、测试点。
- 基础操作：移动（拖拽）、旋转（R 90° / 自由角度）、镜像（Flip 到背面对应位置，跨层翻转）、复制、删除、锁定。
- 对齐与分布（基于 03-规则的 courtyard）：
  - 对齐：左/右/上/下/水平居中/垂直居中；
  - 分布：水平等距 / 垂直等距；
  - 网格对齐：批量吸附到栅格。
- 组合（Group）/ 临时组：多器件成组移动，保持相对位置；用于模块化布局。
- 推挤（Shove）：移动器件时自动推开冲突器件/走线/过孔，保持合规间距（基于 03-规则）。
- 物理碰撞检查：实时检测 courtyard 重叠（器件-器件、器件-板框、器件-禁布区），高亮违规。
- 布局辅助：飞线（Ratsnest）显示网络连通需求、密度图、长度热力图（与 09 联动）。
- 对齐基准：网格 / 选中基准点 / 板框原点 / 定位孔。
- 翻面（Flip）切换 Top/Bottom 层，器件位置关于板中心镜像。
- 单位切换 mm/mil；坐标输入框（绝对/相对）。

## 关键点
- 推挤算法基于 B2 几何 + 空间索引（四叉树/R-tree），万器件级实时响应。
- Flip 操作需联动 02-图层（切换 Top ↔ Bottom）、05-布线（关联走线）。
- courtyard 重叠检测走 08-DRC 实时通道（轻量规则子集）。
- 操作原子化入命令栈（B3）。

## 输入 / 输出
- **入**：网络表（07-04 网络表生成导入器件列表）、C1 封装库、02-图层、03-规则。
- **出**：已布局器件坐标 + 朝向 + 层归属，供 05-布线（飞线起点）与 08-DRC（碰撞检测）。

## 依赖
- **上游**：07-04 网表（器件清单）、C1 封装库、02-图层、03-规则。
- **下游**：05-布线（基于布局连通需求）、06-铺铜（避让器件）、08-DRC（碰撞/位置校验）。
