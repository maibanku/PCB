# 08-11 尺寸标注

> 所属 [[08-PCB编辑器]]。在 PCB 上放置尺寸标注（线性/角度/半径等），用于制造与装配图纸。属 P8c。

## 目标（要实现什么）
- 标注类型：
  - 线性标注（Linear）：水平/垂直/对齐（Aligned）尺寸；
  - 角度标注（Angular）；
  - 半径/直径标注（Radial/Diametric）；
  - 引线标注（Leader）：带文字注释的引线（如"R23 1%", "VCC"）；
  - 坐标标注（Datum/Ordinate）：基线 + 增量坐标。
- 标注对象：板框尺寸、定位孔间距、器件间距、关键走线长度、机械接口位置。
- 单位与精度：mm/mil 切换、小数位（0/1/2/3）、公差显示（± 公差、上下偏差）。
- 标注层：独立尺寸标注层（与 02-图层联动），可独立显示/隐藏，不参与 DRC。
- 标注样式：箭头类型（实心/空心/斜杠）、文字大小/字体、文字位置（上方/中间/自动）。
- 自动标注：板框一键生成整体尺寸（长/宽）、定位孔阵列间距。
- 关联性（Associative）：被标注对象移动时，标注自动跟随更新。
- 输出层映射：D4 制造输出时映射到装配图/钻孔图 PDF 的标注层。

## 关键点
- 标注是文档/制造图属性，不参与电气 DRC（避免误报）。
- 标注几何基于 B2 几何（线段/圆弧），可序列化为图元。
- 关联性需维护"标注 ↔ 源对象"引用表，对象变更时触发标注重算。
- 字体走 HarfBuzz/FreeType（B2 渲染统一），与原理图 PDF（07-09）共用。

## 输入 / 输出
- **入**：板框/器件/过孔坐标（01/04）、02-图层（标注层）、用户绘制操作。
- **出**：尺寸标注图元集，供 D4 制造图/装配图 PDF 输出。

## 依赖
- **上游**：B2 几何与字体、01-板框、04-放置（标注源对象）、02-图层。
- **下游**：D4 制造输出（装配图/制造图 PDF）、归档交付。
