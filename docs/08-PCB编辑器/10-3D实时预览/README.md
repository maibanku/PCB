# 08-10 3D实时预览

> 所属 [[08-PCB编辑器]]。2D/3D 视图实时切换，基于器件 3D 关联呈现整机立体预览。属 P8c。

## 目标（要实现什么）
- 2D ↔ 3D 视图切换：一键切换 PCB 2D 编辑视图与 3D 立体预览，状态保持（视角/选择）。
- 实时同步：2D 布局/布线变更后 3D 立即更新（基于脏区增量，万器件流畅）。
- 3D 渲染：
  - 板基（FR-4 / 铝基等材质纹理）；
  - 器件 3D 模型（关联 C1 库 STEP/OBJ/wrl，C5 联动）；
  - 走线/铺铜按层渲染为薄铜片；
  - 过孔/焊盘几何渲染。
- 视角控制：鼠标旋转/平移/缩放；预设视角（Top/Bottom/Iso/Front/Side）。
- 测量工具：3D 点对点距离、器件高度测量（与 C5 高度限制区联动）。
- 截面 / 剖面（Cross-Section）：沿任一切面截取板叠层视图（用于查看叠层/过孔结构）。
- 爆炸图（Exploded View）：器件层 / 铜层分离展示，便于结构评审。
- 高度限制区检查：器件高度 vs 外壳空间（C5 联动），碰撞高亮。
- 渲染输出：高清 PNG 渲染图、3D PDF、STEP 整机导出（D4 制造输出）。
- 灯光 / 材质：可配置灯光（环境光/方向光）、材质（铜/阻焊/丝印颜色），真实感渲染。

## 关键点
- 3D 引擎与 2D 共用 GPU 抽象（B2 渲染层，借鉴 Godot RenderingDevice），不重复造轮子。
- 性能：万器件 3D 实时同步，依赖 LOD + 实例化渲染（同型号器件共享 mesh）。
- 器件 3D 模型来自 C1 库（缺模型时用封装几何 + 高度参数生成立方体占位）。
- 与 C5 3D 与机械协同模块共担渲染（10 偏 PCB 自身预览，C5 偏整机/外壳）。

## 输入 / 输出
- **入**：04-放置（位置）、05-布线、06-铺铜、01-板框、02-叠层、C1 器件 3D 模型。
- **出**：3D 实时预览 + 渲染图/STEP 导出，供结构评审、外壳碰撞检查、D4 输出。

## 依赖
- **上游**：B2 渲染层（GPU 抽象）、C1 元件库（3D 模型）、01-07 各 PCB 编辑子模块。
- **下游**：C5 3D 与机械协同（共渲染）、D4 制造输出（3D STEP/PDF）。
