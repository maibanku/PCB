# 08-02 图层体系与叠层管理器

> 所属 [[08-PCB编辑器]]。管理信号/电源地/阻焊/丝印/钻孔/用户层等图层体系，提供叠层管理器（Layer Stack Manager）与阻抗计算。属 P8a。

## 目标（要实现什么）
- 图层类型体系：
  - 电气层：Top / Inner1..N / Bottom（信号层 + 平面层 Power/GND）；
  - 非电气层：阻焊（Solder Mask Top/Bot）、丝印（Silk Top/Bot）、铜膏（Paste Top/Bot）、钻孔层、钻孔图、装配层、Keepout、尺寸标注层、文档层、用户自定义层。
- 叠层管理器（Layer Stack Manager）：
  - 可视化叠层截面图（铜层 / 介质 / 阻焊厚度）；
  - 添加/删除/重排铜层，平面层与信号层切换；
  - 介质参数（介电常数 Er、介质厚度、铜厚：1oz/2oz/3oz）；
  - 预设：单层 / 双层 / 4 层 / 6 层 / 8 层常用叠层模板（嘉立创/捷多康等工厂标准叠层）。
- 阻抗计算器（Impedance Calculator）：
  - 微带线（Microstrip）、带状线（Stripline）、边缘耦合差分（Edge-Coupled）模型；
  - 输入线宽/铜厚/介质厚/Er → 输出阻抗（50Ω/90Ω/100Ω 差分等），反向求解（目标阻抗 → 推荐线宽）。
- 图层可见性 / 可选性 / 锁定：每层独立控制显示、可选、锁定；颜色 / 透明度可配。
- 层对（Layer Pair）：定义过孔默认层对（如 Top-Bottom、Top-Inner3）。
- 图层序列化进工程文件，schema 版本化。

## 关键点
- 叠层数据是阻抗控制（07-盲埋孔/阻抗走线）、SI/PI（D3）、制造输出（D4 Gerber 层映射）的共用基准，必须稳定可序列化。
- 阻抗模型采用成熟公式（IPC-2141 / Saturn PCB 算法），结果与主流工具 ±5% 内。
- 平面层与信号层语义不同：平面层默认全铺铜 + 关联电源网络；信号层默认空白。

## 输入 / 输出
- **入**：用户叠层配置 / 工厂预设模板、阻抗需求。
- **出**：图层体系（顺序 / 类型 / 参数）+ 阻抗参数表（线宽/差分宽距推荐），供 03-规则、05-布线、07-盲埋孔、D4-Gerber 使用。

## 依赖
- **上游**：B2 几何（无强依赖）、B3 数据模型（schema）。
- **下游**：03-设计规则（线宽/过孔规则按层）、05-布线（阻抗走线）、07-盲埋孔与背钻、D3-SI/PI、D4 制造输出（Gerber 层映射）。
