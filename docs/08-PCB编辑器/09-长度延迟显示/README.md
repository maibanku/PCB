# 08-09 长度延迟显示

> 所属 [[08-PCB编辑器]]。走线等长与延迟显示，服务高速信号长度匹配。属 P8b。

## 目标（要实现什么）
- 长度统计：
  - 单条网络总长度（累加所有层走线段 + 过孔长度修正）；
  - 差分对正/负线长度 + 偏差；
  - 网络类总长 / 平均长 / 最大最小长。
- 延迟估算：基于 02-叠层介质参数（Er / 铜厚）将长度换算为传播延迟（ns / ps），微带 / 带状线模型分别计算。
- 长度匹配（Length Matching）：
  - 目标长度（绝对 / 相对组内最长 / 用户指定）；
  - 偏差实时显示（如 +5.2mm / -3.1mm）；
  - 网络类分组（如 DDR_DQ[0..7] + DQS + DM 同组匹配）。
- 实时显示：
  - 走线时浮动标签显示当前长度 + 目标偏差；
  - 网络悬停时 tooltip 显示长度/延迟；
  - 长度热力图（与 04-布局联动）：颜色映射长度，过长/过短网络高亮。
- 与蛇形等长（05-布线）联动：自动建议蛇形加长量，叠加后实时刷新长度。
- 与过孔长度（07-盲埋孔）联动：过孔 stub 计入延迟。
- 报表：长度匹配报告（CSV/HTML），列出组内每条网络长度/偏差/达标状态。
- 与 D3-SI 联动：延迟数据是 SI 时序分析输入。

## 关键点
- 长度计算需精确到走线段几何长度（B2 Polyline/Path 累加），过孔长度按层对查表。
- 延迟模型：微带 v=c/√((Er+1)/2+...)、带状线 v=c/√Er；与 02-叠层数据联动。
- 长度匹配服务于 DDR/USB/PCIe/ETHERNET 等并行总线时序，是高速设计必备。
- 实时显示需轻量（走线编辑每帧重算），增量算法（仅重算受影响网络）。

## 输入 / 输出
- **入**：05-布线（走线几何）、07-过孔（长度修正）、02-叠层（介质参数）、03-规则（匹配目标）。
- **出**：每网络长度/延迟数据 + 偏差报告，驱动 05-蛇形等长、08-DRC（长度规则）、D3-SI 时序分析。

## 依赖
- **上游**：05-布线（几何）、07-盲埋孔（过孔长度）、02-叠层（延迟模型）、03-规则（匹配组）。
- **下游**：05-布线（蛇形等长建议）、08-DRC（长度规则校验）、D3-SI/PI（时序/反射）。
