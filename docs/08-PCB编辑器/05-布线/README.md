# 08-05 布线

> 所属 [[08-PCB编辑器]]。交互式推挤绕障布线、差分对、总线、蛇形等长、自动布线、拆线重布。属 P8b。

## 目标（要实现什么）
- 单路交互式布线（Single-Net Routing）：
  - 走线（Track），底层用 Path 几何类型存储（多段直线/圆弧），拐角默认 45°；
  - 推挤（Push-and-Shove）：实时推开同层走线/过孔保持合规间距（基于 03-规则）；
  - 绕障（Walkaround）：环绕障碍物走线，不推动；
  - 自由走线（Freehand）：任意角度（用于异形板）；
  - 拐角模式切换：45° / 90° / 圆弧 / 任意角度；
  - 实时线宽/过孔规则校验（按网络类，03-规则）。
- 差分对布线（Differential Pair）：
  - 等长耦合走线，耦合宽距按阻抗计算（02-叠层）；
  - 自动同步拐角、过孔成对；
  - 单端化处理（如绕开过孔分别走）。
- 总线 / 多线布线（Bus / Multi-Net）：多条网络并行布线，统一拐角，间距保持。
- 蛇形等长（Serpentine / Length Matching）：
  - 在已布走线上叠加蛇形加长，达到目标长度/相对延迟（与 09 联动）；
  - 自动/手动两种模式；锯齿形状可选（圆弧齿/方齿）。
- 自动布线（Auto-Router）：
  - 基于网格扩展/迷宫算法的内置自动布线器；
  - AI 增强（E1）：学习优秀设计，差分/等长/绕障更智能；
  - 选定网络 / 全板批量；可设权重（最短/最少过孔/分层偏好）。
- 拆线 / 重布（Unroute / Reroute）：删除指定网络走线、回到飞线状态；局部重布（用户圈选区域）。
- 长度/阻抗实时显示：走线时显示当前长度、阻抗（与 09 长度延迟联动）。
- 走线编辑：拖动拐角、删除段、移动整条走线、改换层（自动加过孔）。

## 关键点
- 走线数据 = Path（多段直线 + 圆弧），与 B2 几何对齐；走线即网络在某层的几何段。
- 推挤用 Clipper2 做几何偏移与避让；自动布线用 A*/Lee 算法 + 代价函数。
- 差分/等长与 09-长度延迟、D3-SI/PI 联动。
- 所有走线操作进命令栈（B3），布线策略可撤销。
- 自动布线不强制接受，结果作为草稿供用户调整（Copilot 模式）。

## 输入 / 输出
- **入**：04-放置布局（器件位置）、飞线（网络连通需求）、03-规则、02-叠层（阻抗参数）。
- **出**：走线几何（Path + 网络归属 + 层归属），供 06-铺铜避让、08-DRC 批检、09-长度统计、D4-Gerber 输出。

## 依赖
- **上游**：04-放置与布局、03-设计规则、02-叠层（阻抗）、B2 几何与 Clipper2。
- **下游**：06-铺铜（避让走线）、08-DRC（线宽/间距）、09-长度延迟（统计）、D4 制造输出。
