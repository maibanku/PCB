# 08-PCB编辑器

> 对应 **Plan P8**（Phase 2 · MVP 闭环）。MVP 最大模块，承接原理图网表，提供从板框/叠层/规则到布局布线、铺铜、DRC、3D 预览的完整 PCB 物理设计能力。

## 定位
- **做什么**：板框设计、图层体系与叠层管理器、设计规则与约束管理器、放置与布局、布线（交互推挤绕障/差分对/总线/蛇形等长/自动布线/拆线重布）、铺铜、盲埋孔与背钻、DRC、长度延迟显示、3D 实时预览、尺寸标注、测试点。
- **不做什么**：不做原理图（归 P7）；不做完整 DFX/SI-PI（归 P11/P12）；不做制造输出 Gerber/IPC-2581 等（归 P13）；不做 ECO 双向同步（归 P14）；不做完整 3D 机械协同（归 P10，此处仅 2D/3D 切换预览）。
- **拆分说明**：本域规模最大，**可拆为 P8a / P8b / P8c 三个子 Plan 渐进交付**——P8a（板框/图层/规则/布局）打地基，P8b（布线/铺铜/盲埋孔/DRC/长度延迟）上核心能力，P8c（3D 预览/尺寸标注/测试点）补收尾。子功能编号统一 01-12，按子 Plan 分组见下表。
- **代码位置**：`eda/pcb`（见 [[00-总览/03-项目目录结构]]）
