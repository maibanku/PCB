# 08-03 设计规则与约束管理器

> 所属 [[08-PCB编辑器]]。定义间距/线宽/过孔规则集，按网络/网络类分级约束，驱动布线与 DRC。属 P8a。

## 目标（要实现什么）
- 规则维度：
  - 间距（Clearance）：线-线、线-焊盘、焊盘-焊盘、线-过孔、铺铜-焊盘、板框-走线、丝印-焊盘、阻焊桥；
  - 线宽（Width）：最小/默认/最大线宽，按层、按网络类；
  - 过孔（Via）：最小孔径/盘径、默认尺寸、盲埋孔层对约束；
  - 阻焊 / 丝印规则：阻焊 expansion、丝印上焊盘检测、最小阻焊桥；
  - 物理约束：器件间距、 courtyard 重叠、高度限制区（与 C5 联动）；
  - 电气约束：长度匹配、差分对耦合、延迟约束（与 09 联动）。
- 约束作用域分级：
  - 全板默认（Default）；
  - 网络类（Net Class，如 Power/GND/HighSpeed/RF）；
  - 单个网络（Net-specific override）；
  - 区域（Room/Rule Area，如 DDR 区域更严约束）；
  - 层（Layer-specific，如内层更宽线）。
- 约束管理器面板（Constraint Manager）：表格化展示所有规则、作用域、值，可增删改查。
- 网络类管理：将网络分组（如所有 DDR 数据线归为 DDR_DQ 类），统一约束。
- 规则预设：从工厂档案 `capabilities` 加载工艺极限（嘉立创/华秋/JLCPCB 等参考档案见 [[参考/厂商档案规范]]）+ 板型预设；可分享、云同步。
- 与 DRC 实时联动：规则变更触发 DRC 重算（08-DRC）。
- 自定义规则脚本接口（对接 D1 统一校验框架）。

## 关键点
- 规则冲突优先级：单网络 > 网络类 > 区域 > 层 > 默认；冲突时取最严格（保守策略）。
- 约束是 05-布线 / 08-DRC 的输入契约，规则变更需触发实时 DRC 重新评估。
- 借鉴 Altium Constraint Manager / Allegro 约束体系，但简化到中小板够用级别。

## 输入 / 输出
- **入**：用户规则配置 / 工厂能力预设 / 网络类定义（来自 07-04 网表 + 用户分组）。
- **出**：规则集（间距表 / 线宽表 / 过孔规则 / 网络类约束），供 05-布线（实时约束）、08-DRC（批检）使用。

## 依赖
- **上游**：02-图层（层相关规则）、04-放置（区域定义）、网络表（网络类来源）。
- **下游**：05-布线（推挤/差分/蛇形约束）、08-DRC（规则执行）、09-长度延迟（长度规则）。
