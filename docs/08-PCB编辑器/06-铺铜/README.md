# 08-06 铺铜

> 所属 [[08-PCB编辑器]]。动态铺铜（Copper Pour）、热焊盘/直连、避让规则、一键重建。属 P8b。

## 目标（要实现什么）
- 铺铜区域（Copper Pour Area）：在指定层、指定多边形区域内填充铜，关联到一个网络（通常是 GND/VCC）。
- 几何生成：区域多边形 - 避让图元（走线/焊盘/过孔/禁布区）→ 布尔差集（Clipper2）+ 间距 offset → 最终铜皮轮廓。
- 连接方式（Pad Connection）：
  - 热焊盘（Thermal Relief）：4 条/8 条辐条连接，便于焊接散热，默认用于同网络焊盘；
  - 直接连接（Solid/Direct）：全铜连接，低阻抗，用于电源/大电流；
  - 间隙连接（None）：完全不连，用于反极性网络避让。
- 避让规则（Clearance）：铺铜与其他图元间距按 03-规则（同网络/异网络不同）。
- 动态铺铜（Dynamic Pour）：器件/走线移动时实时重铺，保持合规（基于脏区增量算法，避免全板重算）。
- 一键重建（Repour All）：批量重铺所有铜区，用于变更后统一刷新。
- 分块铺铜（Split Plane）：电源平面分割为多个网络区域（用禁布区分隔）。
- 铺铜参数：辐条宽度/数量、避让间距、最小铜皮面积（去孤岛）、圆角处理。
- 死铜删除（Dead Copper Removal）：面积过小或无连接的孤立铜皮自动移除。
- 网络属性：铺铜会改变网络连通性（如两个 GND 焊盘通过铜皮连通），影响网表展���。

## 关键点
- 铺铜 = 布尔差集 + 多边形偏移 offset（Clipper2，B2 几何）。
- 性能：万焊盘铺铜需亚秒级，用空间索引 + 脏区增量（B2 四叉树）。
- 动态铺铜是高频交互，需节流（如鼠标拖动期间降级显示，松开时精算）。
- 铺铜结果需进入网表连通图（影响 DRC 短路/开路检测）。

## 输入 / 输出
- **入**：区域多边形 + 关联网络、03-规则（避让/连接方式）、04-放置、05-布线、01-板框。
- **出**：铜皮多边形（含避让空洞、辐条），供 08-DRC（短路/间距）、D4-Gerber 输出。

## 依赖
- **上游**：B2 几何（Clipper2/offset）、01-板框（边界）、03-规则、04-放置、05-布线（避让对象）。
- **下游**：08-DRC（短路/间距/连通）、D4 制造输出（Gerber 铜层）。
