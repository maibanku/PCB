# 08-08 DRC

> 所属 [[08-PCB编辑器]]。实时 DRC（编辑时即时反馈）与全板 DRC（完整规则批检），结果可定位可修复。属 P8b。

## 目标（要实现什么）
- 实时 DRC（Online DRC）：
  - 编辑操作（放置/布线/铺铜/移动）即时校验，违规位置以红色高亮 + 错误符号提示；
  - 仅校验受影响脏区（基于 B2 空间索引），亚秒级响应；
  - 不阻断用户操作，仅提示。
- 全板 DRC（Batch DRC）：
  - 一键批检全板所有规则（03-规则全部维度）；
  - 进度提示（万级图元扫描分块并行）；
  - 结果分级：Error / Warning / Info。
- 检查项：
  - 间距违规（Clearance，线-线/线-焊盘/焊盘-焊盘/铺铜-走线/板框-走线）；
  - 线宽违规（Width，最小/最大）；
  - 过孔规则（孔径/盘径/盲埋孔层对）；
  - 短路（不同网络图元接触，含铺铜连通分析）；
  - 开路（Netlist 中有连接但 PCB 上未连通，含飞线检测）；
  - courtyard 重叠（器件-器件物理碰撞）；
  - 丝印上焊盘、阻焊桥缺失、孤立焊盘；
  - 板框未闭合、定位孔缺失；
  - 网络连通性 vs 原理图网表（一致性，与 07-04 网表 / B3-ECO 联动）。
- 结果面板：分级列表 + 跳转定位（双击错误跳到 PCB 位置）+ 忽略/批准 + 修复建议（如"自动加间距"）。
- 与 03-规则联动：规则变更触发 DRC 重算。
- 报告导出：DRC 报告（HTML / CSV），归档/分享。
- 增量 DRC 缓存：未变更对象复用上次结果，加速全板 DRC。

## 关键点
- DRC 是"可生产"的最后一道闸，必须与工厂能力（嘉立创 6/6mil 等）对齐（规则预设）。
- 性能关键：空间索引（B2 四叉树/R-tree）+ 增量脏区 + 多线程并行。
- 一致性检查（原理图网表 vs PCB 连通图）是 ECO 双向同步的依据（B3）。

## 输入 / 输出
- **入**：PCB 图元（04/05/06/07）、03-规则、02-叠层、原理图网表（一致性比对）。
- **出**：DRC 报告（错误列表 + 定位 + 修复建议），阻断 D4 制造输出（未通过则警告/禁止）。

## 依赖
- **上游**：01-板框、02-叠层、03-规则、04-放置、05-布线、06-铺铜、07-盲埋孔、07-04 网表（一致性）。
- **下游**：D1 统一校验框架（自定义规则）、D2-DFM/DFT（DRC 衍生）、D4 制造输出（前置闸）。
