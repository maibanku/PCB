# 08-07 盲埋孔与背钻

> 所属 [[08-PCB编辑器]]。盲埋孔（Blind/Buried Via）、背钻（Back Drill）与阻抗控制走线，支持高密度与高速叠层互连。属 P8b。

## 目标（要实现什么）
- 过孔类型体系：
  - 通孔（Through Via）：Top ↔ Bottom，贯穿全部层；
  - 盲孔（Blind Via）：外层 ↔ 内层，仅一端在外（如 Top ↔ Inner3）；
  - 埋孔（Buried Via）：内层 ↔ 内层，两端均在内（如 Inner2 ↔ Inner5）；
  - 微孔（Microvia）：激光盲孔，HDI 高密度互连。
- 层对管理（Layer Pair）：定义可用过孔层对（受 02-叠层能力约束），盲埋孔层对应在叠层中合法。
- 背钻（Back Drill）：对过孔 stub 段做反向钻孔以减小高频反射；参数：背钻起止层、残桩长度（Stub Length）。
- 过孔规格：孔径（Hole Size）、盘径（Pad Size）、阻焊覆盖（Tented）、阻焊开窗。
- 阻抗控制走线：过孔的焊盘/反焊盘影响高频阻抗，提供过孔阻抗估算（与 D3-SI 联动）。
- 布线集成：05-布线换层时按层对规则自动放置合适过孔类型（通孔/盲埋孔）。
- DRC 规则：盲埋孔层对合法性、孔径盘径、间距（08-DRC 联动）。
- 制造输出：盲埋孔分层钻孔文件（每层对独立 Excellon，D4 联动）。

## 关键点
- 盲埋孔层数受工厂能力限制（如嘉立创最多 3 阶 HDI），需在 02-叠层/规则中预校验。
- 背钻影响成本，需在 DRC/DFM 提示并允许用户选择性应用。
- 过孔阻抗模型（D3）需输入叠层参数（02）。
- 微孔叠孔（Stacked Via）/ 错位孔（Staggered Via）影响布线密度与策略。

## 输入 / 输出
- **入**：02-叠层（层结构/介质）、03-规则（过孔规则/层对）、05-布线（换层请求）。
- **出**：类型化过孔（含层对/孔径/盘径/背钻参数），供 08-DRC、D4-钻孔文件、D3-SI 分析。

## 依赖
- **上游**：02-图层与叠层、03-设计规则、05-布线。
- **下游**：08-DRC（过孔规则校验）、09-长度延迟（过孔长度计入）、D3-SI/PI（stub 反射）、D4 制造输出（钻孔分层）。
