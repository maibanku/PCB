# 08-01 板框

> 所属 [[08-PCB编辑器]]。定义 PCB 物理边界：矩形/圆形/异形板框、DXF 导入、开槽、定位孔。属 P8a。

## 目标（要实现什么）
- 板框（Board Outline）数据结构：闭合多边形 / 圆弧 / 路径构成的整体边界（基于 B2 几何 Polyline + Arc）。
- 形状类型：矩形（输入宽高即生成）、圆形（输入半径）、异形（自由多边形 + 圆弧段组合）、DXF/DWG 导入（F3 格式兼容）。
- 内部开槽（Cutout）：板内非边界腔体（如连接器开窗、减重槽），与板框同为"Outline 类"图元但语义不同。
- 定位孔（Mounting Hole）：机械固定用孔，支持非镀通孔（NPTH），可按坐标 / 直径 / 角度阵列放置。
- 圆角 / 倒角：板框外边可加圆角（R 值）或倒角（C 值）。
- DXF 导入：图层映射（哪些 DXF 层 → 板框 / 禁布区 / 丝印），原点对齐，单位识别（mm/inch）。
- 板框作为约束边界：禁布区（Keepout）自动从板框生成（含间距 offset），影响布线（05）与铺铜（06）。
- 尺寸显示：长 / 宽 / 面积实时显示，便于确认板尺寸。
- 板框编辑历史进入命令栈（B3），可撤销。

## 关键点
- 板框是 PCB 一切几何的"容器"，必须闭合（不闭合由 DRC 08 捕获）。
- 多段板框拼接（多个 Arc/Polyline 段）需做并集运算（B2 布尔运算）形成单一闭合轮廓。
- DXF 导入是机械协同的关键入口（与 C5 3D / 机械协同呼应）。
- 板框 offset 用于生成禁布区（B2 多边形偏移 offset，Clipper2 实现）。

## 输入 / 输出
- **入**：用户绘制 / DXF/DWG 文件（F3）、机械外壳约束（C5）。
- **出**：闭合板框 + 开槽 + 定位孔，供 04-放置 / 05-布线 / 06-铺铜 / 08-DRC 作为边界约束。

## 依赖
- **上游**：B2 几何引擎（Polyline/Arc/布尔运算/offset）、F3 格式兼容（DXF 导入）。
- **下游**：04-放置与布局（板内坐标空间）、05-布线（边界避让）、06-铺铜（边界收缩）、08-DRC（板框合法性）。
