# 08-12 测试点

> 所属 [[08-PCB编辑器]]。测试点（Test Point）放置（MVP 基础），为后续 DFT 可测试性与 ICT/FCT 夹具适配打基础。属 P8c。

## 目标（要实现什么）
- 测试点（Test Point）图元：作为特殊焊盘放置，关联到一个网络（待测网络），层数据（Top/Bot）。
- 测试点类型：
  - 圆形焊盘型（最常用，配合探针）；
  - 过孔型（直接利用通孔作测试点）；
  - 专用测试桩（Test Post）。
- 测试点放置：
  - 手动：选网络 → 点击位置放置；
  - 半自动：根据网络列表自动定位到合适走线/过孔位置，用户确认；
  - 全自动（AI 辅助，后续）：基于可达性 + 覆盖率优化自动放置（D2-DFT 联动）。
- 测试点参数：直径、间距规则、探针型号兼容（与夹具厂家对齐）。
- 测试点列表（Test Point List）：所有测试点的网络/坐标/层位/类型，可导出 CSV（夹具厂所需）。
- 覆盖率统计：测试点覆盖网络数 / 总网络数百分比（D2-DFT 关键指标）。
- DRC 集成：测试点间距、可达性（不被器件/courtyard 遮挡）、夹具面对侧等（08-DRC 联动）。
- 与 D2-DFT 联动：可测试性分析（ICT/FCT 夹具适配）的输入数据。
- 输出：测试点坐标文件（IPC-2581 / 自有 CSV，D4 制造输出）。

## 关键点
- 测试点是为后续 D2-DFT 可测试性分析打基础的 MVP；P8c 阶段以放置 + 坐标输出为主，深度可达性分析进 D2。
- 测试点本质是"特定语义的焊盘"，复用焊盘数据结构 + 网络关联。
- 夹具面对侧（Top/Bot）与探针可达性是 DFT 关键，影响放置策略。
- 覆盖率统计需与原理图网络表（04）联动，识别"必须有测试点"的关键网络（电源/关键信号）。

## 输入 / 输出
- **入**：07-04 网表（待测网络列表）、03-规则（测试点规则）、02-图层。
- **出**：测试点图元 + 坐标列表 + 覆盖率统计，供 D2-DFT 可测试性分析、D4 输出（IPC-2581/CSV）。

## 依赖
- **上游**：04-放置与布局、03-设计规则、07-04 网表（待测网络）。
- **下游**：08-DRC（测试点规则/可达性）、D2-DFT（可测试性分析）、D4 制造输出（夹具坐标文件）。
