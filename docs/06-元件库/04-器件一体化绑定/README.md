# 06-04 器件一体化绑定

> 所属 [[06-元件库]]。实现"**器件一体化**"模型：一个器件 = 符号 + 封装 + 3D 模型 + SPICE 模型 + 供应链信息（五位一体），参数元数据贯穿所有视图，对标嘉立创器件一体化（vs KiCad 符号/封装分离）。

## 目标（要实现什么）
- **一体化数据模型**：`Device` Resource 聚合五类子资源：
  1. **符号**（[[01-符号库编辑器]] 输出）：可能多 gate
  2. **封装**（[[02-封装库编辑器]] 输出）：可能多种封装变体（如 SOIC8 / TSSOP8）
  3. **3D 模型**（[[03-3D模型库关联]] 输出）：与每个封装变体关联
  4. **SPICE 模型**：与符号关联（仿真 C4 用）
  5. **供应链信息**：manufacturer、mpn、price、stock、lifecycle、RoHS、供应商链接（E2 供应链用）
- **参数元数据**：器件级属性（`resistance`、`capacitance`、`tolerance`、`voltage_rating`、`package`、`temperature_range`），结构化存储，供搜索/筛选/BOM
- **封装变体**：一个器件可定义多种封装（如 0603 电阻的 reel/tape、不同焊盘布局），用户放置时选其一
- **Pin 映射绑定**：符号引脚号 ↔ 封装焊盘号 ↔ 3D 引脚位置（三表对齐，确保 ECO 双向同步不丢映射）
- **供应链直显**：原理图/PCB 选中器件时，Inspector 显示价格/库存/生命周期（与 E2 联动，设计阶段可见成本）
- **替代料关系**：器件可声明"Pin 兼容替代"列表，E2 推荐时直接用
- **派生器件**：从通用器件（如"0603 电阻"）派生具体料号（"10kΩ 0603 1%"），避免重复建库
- **输出**：`*.dev.toml`，包含所有子资源引用 + 元数据

## 关键点
- **一体化是 vs KiCad 的核心差异化**：KiCad 符号和封装是独立库，放置时才关联；本品器件即"打包好的整体"，设计阶段就是完整的
- **供应链预置（为 E2 铺路）**：器件建库时就录入供应链信息，设计阶段可见成本/可造性
- **多封装变体必备**：同芯片不同封装（如 LQFP/QFN）共用符号 + SPICE，只是封装不同
- **Pin 映射是 ECO 基础**：三表对齐保证原理图↔PCB 同步不丢引脚映射
- **派生避免样板**：通用器件（电阻/电容）建一次，按参数派生万千具体料号

## 输入 / 输出
- **入**：符号、封装、3D 模型、SPICE 模型、供应链信息（子资源）
- **出**：一体化的器件 Resource（`*.dev.toml`），供原理图/PCB/仿真/BOM/供应链共用
