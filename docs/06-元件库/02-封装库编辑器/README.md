# 06-02 封装库编辑器

> 所属 [[06-元件库]]。实现 PCB 封装（footprint）的创建/编辑工具：放置焊盘（SMD/通孔）、绘制丝印、定义阻焊/courtyard/装配区、关联 3D 模型，输出符合制造标准的封装库单元。

## 目标（要实现什么）
- **焊盘系统**：
  - 类型：SMD（表贴）、通孔（TH，含内径/外径）、盲埋孔焊盘
  - 形状：圆形、方形、矩形、圆角矩形、椭圆、自定义多边形
  - 层分配：SMD 焊盘绑定到顶层/底层；通孔焊盘贯穿所有信号层
  - 焊盘属性：`number`（引脚号）、`size`、`drill`（通孔）、`shape`、`layer`、`paste_coverage`（钢网）
- **丝印/装配图元**：线、圆弧、文本（含位号 `<ref>`、值 `<val>` 占位符）、多边形，按层分类（顶层丝印/底层丝印/装配层）
- **courtyard（器件占用区）**：自动生成或手动绘制，用于 DFM 间距检查（器件-器件物理避让）；正文统一保留英文 courtyard（见 [[00-总览/04-术语表]] D2）
- **阻焊/钢网自动生成**：焊盘阻焊层按规则放大（默认 0.1mm），钢网按比例覆盖
- **原点/对位**：封装原点（通常器件中心或 Pin 1），courtyard 几何中心可对齐
- **3D 关联**：封装内挂 3D 模型引用 + 偏移/旋转/缩放（与 [[03-3D模型库关联]] 协作）
- **courtyard 与高度**：定义器件最大高度，用于 3D 干涉检查（C5）
- **库内复用**：从标准封装派生（如 QFP→QFN 派生）
- **校验**：焊盘号重复、焊盘超出 courtyard、阻焊桥不足等 DFM 检查（与 D2 DFX 联动）
- **IPC-7351 集成**：可调用 [[06-库向导]] 生成标准封装

## 关键点
- **焊盘是核心**：SMD/通孔/盲埋孔三类覆盖所有器件类型，焊盘属性决定 DFM/DFT 可制造性
- **courtyard 是 DFM 基石**：courtyard 定义准确，DRC 器件间距检查才有依据
- **阻焊/钢网自动**：避免手动逐焊盘调，规则化生成（与工厂能力挂钩）
- **3D 关联**：封装与 3D 模型绑定后，PCB 3D 预览/干涉检查自动生效

## 输入 / 输出
- **入**：用户绘制、IPC-7351 向导输出（可选）
- **出**：标准封装库单元（`*.fp.toml`），可供器件绑定和 PCB 放置
