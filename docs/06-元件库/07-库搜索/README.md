# 06-07 库搜索

> 所属 [[06-元件库]]。提供强大的库检索：参数化检索、模糊匹配、供应商料号直达，让用户在万级器件库中快速定位，并直显供应链信息（与 E2 联动）。

## 目标（要实现什么）
- **多模式搜索**：
  1. **关键字模糊**：名称/描述/关键字模糊匹配（子序列 + 拼音）
  2. **参数化检索**：按参数过滤（阻值范围、容值、封装、工作电压、精度、温度范围）
  3. **供应商料号直达**：输入 MPN（如 `STM32F103C8T6`）直接定位
  4. **分类浏览**：树形分类（电阻/电容/IC/连接器/...），逐级筛选
- **索引**：本地索引（基于 [[05-库层级]] 缓存），搜索不联网；增量更新（库变更时重建索引）
- **搜索结果 UI**：列表/网格切换，每条显示：符号缩略图、封装缩略图、关键参数、MPN、库存（云库）、价格
- **二次筛选**：结果上方可叠加参数过滤器（如"阻值 > 10kΩ"），动态收窄
- **供应链直显**：选中器件右侧显示库存/价格/生命周期（与 E2 联动，设计阶段可见成本）
- **放置入口**：搜索结果双击/拖拽直接放置到原理图（与 C2 协作）
- **搜索历史 / 收藏**：常用器件收藏夹，跨工程访问
- **空结果建议**：找不到时建议"在线云端库搜索"或"参数相近替代"

## 关键点
- **参数化是 vs KiCad 的优势**：KiCad 搜索仅关键字，本品按电气参数过滤（如"找 100uF 16V 0805 X5R"）
- **MPN 直达**：工程师常以料号思考（"我要 STM32F103"），直达是高频场景
- **供应链直显前置**：搜索结果就显示库存/价格，避免"选完才发现买不到"
- **索引性能**：万级器件搜索 ≤ 100ms，本地索引 + 增量更新

## 输入 / 输出
- **入**：用户搜索查询、库索引（本地缓存）
- **出**：匹配的器件列表 + 供应链摘要，供放置或详情查看

## 依赖
- **上游**：[[05-库层级]]（多级库源）、供应链 E2（库存/价格数据）、[[04-器件一体化绑定]]（器件元数据）
- **下游**：原理图编辑器 C2（放置器件）、PCB 编辑器 C3（添加封装）
