# 06-元件库

> 对应 **Plan P6**（Phase 2 · MVP 闭环）。承载原理图符号、PCB 封装、3D 模型、参数、SPICE 与供应链占位的一体化元件管理体系。

## 定位
- **做什么**：提供符号库与封装库编辑器、3D 模型关联、器件一体化绑定（符号+封装+3D+参数+SPICE+供应链）、库层级（本地/云端/企业）、IPC-7351 库向导、参数化搜索与版本依赖锁定。
- **不做什么**：不做供应链实时数据接入（仅留占位接口）；不做 SPICE 模型本身的求解（由 P9 仿真器承担）。
- **代码位置**：`eda/library`（见 [[00-总览/03-项目目录结构]]）
