# 06-06 库向导

> 所属 [[06-元件库]]。提供库生成向导：批量引脚符号生成 + **IPC-7351 标准封装生成器**，让用户输入器件参数（引脚数/间距/封装尺寸）自动生成符合行业标准的符号和封装，避免手工绘制。

## 目标（要实现什么）
- **IPC-7351 封装生成器**（核心）：
  - 输入：封装类型（QFP/QFN/SOIC/TSSOP/SOT/BGA/DFN/...）、引脚数、引脚间距、body 尺寸、引脚尺寸
  - 输出：完整封装（焊盘尺寸/位置、丝印、courtyard、阻焊、装配图），符合 IPC-7351C 标准
  - 公差计算：按 IPC-7351 的"Maximum/Median/Least"材料条件计算焊盘尺寸
  - courtyard 自动生成：按器件最大尺寸 + IPC 间距规则
- **批量引脚符号生成**：
  - 输入：引脚数（如 100）、gate 数（如 4）、引脚命名规则（如 `A1~A25`、`VCC`、`GND`）
  - 输出：自动布局引脚（按 gate 分块、电源地集中放置）、生成多 gate 符号
  - 支持 CSV 引脚表导入（从 datasheet 复制）
- **BGA 矩阵向导**：输入行×列（如 32×32），自动生成 A-Z,AA-AZ 命名 + 焊盘矩阵
- **连接器向导**：输入排针/D-SUB/HDMI 等连接器参数，生成对应符号 + 封装
- **向导 UI**：分步表单（输入参数 → 预览 → 微调 �� 入库），实时 2D 预览
- **预设模板**：常见器件类型预设参数（如 0603 电阻、TQFP-48），一键应用
- **批次校验**：生成后自动跑 DFM 检查（焊盘间距/阻焊桥）
- **入库**：生成的符号/封装直接存入选定库（与 [[05-库层级]] 协作）

## 关键点
- **IPC-7351 是工业标准**：对标 KiCad/Altium 封装向导，自动生成的封装可直接生产，避免手工绘制错误
- **批量引脚必备**：100+ 引脚器件（FPGA/MCU）手画不现实，向导是生产力关键
- **CSV 引脚表导入**：从 datasheet 复制粘贴引脚表，向导自动布局，零手工
- **与一体化绑定联动**：向导生成的符号 + 封装可直接进入 [[04-器件一体化绑定]]

## 输入 / 输出
- **入**：器件参数（封装类型、引脚数、尺寸、CSV 引脚表）
- **出**：标准符号 + 封装库单元（可直接入 [[01-符号库编辑���]] / [[02-封装库编辑器]]）

## 依赖

- **下游**：[[01-符号库编辑器]]（接收符号）、[[02-封装库编辑器]]（接收封装）、[[04-器件一体化绑定]]
