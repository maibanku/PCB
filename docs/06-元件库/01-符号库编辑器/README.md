# 06-01 符号库编辑器

> 所属 [[06-元件库]]。实现原理图符号的创建/编辑工具：绘制符号图形（矩形/圆/多边形/引脚）、定义引脚属性（名称/编号/类型/位置）、配置 Pin 映射，输出标准符号库单元。

## 目标（要实现什么）
- **图元绘制**：矩形、圆、圆弧、多边形、折线、贝塞尔、文本，支持栅格吸附（100mil 标准 / 自定义）
- **引脚系统**：
  - 引脚属性：`name`、`number`（对应封装焊盘号）、`electrical_type`（Input/Output/Bidirectional/Power/Passive/OpenCollector/...）、`position`、`length`、`orientation`（四向）
  - 引脚样式：低电平有效（上划线）、时钟边沿（三角符号）、反向器等 IEEE 标记
  - 引脚可选中/拖拽/批量对齐/属性表编辑
- **Pin 映射**：符号引脚号 ↔ 封装焊盘号的映射表（支持多 gate 器件、引脚重编号，与 [[04-器件一体化绑定]] 协作）
- **多 Gate 单元**：运放/逻辑门等多单元器件，一个符号含多个 Gate（A/B/C/D），每个 Gate 独立绘制
- **属性管理**：符号级元数据（`designation` 前缀如 U?、`description`、`keywords`、`datasheet`、`manufacturer`、`mpn`）
- **图形/引脚对齐工具**：水平/垂直居中、等距分布、栅格吸附
- **库内复用**：从已有符号派生（继承 + 覆盖），支持符号块复制
- **校验**：引脚号重复检测、引脚未连接检测、图形重叠告警
- **输出**：保存为 `*.sym.toml`（与 [[05-工程与文件系统/02-开放文本格式]] 协作）；可导出 KiCad 符号格式（F3 互操作）

## 关键点
- **遵循行业规范**：引脚电气类型影响 ERC（电源地/输入输出冲突检测，与 D1 校验联动）
- **多 Gate 是硬需求**：运放（双/四）、74 逻辑门等必须支持，否则库覆盖不全
- **Pin 映射先行**：符号引脚号与封装焊盘号的映射在符号阶段定义，器件绑定时复用
- **可继承派生**：系列器件（如 STM32F1 全系列）共享基础符号，派生省时

## 输入 / 输出
- **入**：用户绘制操作、（可选）从 datasheet 提取的引脚表
- **出**：标准符号库单元（`*.sym.toml`），可供器件绑定和原理图放置

## 依赖
- **上游**：GUI 控件体系（P4，编辑器 UI）、几何引擎（图形 + 布尔运算）
- **下游**：[[04-器件一体化绑定]]、原理图编辑器 C2、格式兼容与互操作 F3
