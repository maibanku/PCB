# 06-03 3D模型库关联

> 所属 [[06-元件库]]。实现 3D 模型（STEP/OBJ/VRML）的导入、管理、与封装的关联校准，为 PCB 3D 预览、装配干涉检查、机械协同提供几何数据。

## 目标（要实现什么）
- **导入格式**：
  - **STEP**（AP214/AP242）：机械 CAD 标准，优先支持（与 Altium/KiCad 一致）
  - **OBJ**：轻量网格，快速预览
  - **VRML（.wrl）**：KiCad 生态主流，兼容导入
  - **IGES**（可选）：旧格式兼容
- **模型库管理**：本地 + 工程级模型库，模型带 `uuid`、`name`、`manufacturer`、`mpn`、`source_url`
- **封装关联**：封装内挂载 3D 模型引用，定义偏移 `(x, y, z)`、旋转 `(rx, ry, rz)`、缩放因子（与 [[02-封装库编辑器]] 协作）
- **原点校准**：3D 模型原点对齐封装原点（通常是 Pin 1 或器件中心），支持交互式拖拽校准
- **缩放单位处理**：STEP 用 mm，OBJ 常无单位（默认 mm，可配置），VRML 用 mm/英寸切换
- **简化/LOD**：高面数模型自动 decimate（仅 3D 预览，不参与干涉检查时降精度）
- **3D 渲染**：与渲染层共用 GPU 抽象（Vulkan/GL/Metal），材质/光照基础
- **批量导入**：从 KiCad/Altium 3D 库批量导入，自动匹配封装（与 F3 协作）
- **校验**：模型尺寸与封装 courtyard 不匹配告警（防止模型错误导致干涉误报）

## 关键点
- **STEP 是机械协同关键**：与外壳/结构件对接必须 STEP（IGES 已过时）
- **原点对位是难点**：3D 模型原点常不在 Pin 1，需要交互式校准工具
- **LOD 提速**：万器件 PCB 3D 预览时，远距离器件用低精度模型
- **与封装绑定**：3D 是封装的子资源，不是独立实体（封装变，3D 跟着走）

## 输入 / 输出
- **入**：外部 3D 文件（STEP/OBJ/VRML）、用户校准操作
- **出**：标准化的 3D 模型库 + 封装内的 3D 关联记录

## 依赖
- **上游**：`third_party/Assimp`（3D 导入）、`servers/RenderingServer`（3D 渲染）
- **下游**：[[02-封装库编辑器]]（封装引用 3D 关联）、3D 与机械协同 C5、[[04-器件一体化绑定]]、PCB 编辑器 C3（3D 实时预览）
