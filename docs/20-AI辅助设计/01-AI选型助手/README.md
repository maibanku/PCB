# 20-01 AI选型助手

> 所属 [[20-AI辅助设计]]。基于功能需求、电气约束与供应链现状，给出器件选型建议（含替代料与生命周期），所有建议可接受/拒绝/撤销。

## 目标（要实现什么）
- 接受自然语言/结构化需求输入（如"3.3V LDO，输出 500mA，SOT-23，无铅"），返回候选器件排序清单
- 综合电气参数、封装、库存、价格、交期、生命周期（EOL/NRND）多维度打分，附理由可解释
- 联动 [[21-供应链集成/01-BOM配齐]] 与 [[21-供应链集成/03-元件生命周期]] 实时数据，避免推荐买不到/即将停产的料
- 推荐替代料时给出 Pin 兼容 / 参数近似等级，并标注需重新设计的程度
- 选定后一键插入原理图（占位符号 + 占位封装），变更落入命令栈可撤销
- 记录用户拒绝/接受的反馈，持续优化推荐排序（带用户偏好画像）

## 关键点
- 严格 Copilot 模式：AI 仅给建议，不直接改工程；所有插入走命令栈
- 推荐结果必须可解释（每条候选附理由），避免黑盒误导
- 供应链数据查询须走 [[21-供应链集成/07-供应商对接]] 抽象层，单源故障不阻断
- 隐私敏感工程走本地模型策略（见 [[20-AI辅助设计/08-模型策略]]）

## 输入 / 输出
- **入**：用户需求（自然语言/表单）、供应链实时数据、元件库索引、生命周期数据
- **出**：候选器件排序清单、理由与置信度、一键插入原理图的命令、反馈日志
