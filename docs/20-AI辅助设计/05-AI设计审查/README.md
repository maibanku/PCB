# 20-05 AI设计审查

> 所属 [[20-AI辅助设计]]。以自然语言给出 DRC/DFM/DFT/可靠性的深入审查意见与改进建议（如"这条电源走线够宽吗？""去耦够吗？"），结论可追溯、可接受/拒绝。

## 目标（要实现什么）
- 在 DRC/DFM/DFT 规则结果之上叠加 AI 解读：把冰冷规则违反翻译成"为什么有问题、怎么改"
- 支持自然语言提问：用户在画板上选中对象后提问（如"这路电源 1A 够用吗？""去耦电容够吗？"）
- 可靠性审查：基于工程经验给出潜在隐患（热、EMC、电源完整性、可维修性）
- 给出可执行的修改建议（如"将 R12 改为 4.7kΩ"或"为 U3 增加 100nF 去耦"），一键接受��命令栈
- 引用依据：每条建议附规则依据/历史案例/参考设计，便于追溯
- 审查报告产出（PDF/HTML）：可作为评审材料交付，列出风险等级与处置状态

## 关键点
- AI 审查不替代 ERC/DRC，而是"解释 + 启发式补充"，规则违反的判定仍走 [[11-校验与DFX]]
- 所有建议严格 Copilot：可接受/拒绝/撤销；不得静默修改设计
- 模型策略分层：本地小模型做实时问答，云端大模型做深度可靠性分析（隐私敏感走本地）
- 建议须带置信度，低置信度强制要求人工确认，避免误导

## 输入 / 输出
- **入**：DRC/DFM/DFT 结果、当前设计上下文、用户自然语言提问、器件库知识
- **出**：自然语言解释、改进建议（含依据与置信度）、一键修复命令、审查报告
