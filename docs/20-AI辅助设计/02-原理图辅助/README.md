# 20-02 原理图辅助

> 所属 [[20-AI辅助设计]]。在原理图编辑中提供智能连线建议、典型电路模板推荐与缺漏检测（缺去耦/上拉/续流/保护），全部可接受/拒绝/撤销。

## 目标（要实现什么）
- 智能连线建议：基于器件类型与上下文，推荐下一步连接（如 MCU 的 UART 引脚建议连到电平转换），可一键接受
- 典型电路模板推荐：放置某器件时自动推荐配套电路（如放 LDO → 推荐输入/输出去耦电容组合），来自内置与社区模板库
- 缺漏检测：识别常见设计遗漏（缺去耦电容、缺上拉、缺续流二极管、缺 ESD 保护、未连接电源/地），分级提示
- 电源地完整性快检：粗略识别电源链路异常（电压不匹配、电源域跨越未电平转换）
- 推荐网络命名（基于功能上下文，如 `UART_TX`/`I2C_SCL`），保持命名一致性
- 互动式接受/拒绝：建议作为"幽灵图元"叠加显示，确认后落入命令栈

## 关键点
- 缺漏检测须区分"硬错误"（必接未接）与"软建议"（惯例做法），避免噪音
- 模板库须可由 [[18-扩展生态/04-市场]] 扩展，企业可沉淀私有最佳实践
- 所有建议须可解释、可撤销，绝不静默修改原理图
- 与 [[11-校验与DFX]] 的 ERC 联动：AI 检测的是"惯例性"问题，ERC 检测"规则性"问题，互补不重叠

## 输入 / 输出
- **入**：当前原理图上下文、器件库知识、电路模板库、用户操作历史
- **出**：连线建议、模板插入建议、缺漏警告、网络命名建议（均带置信度与理由）
