# 20-07 原理图理解与生成

> 所属 [[20-AI辅助设计]]。实验性方向：从自然语言/网表/参考设计生成原理图框架，以及对现有原理图做语义理解（功能分块、信号流分析）。

## 目标（要实现什么）
- 从自然语言描述生成原理图框架（如"ESP32 + 温湿度传感器 SHT41，I2C 连接，USB-C 供电"→ 生成包含主控、传感器、电源、连接关系的草图）
- 从网表/参考设计文档（PDF/datasheet 应用电路）提取并生成可编辑原理图
- 原理图语义理解：自动识别功能模块（电源区、MCU 区、传感器区、接口区），输出功能分块视图
- 信号流分析：从输入到输出追踪信号路径，辅助理解电路工作原理
- 图像/截图输入：导入手绘草图或 PDF 原理图，识别并生成本品工程（实验性，标注精度边界）
- 所有生成结果落入命令栈，用户可整体撤销并迭代修正

## 关键点
- 明确标注为"实验性"：生成质量参差，须用户校验；不得作为最终设计直接使用
- 生成结果须通过 ERC 与 [[20-AI辅助设计/05-AI设计审查]] 双重把关后用户才可放心采用
- 与器件库强绑定：生成的器件必须是库中存在的真器件，而非虚构符号
- 适合作为"快速起点"场景：原型阶段、教学示例、POC

## 输入 / 输出
- **入**：自然语言描述、网表、参考设计 PDF/图像、器件库
- **出**：原理图草图（可编辑）、功能分块视图、信号流图、不确定性标注

## 依赖
- **上游**：P7（原理图编辑器）、P6（器件库）、[[20-AI辅助设计/08-模型策略]]（依赖云端大模型）
- **下游**：[[20-AI辅助设计/05-AI设计审查]]（审查生成结果）、[[20-AI辅助设计/02-原理图辅助]]（生成后继续辅助）
