# 20-04 自动布线增强

> 所属 [[20-AI辅助设计]]。在传统自动布线之上叠加 AI 增强：差分对、等长、绕障、高速约束、批量重布等高阶场景的智能建议。

## 目标（要实现什么）
- 在交互式布线中实时给出绕障建议（推挤/绕行），可一键接受下一最优路径
- 差分对自动耦合布线：自动等长、等间距、按阻抗规则自适应线宽/线距（与 [[12-SI-PI分析]] 联动）
- 等长蛇形自动生成：基于时序约束（DDR/高速串行）自动计算需要的蛇形补偿长度
- 高速约束感知：自动满足阻抗、参考层、过孔 stub 最小化、敏感信号远离干扰源等规则
- 批量重布：用户改动某区域布局后，AI 自动重布受影响网络的建议方案，可批量接受/撤销
- 拥塞预测：布线前给出预估布通率与瓶颈区域，提示用户调整布局

## 关键点
- AI 增强不替代确定性布线算法，而是在其上做决策建议与参数推荐
- 所有自动布线结果作为命令栈操作可整体撤销，"撤销 AI 这次布线"必须一键可达
- 与 [[12-SI-PI分析]] 实时联动：布线建议给出预估阻抗/延迟/串扰，便于前置把关
- 性能目标：万线级板子的批量重布在分钟级完成，交互式建议毫秒级响应

## 输入 / 输出
- **入**：布局结果、约束（差分/等长/阻抗）、叠层结构、SI/PI 模型
- **出**：布线路径建议、绕障方案、蛇形补偿、拥塞热图、预估阻抗/延迟
