# 20-06 对话式助手

> 所属 [[20-AI辅助设计]]。提供自然语言交互入口（侧边对话面板），基于当前电路上下文做问答、教学、排错，并将用户意图映射到可执行、可撤销的操作。

## 目标（要实现什么）
- 提供常驻侧边对话面板：自然语言提问、命令执行、状态查询一站式入口
- 上下文感知：助手读取当前工程上下文（选中的图元、当前页、违反列表、网表），回答"这个器件为什么报错？"等问题
- 意图映射到操作：如"为 U3 加一个 100nF 去耦" → 生成命令并预览，确认后入栈
- 教学模式：解释概念（"什么是差分对"、"为什么要等长"），结合当前设计举例
- 排错引导：根据报错/DRC 违反，引导用户逐步定位与修复（"先看这个网络的连接"）
- 多轮上下文记忆：保持对话上下文，支持追问、修正、迭代

## 关键点
- 严格 Copilot：对话产生的设计变更一律预览 + 确认 + 入栈，AI 不直接改工程
- 上下文 token 控制：选择性注入相关上下文（不要把整个工程塞给模型）
- 模型策略：本地小模型处理简单问答/命令解析，云端大模型处理复杂解释与设计建议
- 隐私：默认不上传工程细节到云端；用户可显式选择"发送当前设计到云端深度分析"

## 输入 / 输出
- **入**：用户自然语言、当前工程上下文、对话历史、命令栈
- **出**：自然语言回复、操作预览（命令 + diff）、教学解释、上下文相关的下一步建议
