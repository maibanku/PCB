# 20-03 自动布局

> 所属 [[20-AI辅助设计]]。基于约束（机械/电气/热/制造）与学习优秀设计，给出智能布局建议与自动布局方案，用户可接受/拒绝/撤销。

## 目标（要实现什么）
- 接受约束输入：板框、禁布区、高度限制区、连接器位置、关键器件预置、热源、敏感信号区
- 基于连接密度（力导向 / 谱聚类）生成初始布局，最小化总线长与交叉
- 考虑电气约束：去耦电容贴近 IC、晶体振荡器贴近 MCU、模拟/数字分区、电源模块靠近负载
- 考虑热约束：热敏器件远离热源，散热路径优化（与 [[10-3D与机械协同]] 联动）
- 考虑制造约束：回流焊方向、器件间距、波峰焊元器件排布（与 [[11-校验与DFX/07-DFA可装配性]] 联动）
- 学习模式：从用户历史布局或导入的优秀设计提取模式，逐步个性化推荐
- 互动式接受：可锁定部分已布器件，让 AI 在剩余空间内优化；可逐步精化

## 关键点
- 自动布局须在"秒级"反馈，复杂板使用启发式 + 局部优化，避免长时阻塞
- 严格 Copilot：布局变更作为单一可撤销命令入栈，支持一键回退到 AI 操作前
- 必须与 DRC/制造约束实时联动，AI 布局不得违反间距/高度规则
- 可解释：每个布局决策给出理由（如"去耦 C1 贴近 U3 的 VCC 引脚"）

## 输入 / 输出
- **入**：板框/约束、网表连接关系、热/制造约束、用户锁定标记、历史布局样本
- **出**：布局建议（坐标 + 旋转 + 层）、布局理由、约束违反报告（应为空）、可视化预览
