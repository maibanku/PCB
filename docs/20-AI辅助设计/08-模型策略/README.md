# 20-08 模型策略

> 所属 [[20-AI辅助设计]]。统一管理本地小模型与云端大模型的混合调度策略，保证隐私敏感电路走本地、重任务走云端，所有 AI 子功能共用。

## 目标（要实现什么）
- 提供统一模型调度层：所有 AI 子功能（选型/辅助/布局/布线/审查/对话/生成）通过该层选择模型
- 本地小模型（如量化后 1-7B 模型）：处理简单问答、命令解析、缺漏检测、隐私敏感工程的所有任务
- 云端大模型：处理深度分析、复杂推理、原理图生成等重任务，仅在用户授权且工程允许上传时启用
- 隐私分级策略：工程标记为"敏感"时强制走本地，禁止任何数据上传；用户可手动覆盖并记录审计
- 模型可插拔：支持 OpenAI/Anthropic/本地 Ollama/llama.cpp 等多后端，配置驱动切换
- 缓存与降级：相同 prompt 缓存命中避免重复调用；云端不可用时降级到本地，并明确告知用户质量差异
- 成本与配额：统计 token 消耗、按用户/工程预算告警；企业版可设统一账单与上限

## 关键点
- 隐私优先：默认本地，云化为显式 opt-in；任何上传须明示用户并留审计
- 模型版本管理：记录每条建议使用的模型与版本，便于可复现与回归对比
- 不破坏确定性：模型仅给建议，决策权与变更权在用户；AI 不写入工程状态
- 离线可用性：核心 AI 能力（基础选型、规则解释、命令解析）必须可离线工作

## 输入 / 输出
- **入**：各 AI 子功能的 prompt/request、工程隐私标记、用户授权、模型后端配置
- **出**：路由决策（本地/云端）、模型响应、token/成本统计、审计日志
