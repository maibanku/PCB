# 20-AI辅助设计

> 对应 **Plan P20**（Phase 5 · 差异化）。以 AI Copilot 模式贯穿器件选型、原理图、布局、布线、审查与对话式交互，构成项目核心差异化能力之一。

## 定位
- **做什么**：在选型、原理图、布局、布线、设计审查等环节提供 AI 建议与自动化，并通过对话式助手与原理图理解/生成（实验性）降低设计门槛。
- **不做什么**：**严格遵守 Copilot 模式——所有 AI 建议均可接受/拒绝/撤销，绝不破坏核心引擎的确定性**；AI 不直接改写工程状态，所有变更须经用户确认后落入命令栈。
- **代码位置**：`eda/ai`（见 [[00-总览/03-项目目录结构]]）
