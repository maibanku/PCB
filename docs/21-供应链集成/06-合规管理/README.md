# 21-06 合规管理

> 所属 [[21-供应链集成]]。管理 RoHS/REACH/无铅/冲突矿物等合规属性，按目标市场（EU/US/CN）输出合规报告，避免合规风险导致产品无法上市。

## 目标（要实现什么）
- 维护器件级合规属性：RoHS 状态、REACH SVHC 含量、无铅工艺、冲突矿物（3TG）声明、卤素状态
- 按目标市场/认证（EU RoHS、US RoHS、中国 RoHS、REACH、UL、CE、FCC 等）配置合规规则集
- BOM 级合规检查：聚合所有器件合规属性，识别不合规器件与高风险项
- 与 [[21-供应链集成/07-供应商对接]] 联动：自动拉取厂商合规声明/Certificate，缺失时提示补全
- 合规报告导出：BOM 合规汇总、不合规器件清单、需替换建议（联动 [[21-供应链集成/02-替代料推荐]]）
- 证书/声明文档归档：与工程版本绑定，便于应对客户审计与法规追溯

## 关键点
- 合规属性是动态的（SVHC 列表每半年更新），须支持规则集版本化与刷新
- 多市场合规规则不同（EU vs US vs CN RoHS 差异），用户须能选择目标市场
- 缺失数据须明确标注"未声明"，不能默认为合规
- 与 [[21-供应链集成/02-替代料推荐]] 联动：发现不合规器件时推荐合规替代

## 输入 / 输出
- **入**：器件合规属性、目标市场规则集、厂商声明/Certificate
- **出**：BOM 合规汇总、不合规清单、合规报告（PDF/Excel）、证书归档包

## 依赖
- **上游**：P6（器件库合规属性）、[[21-供应链集成/07-供应商对接]]（厂商声明）
- **下游**：[[21-供应链集成/02-替代料推荐]]（替换不合规器件）、终端用户（应对审计）
