# 21-05 订单进度跟踪

> 所属 [[21-供应链集成]]。同步并展示订单各阶段状态（生产/质检/物流），在设计内查看生产进度，支持异常告警。

## 目标（要实现什么）
- 聚合多供应商订单状态：从已下单到交付全流程（生产中/质检/SMT 贴片/发货/物流/签收）
- 在工程面板中可视化展示当前订单进度与预计交付时间
- 异常告警：超期、卡在某阶段、缺料暂停、质检不合格等异常主动通知用户
- 支持订单关联到工程/板子，多板多订单统一视图
- 物流追踪：对接物流商接口或解析邮件/SMS 通知，统一时间线
- 历史订单归档：与工程版本绑定，便于追溯"这个版本对应的实物在哪家工厂、何时交付"

## 关键点
- 多供应商状态映射：各家状态术语不一，须归一化到统一状态机
- 同步策略：定时轮询 + Webhook 推送（供应商支持时）+ 用户手动刷新
- 数据只读：不修改设计；状态变化仅作为信息呈现与通知
- 与 [[05-工程与文件系统]] 工程版本绑定，支持"设计版本 ↔ 实物订单"双向追溯

## 输入 / 输出
- **入**：订单号、供应商 API/通知、用户工程关联
- **出**：统一状态时间线、预计交付时间、异常告警、历史订单归档

## 依赖
- **上游**：[[21-供应链集成/04-一站式下单]]（订单来源）、[[21-供应链集成/07-供应商对接]]（状态数据源）
- **下游**：用户（信息消费）、[[17-协作与版本]]（订单关联工程版本）
