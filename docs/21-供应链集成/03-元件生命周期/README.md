# 21-03 元件生命周期

> 所属 [[21-供应链集成]]。聚合器件生命周期状态（Active/NRND/EOL/停产），在设计阶段前置预警，避免选用即将停产的料。

## 目标（要实现什么）
- 聚合多源生命周期数据：供应商官方、Octopart/Z2Data 等第三方、社区上报
- 状态分级：Active（推荐）/ NRND（不建议新设计）/ EOL 预告（限定尾货）/ 已停产（禁用）
- 在选型/原理图/PCB/BOM 任何出现器件的地方直观展示状态图标 + 时间线
- 预警规则：新设计自动拒绝 NRND/EOL 料；已有设计出现状态恶化时主动提醒
- 生命周期曲线：展示器件从发布到停产的历史与预测，辅助长期可维护决策
- 与 [[20-AI辅助设计/01-AI选型助手]] 联动：选型时自动排除停产风险高的料

## 关键点
- 生命周期数据时效性：定期刷新 + 关键事件（停产公告）推送通知
- 多源冲突处理：以厂商官方为准，第三方作为补充，冲突时标注来源置信度
- 数据作为只读建议：不直接修改工程，但可在选型阶段作为硬过滤
- 长生命周期产品（工业/医疗）特别需要此能力，避免几年后无料可用

## 输入 / 输出
- **入**：器件料号、多源生命周期数据、用户预警阈值配置
- **出**：生命周期状态标签、预警通知、生命周期曲线、可维护性评分
