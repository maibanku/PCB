# 21-04 一站式下单

> 所属 [[21-供应链集成]]。聚合 PCB 打样 + SMT 贴片 + 物料代购的一站式下单入口，对接嘉立创/华秋等多供应商，在设计内直接生成可生产订单。

## 目标（要实现什么）
- 从已完成的设计一键生成下单包：Gerber/钻孔/坐标/钢网/BOM/IPC-2581，自动匹配各供应商接受格式
- 聚合三类服务：PCB 打样（板厚/铜厚/颜色/工艺参数）、SMT 贴片（基于 BOM+坐标）、物料代购
- 多供应商比价：工艺参数与交期可视对比，价格/交期/口碑多维打分
- DFM 前置检查：下单前自动跑 [[11-校验与DFX]] DFM 规则集，避免到工厂被打回
- 订单配置模板：常用板型/工艺组合可保存为预设，下次一键复用
- 下单走供应商 API（[[21-供应链集成/07-供应商对接]]），订单创建后状态回流到 [[21-供应链集成/05-订单进度跟踪]]

## 关键点
- 本工具不参与支付结算：仅生成订单并跳转/对接供应商，结算与履约走供应商
- 严格 DFM gate：DFM 不通过的板子默认禁用下单，必须显式确认"已知风险强制下单"
- BOM 与坐标文件必须与设计当前状态严格一致，下单前自动重跑一致性检查
- 嘉立创/华秋的工艺参数差异须映射到统一选项模型，避免用户面对不一致表单

## 输入 / 输出
- **入**：完成的设计工程、供应商能力矩阵、工艺参数选择、DFM 规则集
- **出**：可生产订单包、比价结果、DFM 检查报告、订单创建结果（含订单号）

- **下游**：[[21-供应链集成/05-订单进度跟踪]]（订单状态回流）
