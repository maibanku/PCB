# 21-01 BOM配齐

> 所属 [[21-供应链集成]]。从原理图/BOM 雏形出发，跨多供应商实时比对库存、价格、交期、最小起订量，给出"配齐方案"与成本预估，在设计阶段就前置暴露买不到/买不起的风险。

## 目标（要实现什么）
- 从工程 BOM 自动提取位号、料号、用量，生成可配齐任务
- 并行查询多供应商（嘉立创/华秋/立创商城/Mouser/DigiKey 等，走 [[21-供应链集成/07-供应商对接]]）的实时库存/价格/交期/MOQ
- 多维打分推荐"最优配齐方案"：总成本最低、交期最短、单源/多源、库存风险最低
- 暴露风险：标红"某料仅一家有货/低库存/MOQ 不达/即将停产"，前置提示
- 支持手动锁定某供应商/某料号后重新计算其余方案
- 配齐方案可导出（CSV/Excel，含每家供应商下单明细），可一键进入 [[21-供应链集成/04-一站式下单]]

## 关键点
- 数据只读建议：不修改工程；替代/换料决策须经用户确认后落入命令栈
- 价格/库存时效性强：结果带查询时间戳，缓存策略可配置（默认短缓存）
- 多供应商比价须去重料号（同一料号在不同家不同 SKU），提供归一化映射
- 与 [[21-供应链集成/02-替代料推荐]] 联动：某料断货时自动推荐替代并入配齐方案

## 输入 / 输出
- **入**：工程 BOM、供应商实时数据、用户偏好（成本/交期/单源）锁定
- **出**：配齐方案（每料推荐供应商+料号+数量+价格）、风险清单、可导出明细、成本汇总
