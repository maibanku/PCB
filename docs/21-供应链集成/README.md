# 21-供应链集成

> 对应 **Plan P21**（Phase 5 · 差异化）。将价格、可造性、生命周期与合规信息前移到设计阶段，构成项目核心差异化能力之一。

## 定位
- **做什么**：在设计阶段即呈现成本与可造性，提供 BOM 比价、替代料推荐、生命周期预警、一站式下单、订单跟踪与合规管理，并抽象多供应商对接层（嘉立创/华秋/立创商城/Mouser/DigiKey 等接口可配置）。
- **不做什么**：**核心约束是“设计阶段就可见成本/可造性”——所有供应链数据作为只读建议呈现，不直接改写工程；通过多供应商抽象层防止单一渠道断供。** 不自建电商交易系统，下单走供应商。
- **代码位置**：`eda/supply_chain`（见 [[00-总览/03-项目目录结构]]）
