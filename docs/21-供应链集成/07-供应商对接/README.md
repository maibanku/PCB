# 21-07 供应商对接

> 所属 [[21-供应链集成]]。抽象供应商接口为统一适配层（嘉立创/立创商城/华秋/Mouser/DigiKey 等参考档案见 [[参考/厂商档案规范]]），可配置可替换，防单一渠道断供或接口变更。

## 目标（要实现什么）
- 提供统一供应商抽象接口：查库存、查价格、查交期、查生命周期、查合规、下单、查订单状态
- 内置参考适配器集（国内/国际对称，详见 [[参考/厂商档案规范]]）：立创商城、华秋 / Mouser、DigiKey、Octopart
- 适配器插件化：第三方/企业可贡献新供应商适配器（与 [[18-扩展生态/01-插件系统]] 协同）
- 鉴权管理：API Key/OAuth 凭据安全存储（与 [[22-工程化与非功能/04-安全]] 一致），区分用户级/企业级
- 限流与缓存：尊重供应商 API 配额，本地缓存减负，失败优雅降级（一家失败不影响整体）
- 数据归一化：各家字段（料号/封装/单位/币种/状态）映射到统一 schema

## 关键点
- 抽象层是"防断供"的核心：单家供应商接口变更/停止服务，仅需替换适配器
- 凭据安全：API Key 加密存储，不明文写入工程文件，不上传遥测
- 限流策略：各家有不同的速率限制，须有令牌桶/退避机制
- 离线降级：供应商不可达时使用最近一次缓存数据并明确标注"数据可能过期"

## 输入 / 输出
- **入**：统一查询请求（料号/数量/供应商列表）、凭据、缓存策略
- **出**：归一化的库存/价格/交期/合规/生命周期数据、订单操作结果、错误与降级标注
