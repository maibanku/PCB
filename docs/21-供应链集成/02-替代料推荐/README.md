# 21-02 替代料推荐

> 所属 [[21-供应链集成]]。从 Pin 兼容、参数近似、生命周期、库存等多维度推荐替代料，防单源断供；推荐结果可一键替换并落入命令栈。

## 目标（要实现什么）
- 多维度相似度匹配：Pin 兼容（封装+引脚定义）、关键参数近似（电气/封装/工作温度）、供应链可购、生命周期健康
- 分级推荐：完全 Pin 兼容（drop-in 替换）/ 参数近似（需评估）/ 仅封装兼容（需重新设计）
- 提供差异报告：列出原型号与替代料在参数、封装、引脚、供应链状态上的差异
- 联动 [[21-供应链集成/03-元件生命周期]]：优先推荐未停产/未 NRND 的料
- 支持一键替换原理图与 PCB 中的器件（更新料号、参数、必要时封装），落入命令栈可撤销
- 学习反馈：记录用户接受/拒绝的替代对，沉淀企业私有映射表

## 关键点
- Pin 兼容性是核心判定，须基于精确的引脚定义对比，而非仅封装相同
- 替换涉及 PCB 封装变更时须触发 DRC 重检与 ECO 同步（与 [[14-ECO工程变更]] 联动）
- 严格 Copilot：替换建议预览 + 确认 + 入栈；不得静默换料
- 企业私有替代表（approved alternate list）可作为权威源优先于通用推荐

## 输入 / 输出
- **入**：原器件料号、器件库参数、引脚定义、生命周期数据、企业私有替代表
- **出**：替代料候选排序（含相似度/等级/理由）、差异报告、一键替换命令
