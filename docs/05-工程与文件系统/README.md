# 05-工程与文件系统

> 对应 **Plan P5**（Phase 1 · 引擎内核）。定义 EDA 工程的层级结构、开放文本格式与版本/模板/打包能力。

## 定位
- **做什么**：组织 工程 > 板 > 图页 的层级；用 JSON/TOML 等开放文本格式持久化；提供版本快照、工程模板、附件管理与整工程打包归档。
- **不做什么**：不做具体的原理图/PCB 业务数据结构（由 P7/P8 承载）；不做云端协作存储（由 P17 承载）。
- **代码位置**：`core/io, eda/project`（见 [[00-总览/03-项目目录结构]]）
