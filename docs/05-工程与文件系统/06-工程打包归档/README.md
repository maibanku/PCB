# 05-06 工程打包归档

> 所属 [[05-工程与文件系统]]。实现一键工程打包：把工程 + 所有依赖库 + 附件 + 输出物打成自包含归档（`.edapkg`），可离线移交工厂或同事，对方无需配置库即可打开。

## 目标（要实现什么）
- **一键打包**：菜单"工程 → 打包归档..."，向导选择打包内容（工程 / 库 / 附件 / 输出物）
- **依赖库自动收集**：扫描工程引用的所有库单元（符号/封装/3D/器件），打包进归档（与元件库 08-版本管理与依赖锁定 联动），保证离线可开
- **归档格式**：`.edapkg`（zip 容器），内含 `project.toml` + `libs/` + `attachments/` + `output/` + `manifest.toml`（清单）
- **manifest 清单**：记录工程版本、库版本快照、打包时间、源路径���签名（可选）
- **打包模式**：
  - **完整归档**（移交同事）：含所有依赖，可继续���辑
  - **生产归档**（移交工厂）：只含 Gerber/BOM/IPC-2581 + 必要文档，不含源设计
  - **快照归档**（版本归档）：项目里程碑冻结，含历史快照
- **导入/解包**：打开 `.edapkg` 自动解包到工作区，重建依赖链接
- **校验**：打包后自动校验完整性（所有引用可解析、无缺失库）
- **压缩**：默认 zip 压缩，3D 模型等大文件可选去重 + 增量
- **加密（可选）**：企业版支持归档加密（IP 保护）

## 关键点
- **工厂友好**：生产归档模式直出"开箱即造"包（与 D4 制造输出协作），工厂无需装 EDA 软件
- **依赖快照锁定**：打包即冻结库版本，对方打开 100% 复现（不因库更新而漂移）
- **manifest 是真相**：归档内清单记录所有版本，可审计
- **去重压缩**：多板工程共享的库只存一份，避免���积膨胀

## 输入 / 输出
- **入**：当前工程 + 依赖库 + 附件 + 输出物
- **出**：自包含的 `.edapkg` 归档文件
