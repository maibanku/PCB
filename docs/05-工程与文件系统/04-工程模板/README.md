# 05-04 工程模板

> 所属 [[05-工程与文件系统]]。提供工程模板系统：内置常用板型（树莓派 HAT / Arduino Shield / 核心板 / 背板）+ 规则预设 + 叠层预设，新建工程一键生成骨架，避免从零配置。

## 目标（要实现什么）
- **内置模板库**：
  - 板型模板：树莓派 HAT、Arduino Shield、STM32 核心板、USB 转串口模块、LED 矩阵板
  - 行业模板：电机驱动板、电源板（DC-DC）、传感器采集板
- **模板内容**：板框（DXF/预绘）、定位孔、叠层预设（2/4/6 层）、规则预设（线宽/间距/过孔）、默认器件库引用、示例原理图（可选）
- **模板元数据**：`template.toml` 描述（名称、分类、缩略图、版本、作者、标签）
- **新建工程向导**：选模板 → 填工程名/路径 → 生成完整工程骨架（工程树 + 默认图页 + 模板规则）
- **模板参数化**：模板支持变量（如"板尺寸 W×H"，用户填值生成不同尺寸的同型板）
- **自定义模板**：用户可把当前工程"另存为模板"，纳入本地模板库
- **模板市场（远期）**：与 F2 扩展生态协作，社区分享模板
- **模板版本化**：模板带版本号，基于模板创建的工程记录所用版本（可追溯）

## 关键点
- **降低上手门槛**：新手不需要从零配置叠层/规则，选模板即得专业起点
- **板型预设与制造能力挂钩**：模板的规则预设对齐常见工厂能力（如嘉立创 6mil 间距）
- **可分享**：模板本质是工程文件 + 元数据，可打包分享（与 [[06-工程打包归档]] 协作）
- **参数化生成**：避免"每种尺寸一个模板"，变量化让一个模板覆盖一族板

## 输入 / 输出
- **入**：模板库（本地 + 内置）、用户填写的参数
- **出**：完整的初始工程目录（可直接打开编辑）
