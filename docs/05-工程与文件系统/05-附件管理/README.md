# 05-05 附件管理

> 所属 [[05-工程与文件系统]]。管理工程相关的非设计数据：设计说明文档、datasheet 链接、参考资料、图片、外部 PDF，集中归档于工程内，避免散落各处。

## 目标（要实现什么）
- **附件目录**：工程内标准 `attachments/` 目录，分类存放（`docs/`、`datasheets/`、`images/`、`refs/`）
- **附件节点**：工程树（[[01-工程树]]）中可挂"附件"节点，每节点带 `name`、`path`、`type`、`description`、`tags`
- **三类附件**：
  1. **本地文件**：复制进工程目录（PDF、图片、文档），自包含可移交
  2. **外链**：URL 引用（datasheet 官网、Wiki、参考设计），不下载，记录访问日期
  3. **工程内引用**：指向工程内器件的 datasheet（与元件库 04-器件一体化绑定 联动）
- **附件浏览**：双击 PDF 在内置查看器打开；图片在 Inspector 显示预览；URL 在浏览器打开
- **搜索/过滤**：按名称、标签、类型过滤；支持全文索引（PDF 内容，可选）
- **版本/失效检测**：外链定期检查可访问性，失效标记（红色）
- **打包包含**：[[06-工程打包归档]] 时可选包含附件（避免体积过大）
- **注释/批注**：附件可挂笔记（如"这家厂停产了，参考替代料 X"）

## 关键点
- **设计与文档同源**：datasheet 跟着工程走，不依赖外部链接失效
- **三类附件区分**：避免把大文件 datasheet 强塞工程（外链更轻），同时关键资料本地化（防失联）
- **与器件库联动**：器件绑定 datasheet 后，工程自动引用（不重复存储）
- **打包可选**：移交工厂时不一定需要 datasheet（工厂有自己流程），可选排除
