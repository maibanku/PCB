# 05-01 工程树

> 所属 [[05-工程与文件系统]]。实现紧凑的工程树数据模型：工程 > 板子 > 图页（原理图页 / PCB），对标嘉立创紧凑结构，作为整个 EDA 工程的组织骨架。

## 目标（要实现什么）
- 三级层次：**工程（Project）> 板子（Board）> 图页（Sheet/PCB）**
  - 工程可含多板（多板系统级设计，见蓝图 B4 多板）
  - 板子可含多张原理图页 + 多个 PCB（多页原理图 + 多板变体）
- **图页类型**：原理图页（Schematic Sheet）、PCB（板级版图）、3D 装配图、BOM 视图、Gerber 视图
- **树视图 UI**：在左侧 Dock 显示层级，支持展开/折叠/重命名/拖拽重排/右键菜单（新建/复制/删除/导入）
- **双击跳转**：双击图页节点 → 在中心区打开对应编辑器
- **元数据**：每节点带 `name`、`path`、`uuid`、`modified_time`、`thumbnail`（缩略图缓存）
- **激活节点**：当前正在编辑的图页高亮，切换时保存状态（滚动位置/缩放/选中）
- **跨图页引用**：原理图层次块、跨页网络标号（与原理图编辑器 C2 协作）
- **工程树序列化**：进 `project.toml`（与 [[02-开放文本格式]] 协作）

## 关键点
- **紧凑结构**（vs KiCad 松散）：所有图页/板子归属一个工程文件，打开工程即加载全部上下文
- **UUID 稳定标识**：图页/器件用 UUID 而非文件名，重命名/移动不破坏引用（与 ECO 协作）
- **缩略图缓存**：树节点显示图页缩略图，快速识别内容
- **多板支持**：一个工程含主板 + 子板/扩展板，支持板间连接器关系（B4 多板系统级前置）

## 输入 / 输出
- **入**：用户操作（新建/导入/重命名）、`project.toml`
- **出**：工程树结构 + 当前激活图页事件，供编辑器跳转

## 依赖
- **上游**：[[02-开放文本格式]]（project.toml 序列化）、GUI 框架的 Dock 面板（承载树视图）
- **下游**：所有编辑器（原理图、PCB、库编辑器都从工程树打开图页）、ECO 工程变更订单（B3，跨图页同步）
