# 工程与文件系统实现计划（Project & Filesystem）

> 📊 **实现进度**：`[██████████] 100%` · 5/5 Task · ✅ 已实现 · 追踪：[[00-总览/06-前期搭建项目路线]] · 最后更新：2026-07-27

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 按任务逐个实现。步骤使用 `- [ ]` 复选框跟踪。

**Goal:** 搭建自研 EDA 引擎的工程与文件系统——层级化工程树（工程 > 板 > 图页，对标嘉立创紧凑结构）+ 开放文本格式（TOML 为主，Git diff 友好）+ 版本快照 + 工程模板 + 附件管理 + 一键打包归档，最终产出"一个可创建 / 保存 / 加载 / 归档的 EDA 工程，且工程文本可读、可被 Git diff、可离线移交"。

**Architecture:** 在 P1 的 `core/` 下新增 `core/io/`（文件、流、序列化、TOML/JSON 读写器、`res://` 路径解析）；在 `eda/` 业务核心层新增 `eda/project/`（工程树数据模型 + `project.toml` 读写 + 快照 / 模板 / 附件 / 归档）。工程树是整个 EDA 工程的组织骨架：所有编辑器（P6 库 / P7 原理图 / P8 PCB）通过工程树挂载点打开图页；工程树节点在 P2 完成后继承 `Resource`（首版以纯值类型实现，P2 落地后替换为 `Resource` 子类）。`project.toml` 用 TOML 文本持久化（schema 带版本号、字段顺序稳定、列表按 uuid 排序，确保 `git diff` 可读）；二进制资源（3D STEP / 图片 / 字体）以 `res://` 引用单独存储，不混入文本；整工程可一键打包为 `.edapkg` 自包含归档，离线移交。

**Tech Stack:** C++20、CMake ≥ 3.20、GoogleTest、CMake FetchContent；TOML 库（toml++ / tomlplusplus，header-only）；JSON（RapidJSON，header-only）；minizip 或 zlib（打包归档 zip 容器，Task 5 引入）。

## Global Constraints

- **继承 P1 全部约束**：C++20（`-std=c++20`，MSVC 19.29+ 或 GCC 11+）；CMake ≥ 3.20；头源同目录；文件名 `snake_case.h`；类型 `PascalCase`；命名空间 `eda::`；成员变量带尾下划线 `name_`；枚举值 `SCREAMING_CASE`；include 从仓库根解析（`#include "eda/project/project_tree.h"`、`#include "core/io/toml_writer.h"`）；约定式提交（`feat:` / `fix:` / `test:` / `docs:` / `chore:`），每任务结束提交一次；GoogleTest 单元测试 + 集成烟雾测试。
- **术语对齐 [[04-术语表]]**：`project = 工程`、`board = 板`、`page/sheet = 图页`、`schematic = 原理图`、`netlist = 网表`；代码符号 `Project` / `Board` / `Page` / `Schematic`（PascalCase），`tr()` source 用全小写 `project` / `board`。
- **格式 Git-diff 友好（P5 核心）**：所有描述性数据用 TOML 文本持久化；字段顺序在 schema 中固定、不得随实现漂移；列表（boards / pages / dependencies）按 `uuid` 字典序输出；时间戳用 ISO 8601 UTC（`2026-07-27T12:00:00Z`）；布尔 / 枚举用小写下划线（`type = "main"`、`type = "schematic"`）；避免单行嵌套过深（最多两层表嵌套）；同一逻辑树二次保存输出字节级一致（确定性序列化）。
- **二进制资源单独存（不混入文本）**：3D STEP / 位图 / 字体 / 缩略图等以 `res://` 引用，存工程目录下的独立文件（如 `res://models/X.step`、`res://thumbnails/sheet1.png`）；`project.toml` 与 `*.sch.toml` / `*.pcb.toml` 内只出现引用字符串，绝不内嵌 base64。
- **工程自包含 / 可离线移交**：工程目录拷贝到任何机器都能打开（无绝对路径、无盘符依赖、无外部库隐式依赖）；打包归档（`.edapkg`）必须冻结所有依赖库版本，对方 100% 复现。
- **Schema 向后兼容带版本号**：每个文本文件首行（TOML）或首字段（JSON）记录 `schema_version`；破坏性变更走主版本号 + 迁移器（`Migrator` 链：v1 → v2 → v3，旧工程自动升级、不丢数据）；首版 `schema_version = 1`。
- **路径方案三类前缀**：`res://`（工程内，相对工程根）、`user://`（用户级配置 / 模板）、`lib://`（库引用，可被依赖锁定快照替换为 `res://` 以离线化）；统一正斜杠 `/`，禁止入库绝对路径与盘符。
- **UUID 稳定标识**：工程 / 板 / 图页 / 附件等节点用 UUID v4 字符串作主键（非文件名、非自增整数）；重命名 / 移动不破坏引用；UUID 在序列化时**不**重排。
- **第三方**：本 plan 允许引入 toml++ / RapidJSON / minizip（zlib）；其余继承 P1 白名单（GLFW / glad / Vulkan / GoogleTest）。
- **上游契约对齐 P2**：工程树节点（Project / Board / Page）在 P2 完成后将继承 `Resource : RefCounted`，经 `ResourceLoader` / `ResourceSaver` 加载保存；首版以**纯值类型**实现，序列化接口形态与 P2 `.tres` 文本格式对齐（`res://` 路径、`SubResource` 子资源引用、`ResourceCache` 路径唯一缓存预留接口），P2 落地后平滑替换。
- **范围边界**：原理图 / PCB 业务数据结构（`*.sch.toml` / `*.pcb.toml` 的器件 / 走线 / 网络）**不在本 plan**（归 P7 / P8）；本 plan 只实现 `project.toml`（工程树骨架）+ 格式基础设施（`core/io/`）+ 快照 / 模板 / 附件 / 归档。元件库（C1）仅作为依赖项引用，不实现库本身。

```cpp
#include <gtest/gtest.h>
#include "eda/project/project_tree.h"
#include "eda/project/page_type.h"
#include "eda/project/board_type.h"
#include "core/io/path.h"
#include <filesystem>
#include <fstream>
using namespace eda;

namespace {
std::string scratch_file(const std::string& name) {
    auto p = std::filesystem::temp_directory_path() / name;
    return p.string();
}
}  // namespace

TEST(ProjectTreeTest, CreateAddBoardAddPageRoundTrip) {
    // 创建工程 → 加板 → 加图页 → 保存 → 重新加载 → 树结构相等
    ProjectTree tree;
    auto& proj = tree.root();
    proj.set_name("DemoProject");
    auto& main = proj.add_board("MainBoard", BoardType::MAIN);
    main.add_page("Sheet1", PageType::SCHEMATIC, "res://sheets/sheet1.sch.toml");
    main.add_page("PCB1",     PageType::PCB,      "res://boards/pcb1.pcb.toml");
    auto& exp = proj.add_board("Expansion", BoardType::DAUGHTER);
    exp.add_page("Sheet2", PageType::SCHEMATIC, "res://sheets/sheet2.sch.toml");
    proj.add_dependency("lib://standard@1.2.0");

    const std::string path = scratch_file("demo_project.toml");
    ASSERT_TRUE(tree.save(path)) << "save 应成功";

    ProjectTree reloaded;
    ASSERT_TRUE(reloaded.load(path)) << "load 应成功";

    EXPECT_EQ(reloaded.root(), proj);  // 深比较：name/uuid/boards/pages/dependencies 全等
}

TEST(ProjectTreeTest, UuidStableAcrossSaveLoad) {
    ProjectTree tree;
    tree.root().set_name("U");
    auto& b = tree.root().add_board("B", BoardType::MAIN);
    const std::string uuid_before = b.uuid();
    b.add_page("S", PageType::SCHEMATIC, "res://s.sch.toml");

    const std::string path = scratch_file("uuid_demo.toml");
    ASSERT_TRUE(tree.save(path));

    ProjectTree reloaded;
    ASSERT_TRUE(reloaded.load(path));
    const auto* b2 = reloaded.find_board_by_uuid(uuid_before);
    ASSERT_NE(b2, nullptr);
    EXPECT_EQ(b2->uuid(), uuid_before);
    EXPECT_EQ(b2->name(), "B");
}

TEST(ProjectTreeTest, FindByUuidTraversesPages) {
    ProjectTree tree;
    auto& b = tree.root().add_board("MainBoard", BoardType::MAIN);
    auto& p = b.add_page("Sheet1", PageType::SCHEMATIC, "res://s.sch.toml");
    EXPECT_EQ(tree.find_page_by_uuid(p.uuid()), &p);
    EXPECT_EQ(tree.find_page_by_uuid("non-existent-uuid"), nullptr);
}

TEST(ProjectTreeTest, SchemaVersionDefaultsToOne) {
    ProjectTree tree;
    EXPECT_EQ(tree.root().schema_version(), 1);
}

TEST(ProjectTreeTest, LoadsLegacyWithoutDependencies) {
    // 旧工程可能没有 [dependencies] 段，加载不应失败

    {
        std::ofstream f(path);
        f << R"(schema_version = 1
name = "Legacy"
uuid = "11111111-1111-1111-1111-111111111111"

[[boards]]
name = "B"
uuid = "22222222-2222-2222-2222-222222222222"
type = "main"
)";
    }
    ProjectTree reloaded;
    ASSERT_TRUE(reloaded.load(path));
    EXPECT_EQ(reloaded.root().name(), "Legacy");
    EXPECT_TRUE(reloaded.root().dependencies().empty());
}
```

`tests/test_project_diff.cpp`（Git-diff 友好断言）：

```cpp
#include <gtest/gtest.h>
#include "eda/project/project_tree.h"
#include "eda/project/page_type.h"
#include "eda/project/board_type.h"
using namespace eda;

namespace {
void fill(ProjectTree& t) {
    t.root().set_name("DiffProject");
    auto& b = t.root().add_board("MainBoard", BoardType::MAIN);
    b.add_page("Sheet1", PageType::SCHEMATIC, "res://s1.sch.toml");
    b.add_page("Sheet2", PageType::SCHEMATIC, "res://s2.sch.toml");
}
}  // namespace

TEST(ProjectDiffTest, DeterministicOutputByteIdentical) {
    // 同一逻辑树两次序列化 → 字节级一致（Git diff 不会因顺序漂移产生噪声）
    ProjectTree a, b;
    fill(a);
    fill(b);
    // 注意：UUID 是随机的，需用固定 UUID 注入接口测试确定性
    a.root().assign_uuid_for_test("00000000-0000-0000-0000-000000000001");
    b.root().assign_uuid_for_test("00000000-0000-0000-0000-000000000001");
    for (size_t i = 0; i < a.root().board_count(); ++i) {
        const auto u = "10000000-0000-0000-0000-" + std::to_string(i);
        a.root().board(i).assign_uuid_for_test(u);
        b.root().board(i).assign_uuid_for_test(u);
    }
    EXPECT_EQ(a.serialize_to_string(), b.serialize_to_string());
}

TEST(ProjectDiffTest, PagesSortedByUuidInOutput) {
    // 列表按 uuid 字典序输出，避免插入顺序影响 diff
    ProjectTree t;
    t.root().set_name("S");
    auto& b = t.root().add_board("Main", BoardType::MAIN);
    auto& p1 = b.add_page("Z-Page", PageType::SCHEMATIC, "res://z.sch.toml");
    auto& p2 = b.add_page("A-Page", PageType::SCHEMATIC, "res://a.sch.toml");
    p1.assign_uuid_for_test("bbbbbbbb-0000-0000-0000-000000000000");
    p2.assign_uuid_for_test("aaaaaaaa-0000-0000-0000-000000000000");
    const std::string out = t.serialize_to_string();
    auto pos_a = out.find("aaaaaaaa");
    auto pos_b = out.find("bbbbbbbb");
    ASSERT_NE(pos_a, std::string::npos);
    ASSERT_NE(pos_b, std::string::npos);
    EXPECT_LT(pos_a, pos_b);  // a 在 b 之前
}
```

```cpp
TEST(TomlIOTest, RoundTripScalarsAndArrays) {
    TomlWriter w;
    w.set_int("schema_version", 1);
    w.set_string("name", "demo");
    w.set_bool("locked", true);
    w.push_array("tags");
    w.append_string("a");

    EXPECT_EQ(r.array_size("tags"), 2u);
    EXPECT_EQ(r.array_string("tags", 1), "b");
}
```

```cpp
#include "project_io.h"
#include "core/io/toml_reader.h"
#include "core/io/toml_writer.h"
#include "core/io/schema_version.h"
#include "core/io/file.h"
#include <algorithm>

namespace eda {

namespace {
template <typename T>
void sort_by_uuid(std::vector<T>& v) {
    std::sort(v.begin(), v.end(),
              [](const auto& a, const auto& b) { return a.uuid < b.uuid; });
}
}  // namespace

std::string ProjectSaver::serialize(const ProjectTree& tree) {
    const Project& p = tree.root();
    io::TomlWriter w;
    w.set_int("schema_version", p.schema_version());
    w.set_string("name", p.name());
    w.set_string("uuid", p.uuid());
    w.set_int("modified_time", p.modified_time());

    // dependencies：拷贝并按字典序输出
    std::vector<std::string> deps = p.dependencies();
    std::sort(deps.begin(), deps.end());
    w.push_array("dependencies");
    for (const auto& d : deps) w.append_string(d);
    w.pop_array();

    // boards：拷贝并按 uuid 排序（不修改原树）
    std::vector<Board> boards = p.boards();
    sort_by_uuid(boards);
    w.push_array("boards");
    for (const Board& b : boards) {
        w.append_table_begin();
        w.set_string("name", b.name());
        w.set_string("uuid", b.uuid());
        w.set_string("type", std::string(to_string_view(b.type())));

        std::vector<Page> pages = b.pages();
        sort_by_uuid(pages);
        w.push_array("pages");
        for (const Page& pg : pages) {
            w.append_table_begin();
            w.set_string("name", pg.name);
            w.set_string("uuid", pg.uuid);
            w.set_string("type", std::string(to_string_view(pg.type)));
            w.set_string("path", pg.path);
            w.set_int("modified_time", pg.modified_time);
            w.append_table_end();
        }
        w.pop_array();
        w.append_table_end();
    }
    w.pop_array();
    return w.serialize();
}

bool ProjectSaver::save(const ProjectTree& tree, const std::string& path) {
    return io::File::write_text(path, serialize(tree));
}

bool ProjectLoader::load(ProjectTree& tree, const std::string& path) {
    std::string text;
    if (!io::File::read_text(path, text)) return false;
    return parse(tree, text);
}

    // ...（省略：按 schema 反向填充）
    return true;
}

bool ProjectTree::load(const std::string& path) {
    return ProjectLoader::load(*this, path);
}
bool ProjectTree::save(const std::string& path) const {
    return ProjectSaver::save(*this, path);
}
std::string ProjectTree::serialize_to_string() const {

}
```

## 接口契约（跨 Plan 依赖）

- **工程树暴露给所有编辑器（P6 / P7 / P8 挂载点）**：`eda::ProjectTree` 是工程组织骨架的单一入口；编辑器通过 `ProjectTree::find_page_by_uuid(uuid)` 拿到 `Page`，再据 `Page::path`（`res://...`）经 `core/io` 解析为本地文件，由各编辑器（原理图 / PCB / 库）自行加载业务数据（`*.sch.toml` / `*.pcb.toml` 等，schema 由 P7 / P8 定义）。P5 不感知业务文件内容，只提供寻址与挂载点。
- **Resource 序列化接口给 P2（上游）**：`core/io/Serializer` 抽象 + `eda::io::TomlReader / TomlWriter` 提供 `res://` 路径、文本 / 二进制双形态与 `SubResource` 子资源引用语义，对齐 Godot `ResourceFormatLoader / Saver`。P2 落地 `Resource : RefCounted` 后，`Project / Board / Page` 改为继承 `Resource`，`ProjectLoader / Saver` 改为通过 `ResourceLoader::load("res://project.toml")` 分发；首版接口形态已对齐，替换为平滑迁移。
- **开放格式 schema 给 P16 格式兼容（下游）**：本 plan 定义的 `project.toml` schema（`schema_version` / `name` / `uuid` / `boards[]` / `pages[]` / `dependencies[]`）与三类路径前缀（`res://` / `user://` / `lib://`）是 P16 KiCad / Altium / IPC-2581 导入导出的**映射目标**。P16 适配器将外部格式（如 KiCad `.kicad_pro` 的工程结构、`.kicad_sch` 的原理图）转换为本 schema；破坏性 schema 变更走主版本号 + `Migrator` 链（`schema_version.h` 注册），P16 适配器据此选择迁移路径。
- **附件与器件库联动（P6 占位）**：`Attachment::type = INTERNAL_REF` 保留接口，待 P6 器件一体化绑定落地后接入器件 datasheet 引用（同一 datasheet 工程内不重复存储）。
