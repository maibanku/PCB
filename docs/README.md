# EDA 自研软件 · 知识库总索引

> 纯 C++20 自研引擎（借鉴 Godot 架构）的竞品级全栈 EDA 套件知识库。**差异化**：AI 辅助设计 + 供应链集成。**灵魂主线**：端到端"画图 → 验证 → 输出可直接生产文件"闭环。

## 编号体系

- **顶层目录 = Plan**：`01`~`22` 对应 22 个 Plan（**编号即 Plan 号**）；`00-总览` 放跨模块纲领；`参考/` 放对照研究。
- **域内子目录 = 子功能**：每个域下 `MM-中文名` 编号该域的具体业务/功能。
- 每个目录都有 `README.md`（定位 / 子功能 / 依赖 / 状态）。

## MVP 边界

Phase 0+1+2 = **P1–P8、P11、P13、P14**（跑通"画图 → 输出可生产文件"最小闭环）；F3 仅 KiCad 导入子集。

**关键路径**：P1 → P2 → P3/P4（并行）→ P5 → P6 → P7 → P8 → P11 → P13 → P14。

## 工作流（进入某 Plan 时）

1. 查 [[00-总览/03-项目目录结构]] 确认代码目录位置
2. 读对应域 `NN-域名/README.md` + 子功能占位
3. `brainstorming` 细化设计 → `writing-plans` 产出 `plan/` 实现计划
4. TDD 落码（对齐 Godot 目录、CMake、头源同目录、`eda::` 命名空间）
