# EDA 项目实现路线图

> 把功能设计目录（What）转化为**按依赖与优先级排序的 Plan 序列**（How / When）。本文件是纲领，持续维护；具体 plan 快照存于 `plans/`。

## 总目标

端到端**可生产闭环**（A1 主线 7 节点）：建库 → 原理图 → 仿真 → PCB → 校验 → 制造输出 → 供应链下单，ECO 双向贯通，终态产出"开箱即造"生产包。

**全景套件工程量巨大**（附录四风险），故分 6 个阶段、22 个 Plan 渐进交付。每个 Plan 产出**可独立验证的软件**。

---

## 一、分阶段总览

| 阶段 | 主题 | Plan | 终态里程碑 |
|------|------|------|-----------|
| **Phase 0** | 引擎地基 | P1 | 能显示矢量图形的窗口（渲染+输入+画布+主循环） |
| **Phase 1** | 引擎内核 | P2–P5 | 引擎"能用"：对象体系、几何/命令栈、GUI、工程文件 |
| **Phase 2** | **MVP 可生产闭环** ★ | P6–P8, P11, P13, P14 | 跑通"画图 → 输出可生产文件"最小闭环 |
| **Phase 3** | 专业能力补强 | P9, P10, P12, P15 | 仿真、3D 机械、SI/PI、多板系统级 |
| **Phase 4** | 生态与协作 | P16–P19, P22 | 格式兼容、协作、扩展、CLI、工程化 |
| **Phase 5** | 差异化 | P20–P21 | AI 辅助、供应链集成 |

> **关键路径**：P1 → P2 → P3/P4（并行）→ P5 → P6 → P7 → P8 → P11 → P13 → P14（MVP 闭环）。P9/P10 等可在 MVP 后并行补强。

## 三、各 Plan 详细卡片

> 格式：**范围 / 依赖 / 产出 / 对应功能章节**。★ = MVP 必经路径。

### Phase 0：引擎地基

**P1 引擎地基** ★（已有 plan：`plans/2026-07-27-引擎地基实现计划.md`）
- 范围：平台抽象（GLFW 引导）+ 渲染服务器抽象（servers/drivers GL+VK）+ 输入 + 2D 画布 + 主循环
- 依赖：无
- 产出：能显示 EDA 风格矢量图形并响应鼠标缩放的窗口
- 对应：B1（窗口/输入）、B2（渲染部分）、附录三落地节奏①

### Phase 1：引擎内核

**P2 核心对象体系** ★
- 范围：Object 基类 + ClassDB 反射 + Signal + Variant + Resource + Node/SceneTree（工程树即场景树的基础）
- 依赖：P1
- 产出：统一对象模型，可序列化、可反射、可挂信号
- 对应：B3（数据模型基础）、附录三"核心/节点层"

**P3 几何内核 + 命令栈** ★
- 范围：2D 几何（点/线/弧/多边形/路径）+ 布尔运算（Clipper2）+ 偏移 + 空间索引（R-tree）+ 单位坐标系 + 网格吸附；命令栈（Undo/Redo 事务化）+ 选择系统
- 依赖：P2
- 产出：可撤销的几何操作、万级图元碰撞检测
- 对应：B2（几何内核）、B3（命令栈/选择）

**P4 自研 GUI 框架** ★
- 范围：Control 节点体系 + 布局（锚点/容器）+ 主题 + 可停靠 Dock/面板 + 属性 Inspector + 命令面板 + 快捷键体系（KiCad/Altium/嘉立创预设）+ i18n + 无障碍
- 依赖：P1（渲染）、P2（节点）
- 产出：能用自研控件搭出专业编辑器 UI
- 对应：B1（GUI 其余）、附录三"GUI 框架层"、落地节奏②

**P5 工程与文件系统** ★
- 范围：工程树（工程>板>图页）+ 开放文本格式（JSON/TOML，Git 友好）+ 版本快照 + 工程模板 + 附件管理 + 工程打包归档
- 依赖：P2（Resource 序列化）
- 产出：可保存/加载/归档的工程
- 对应：B4（除多板）

### Phase 2：MVP 可生产闭环 ★

**P6 元件库体系** ★
- 范围：符号库编辑器 + 封装库编辑器 + 3D 模型库关联 + 器件一体化绑定（符号+封装+3D+参数+SPICE+供应链占位）+ 库层级（本地/云端/企业）+ 库向导（IPC-7351 封装生成器）+ 库搜索 + 版本管理+依赖锁定
- 依赖：P2、P3、P5
- 产出：可建/可搜/可锁版本的标准器件库
- 对应：C1

**P7 原理图编辑器** ★
- 范围：图元（器件/导线/网络标号/总线/电源端口/层次块/子图/端口/注释/图片）+ 绘制放置（栅格吸附/正交/任意角）+ 层次化设计 + 网络表生成 + ERC + 位号标注 Annotate + 复用模块 + BOM 雏形 + 原理图 PDF 输出
- 依赖：P3、P4、P5、P6
- 产出：能画原理图、出网表、过 ERC
- 对应：C2

**P8 PCB 编辑器** ★（最大，建议拆 P8a/P8b/P8c）
- P8a：板框（矩形/圆/异形/DXF 导入/开槽/定位孔）+ 图层体系 + 叠层管理器 + 阻抗计算 + 设计规则/约束管理器 + 放置/布局（移动/旋转/对齐/推挤/碰撞）
- P8b：布线（交互推挤绕障/差分对/总线/蛇形等长/自动布线/拆线重布）+ 铺铜（动态/热焊盘/避让/重建）+ 盲埋孔/背钻/阻抗控制 + DRC（实时+全板）+ 长度延迟显示
- P8c：3D 实时预览切换 + 尺寸标注 + 测试点
- 依赖：P3、P4、P5、P6、P7（网表）
- 产出：能布局布线、过 DRC、出物理版图
- 对应：C3

**P11 统一校验框架 + DFX** ★
- 范围：ERC+DRC+一致性检查统一中心 + 自定义规则语言（脚本化）+ 电气网络分析 + 结果面板（分级/定位/忽略/批修建议）+ 规则集预设；DFM/DFA/DFT + DFX 报告
- 依赖：P7、P8
- 产出：一站式校验，可定位可修复
- 对应：D1、D2

**P13 制造与装配输出** ★
- 范围：Gerber(RS-274X)+Excellon 钻孔+Pick&Place 坐标 + 钢网 Gerber + IPC-2581/ODB++ + BOM(CSV/Excel) + 装配图/制造图/钻孔图 PDF + DXF + 3D STEP + 拼板面板化（V-cut/邮票孔/工艺边/阴阳板）+ 输出模板批处理 + 制造前检查
- 依赖：P8
- 产出：一键产出"开箱即造"完整生产包
- 对应：D4

**P14 ECO 工程变更订单** ★（可紧随 MVP 闭环）
- 范围：原理图↔PCB 双向同步 + 差异检测 + ECO 列表 + 选择性应用 + 变更预览/日志/回滚 + 审计
- 依赖：P7、P8
- 产出：设计变更可审查可回滚地贯通
- 对应：B3（ECO）

### Phase 3：专业能力补强

**P9 仿真集成**
- 范围：ngspice 集成 + 仿真模型库（关联器件库）+ 分析类型（DC/AC/瞬态/噪声/蒙特卡洛/参数扫描）+ 波形查看器（多迹/游标/测量/数学/FFT）+ 原理图联动（激励源/探针）+ 第三方模型导入
- 依赖：P7
- 对应：C4

**P10 3D 与机械协同**
- 范围：3D 查看器（剖面/测量/爆炸图）+ STEP/IGES/OBJ/VRML 导入导出 + 装配干涉检查 + 机械 CAD 协同（外壳对位）+ 高度限制区 + 渲染输出（高清/3D PDF）
- 依赖：P1（渲染 3D 扩展）、P8
- 对应：C5

**P12 SI/PI 信号与电源完整性**
- 范围：SI（阻抗/串扰/反射/过孔 stub/眼图，需 IBIS）+ PI（电源平面/去耦优化/IR Drop/目标阻抗）+ 叠层规则联动 + 报告建议
- 依赖：P8
- 对应：D3

**P15 多板/系统级设计**
- 范围：一系统多 PCB + 连接器/线缆关系 + 板间信号连通性检查
- 依赖：P5、P8
- 对应：B4（多板）

### Phase 4：生态与协作

**P16 格式兼容层 ★（F3）**
- 范围：导入导出各 EDA 格式（KiCad/Altium/Eagle/OrCAD/PADS/立创EDA/Protel/DesignSpark/gEDA）+ 元件库格式 + DXF/DWG + ODB++/IPC-2581/Gerber 反向解析 + 3D + 网表；迁移向导 + 保真度报告 + 适配器插件化
- 依赖：P5、P6、P7、P8
- 产出：能从其他 EDA 迁入工程，附保真度报告
- 对应：F3
- MVP 子集：**KiCad 工程导入优先**（最常见开源格式），其余格式后补

**P17 协作与版本**
- 范围：本地快照 + Git 集成 + 图形化 diff + 轻量云同步 + 评论/批注/评审 + 工程包分享
- 依赖：P5
- 对应：F1

**P18 扩展生态**
- 范围：插件系统（C++ GDExtension 思路 + 沙箱 + 权限）+ 脚本支持（类 GDScript 或嵌入 Python）+ 脚本/外部 API + 市场（主题/图标/符号/封装/模板）
- 依赖：P2、P4
- 对应：F2

**P19 工具链 CLI**
- 范围：无头导出 Gerber/BOM/PDF/ERC/DRC + 版本控制钩子（提交前 DRC）+ 与 KiCad/Altium 互转
- 依赖：P11、P13、P16
- 对应：F4

**P22 工程化与非功能**（贯穿，集中收尾）
- 范围：性能基准（万焊盘流畅目标）+ 多核/GPU 利用 + 无障碍 WCAG + 安全（插件沙箱/接口鉴权/遥测可控）+ 测试策略（几何/规则/格式适配器单测+回归）+ 打包分发（Win/Mac/Linux 安装包/签名/自动更新）+ 文档（手册/API/规则语言/格式规范）
- 依赖：全部
- 对应：F5

### Phase 5：差异化

**P20 AI 辅助设计 ★（E1）**
- 范围：AI 选型助手 + 原理图辅助（连线建议/电路模板/缺漏检测）+ 自动布局 + 自动布线增强（差分/等长/绕障）+ AI 设计审查（自然语言 DRC/DFM/可靠性）+ 对话式助手 + 原理图理解/生成（实验）+ 模型策略（本地小模型+云端大模型，隐私敏感走本地）
- 依赖：P6、P7、P8、P11
- 约束：Copilot 模式，所有建议可接受/拒绝/撤销，不破坏确定性
- 对应：E1

**P21 供应链集成 ★（E2）**
- 范围：BOM 配齐（多供应商比价）+ 替代料推荐（Pin 兼容/参数近似/生命周期）+ 元件生命周期管理（EOL/NRND 预警）+ 一站式下单（PCB 打样+SMT+物料代购）+ 订单进度跟踪 + 合规管理（RoHS/REACH/无铅/冲突矿物）+ 供应商对接（嘉立创/华秋/立创商城/Mouser/DigiKey，接口可配置）
- 依赖：P6（供应链信息预置）、P13
- 约束：设计阶段就可见成本/可造性，多供应商抽象层防断供
- 对应：E2

## 四、MVP 边界（明确）

**MVP = Phase 0 + 1 + 2**，即 P1–P8、P11、P13、P14，跑通"画图 → 输出可生产文件"最小闭环。

**MVP 必含**：
- 引擎地基 + 对象/几何/GUI/工程 四件套（P1–P5）
- 元件库 + 原理图 + PCB + 校验 + 制造输出 + ECO（P6–P8、P11、P13、P14）

**MVP 可简化/后置**：
- F3 格式兼容：只做 **KiCad 工程导入**（P16 子集），其余格式二期
- DFT 可测试性：MVP 只做基础测试点放置，完整 DFT 二期
- 多板/系统级（P15）：二期
- 仿真/3D/SI-PI（P9/P10/P12）：二期
- AI/供应链（P20/P21）：二期差异化

**MVP 不做**：实时多人协同（F1 仅 Git+云同步）、自研 Web 版。

## 六、使用说明

- 每进入一个 Plan，用 `superpowers:brainstorming` → `writing-plans` 产出该 Plan 的详细实现计划，存 `plans/YYYY-MM-DD-<名>.md`
- Plan 内部仍遵循 TDD / bite-sized / Godot 对齐目录（见 P1 plan 的 Global Constraints）
- 本路线图随决策演进更新；功能细节以 `从零搭建EDA软件-功能设计目录.md` 为权威
