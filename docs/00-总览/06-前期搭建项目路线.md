# 06 前期搭建项目路线

> **前期搭建**（Phase 0 + Phase 1）的可勾选任务路线：从空仓库到"引擎地基就绪、可进入 MVP 0.1 PCB 闭环开发"。每项完成即勾选 `- [x]` 并附完成日期；对应内部 plan 文档**开头徽章同步更新**。本路线是 [[00-总览/02-实现路线图]] 的**执行级切片**（P1–P5 关键路径），不替换 22 Plan 体系。

## 一、完成状态标记规则

**路线图（本文件）**：
- `- [ ]` 未开始 · `- [x]` 已完成（附 `✅ YYYY-MM-DD`）· `🚧` 进行中
- 里程碑：🔴 未达 / 🟡 进行中 / 🟢 已达

**内部文档（各 plan）开头徽章**——每份 plan 标题下必含：
```
> 📊 完成进度：[██░░░░░░░░] 20% · 2/10 Task · status: 实现中 · 追踪：[[00-总览/06-前期搭建项目路线]]
```
- 进度条 10 格（█ 完成 / ░ 未完成）
- `status` 演进：`待实现`（未起草/刚起草）→ `设计中`（plan 起草完）→ `实现中`（首个 Task 开工）→ `已实现`（全部 Task 通过验收）

**勾选责任**：每完成一个 Task（含测试 PASS + 约定式提交），① 路线图勾选 + 日期 ② 更新 plan 开头徽章 ③ 更新 plan frontmatter `status`。

P1 (M0) ──→ P2 (M1) ──┬─→ P3 (M2) ──┐
