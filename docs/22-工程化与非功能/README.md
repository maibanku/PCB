# 22-工程化与非功能

> 对应 **Plan P22**（贯穿）。集中收尾的工程化与非功能性要求，作为横切关注点贯穿各 Phase，保障产品质量与可交付性。

## 定位
- **做什么**：集中承接性能基准、多核与 GPU 利用、无障碍、安全、测试策略、打包分发与文档等非功能性要求，作为贯穿全周期的横切关注点进行集中收尾。
- **不做什么**：不替代各功能域自身的工程实践，仅提供统一基准、工具与验收口径。
- **代码位置**：跨全局（`tests/`、`docs/`、打包脚本等，见 [[00-总览/03-项目目录结构]]）
