# 22-02 多核与GPU利用

> 所属 [[22-工程化与非功能]]。规划渲染、几何运算、DRC、AI 推理等任务的并行化与 GPU 加速策略，把多核 CPU 与 GPU 算力转化为万焊盘级流畅体验。

## 目标（要实现什么）
- 渲染层 GPU 加速：Vulkan 优先（借鉴 Godot `RenderingDevice`）+ OpenGL/Metal 后端，2D 图元 CanvasItem 式批渲染
- DRC/几何运算并行化：基于任务图（task graph）调度到多核，万级图元碰撞检测线性加速
- 增量渲染 + 脏区刷新：仅重绘变化区域，避免全帧重绘
- GPU 拾取（picking）：鼠标命中测试走 GPU，避免 CPU 遍历
- AI 推理后端：本地模型支持 CPU/GPU/NPU 切换，自动选择最优后端
- 计算密集任务（铺铜重建/阻抗计算/SI 仿真）异步并行，不阻塞 UI 主循环

## 关键点
- GPU 抽象须有 CPU 软件回退路径，无 GPU 环境也能工作（CI/无头场景）
- 多线程数据竞争：核心数据结构须支持只读快照 + 写时复制或细粒度锁
- 任务调度须可观测：profiler 暴露线程利用率、任务等待时间
- 移动端/入门硬件降级：自动降低 LOD、关闭特效，保证可用性

## 输入 / 输出
- **入**：硬件能力探测（CPU 核数/GPU 型号/显存）、任务负载特征
- **出**：并行调度策略、GPU 资源分配、性能数据反馈给 [[22-工程化与非功能/01-性能基准]]

## 依赖
- **上游**：P1（引擎地基 GPU 抽象）、P3（几何/命令栈并发设计）、[[22-工程化与非功能/01-性能基准]]
- **下游**：全部计算/渲染密集功能域（PCB 编辑、DRC、3D、AI、仿真）
