# 22-07 文档

> 所属 [[22-工程化与非功能]]。建立用户手册、API 文档、规则语言参考、格式规范、教程等多层次文档体系，并保证文档与代码同步演进。

## 目标（要实现什么）
- 用户手册：覆盖建库→原理→PCB→验证→输出→下单全流程，含图文教程与视频引导
- API 文档：进程内 API（C/C++ ABI）、外部 API（IPC/RPC）、脚本绑定的完整参考，自动从源码生成
- 规则语言参考：自定义 DRC/ERC 规则语言的语法、内置函数、示例库
- 格式规范：自有开放工程格式规范、对各家格式（KiCad/Altium/ODB++/IPC-2581）的导入导出能力与保真度说明
- 教程与示例：新手入门 5 板（LED 闪烁/USB 串口/传感器板等）、进阶专题（差分布线/阻抗控制/拼板）
- 企业最佳实践：库管理、协作流程、CI/CD 集成、规则集沉淀

## 关键点
- 文档即代码：Markdown + 静态站点生成（类 Docusaurus/MkDocs），版本化与代码同步
- API 文档自动生成：从 C++ 头文件 + 注释提取，避免手写漂移
- 多语言：中英为主，社区可贡献翻译；与 B1 i18n 协同
- 文档可搜索、可反馈（每页"是否有帮助"+ 编辑建议入口）
- 与 [[18-扩展生态/04-市场]] 协同：第三方插件/规则集可附自有文档

## 输入 / 输出
- **入**：源码（API 注释）、格式规范、规则语言定义、用户反馈
- **出**：在线文档站点、离线 PDF 手册、上下文帮助（编辑器内 ? 按钮）、API 参考包

## 依赖
- **上游**：全部功能域（提供文档素材）、[[18-扩展生态/02-脚本支持]]（脚本 API 文档）
- **下游**：终端用户、社区贡献者、企业培训
