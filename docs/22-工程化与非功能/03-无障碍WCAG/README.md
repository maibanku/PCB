# 22-03 无障碍WCAG

> 所属 [[22-工程化与非功能]]。提供完整的无障碍支持：键盘全操作、读屏适配、高对比度、界面缩放、色觉无障碍，对标 WCAG 2.1 AA。

## 目标（要实现什么）
- 键盘全操作：所有编辑/导航/命令可仅用键盘完成，无强制鼠标路径
- 读屏适配：自绘 UI 暴露无障碍树（UI Automation/AT-SPI/NSAccessibility），支持 NVDA/VoiceOver/Orca
- 高对比度主题：内置高对比度配色，符合 WCAG AA 文字/图元对比度
- 界面缩放：50%-400% 无极缩放，支持高 DPI 与视力辅助需求
- 色觉无障碍：颜色不仅作为唯一信息载体（如 DRC 错误同时用形状/图标/文字标注），提供色盲友好调色板
- 减少动效：尊重系统"减少动画"设置，关闭非必要动画

## 关键点
- 自绘 GUI 的无障碍是难点：须显式构建无障碍树映射到平台 AT API
- EDA 图元的无障碍描述：器件/网络/违反项须有清晰文本描述，便于读屏
- 无障碍测试纳入回归：自动化检查对比度/键盘可达性
- 快捷键体系对齐 B1，提供 KiCad/Altium/嘉立创预设降低迁移成本

## 输入 / 输出
- **入**：WCAG 2.1 AA 规则集、平台 AT API、用户无障碍偏好
- **出**：无障碍树、高对比度主题、键盘焦点可视化、对比度检查报告

## 依赖
- **上游**：P1（平台抽象提供 AT API 接入）、P4（GUI 框架构建无障碍树）
- **下游**：终端用户（视障/色盲/键盘偏好用户）、企业无障碍合规需求
