# 22-04 安全

> 所属 [[22-工程化与非功能]]。覆盖插件沙箱、外部接口鉴权、供应链凭据保护、可控遥测与崩溃上报等安全面，作为横切关注点贯穿全产品。

## 目标（要实现什么）
- 插件沙箱：[[18-扩展生态/01-插件系统]] 的进程级隔离 + 权限清单 + 签名校验，未签名/越权插件默认禁用
- 外部 API 鉴权：[[18-扩展生态/03-外部API]] 的 IPC/RPC 走 Token + 来源校验 + 限流
- 凭据安全存储：供应链 API Key/OAuth 加密存储（OS Keychain/Credential Manager/libsecret），不明文落盘
- 遥测可控：默认 opt-in 或最小化遥测，崩溃报告可关，敏感数据（工程内容/路径）脱敏
- 工程文件安全：加载第三方工程时沙箱化解析，防止恶意工程文件利用解析漏洞
- 供应链安全：下载的插件/库资源走签名校验 + 来源白名单（与 [[18-扩展生态/04-市场]] 协同）
- 安全更新通道：CVE 修复走紧急通道，自动更新优先推送安全补丁

## 关键点
- 安全默认：敏感能力默认关闭，用户显式开启；最小权限原则贯穿
- 威胁模型文档化：明确防范范围（恶意插件/恶意工程文件/供应链攻击/本地数据窃取）
- 与 [[18-扩展生态/01-插件系统]]、[[18-扩展生态/03-外部API]]、[[21-供应链集成/07-供应商对接]] 强耦合
- 安全审计日志：所有敏感操作（凭据访问/插件加载/外部调用）可审计
- 职责边界：崩溃**上报**（遥测、minidump 收集）属本节与 P1 平台抽象；崩溃**恢复**（crash-safe 自动保存 + 重启后恢复未保存工作）属 [[05-工程与文件系统]]（P5 版本快照/原子写入），不在本节范围

## 输入 / 输出
- **入**：插件/外部调用/凭据/遥测配置、威胁模型、用户授权决策
- **出**：鉴权决策、沙箱运行时、加密凭据、脱敏遥测数据、审计日志

## 依赖
- **上游**：P1（平台抽象的 OS Keychain/进程隔离）、[[18-扩展生态/01-插件系统]]
- **下游**：[[18-扩展生态/03-外部API]]、[[21-供应链集成/07-供应商对接]]、[[20-AI辅助设计/08-模型策略]]（隐私分级）
