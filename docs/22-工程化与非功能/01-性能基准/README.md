# 22-01 性能基准

> 所属 [[22-工程化与非功能]]。定义万焊盘/万器件级的性能目标（对标嘉立创 WebGPU 万焊盘能力），建立可重复运行的基准测试套件，作为性能回归与对外承诺的客观口径。

## 目标（要实现什么）
- 定义核心性能指标：万焊盘渲染帧率（≥60fps）、万器件原理图加载时延、铺铜重建时延、全板 DRC 时延
- 建立标准基准工程集：小（千焊盘）/中（万焊盘）/大（十万焊盘）三级，覆盖原理图/PCB/铺铜/DRC/导出
- 提供自动化基准工具：CLI 一键跑全部用例，产出 JSON/HTML 报告（含火焰图、内存、GPU 利用率）
- 性能回归 gate：每次 PR 自动跑基准，对比基线，回归超阈值（如帧率下降 >5%）阻断合并
- 跨硬件基准矩阵：覆盖入门集显/中端独显/高端独显/Apple Silicon，给出最低硬件建议
- 长时稳定性：连续编辑 1 小时的内存泄漏/性能衰减检测

## 关键点
- 基准工程须可公开复现，避免依赖商业库；用合成工程 + 真实采样
- 性能数据须分场景报告：交互式编辑/无头批量/3D 渲染，不可混为一谈
- 与 [[22-工程化与非功能/05-测试策略]] 协同，基准作为 CI 的一个测试类别
- 性能问题定位工具：内置 profiler 钩子，可导出 chrome tracing 格式便于分析

## 输入 / 输出
- **入**：标准基准工程集、目标硬件配置清单、性能阈值
- **出**：基准报告（帧率/时延/内存/GPU）、回归告警、性能趋势曲线

## 依赖
- **上游**：全部功能域（提供可度量场景）、[[22-工程化与非功能/05-测试策略]]（CI 集成）
- **下游**：[[22-工程化与非功能/02-多核与GPU利用]]（优化依据）、用户（最低硬件建议）
