# 厂商档案规范（供应商 + 工厂能力）

> **目的**：把"嘉立创/华秋/JLCPCB/Mouser/DigiKey"等具体厂商从**代码默认值**剥离为**可配置数据**（Vendor / Fabricator Profile）。厂商能力、工艺极限、命名约定、对接 API 全部走档案；发行版仅内置"参考档案集"作为示例，用户/企业可覆盖、社区可贡献。**国际化前提**：内置档案不预设"国内厂商为一等公民"，国内/国际厂商对称列入参考集。

## 一、两类档案

| 档案类型 | 服务域 | 内容要点 |
|---|---|---|
| **供应商档案（Vendor Profile）** | [21-供应链集成/07-供应商对接](../21-供应链集成/07-供应商对接/) | 元器件商城：API endpoint、鉴权方式、库存/价格/交期/合规查询能力、字段映射 |
| **工厂档案（Fabricator Profile）** | [13-制造输出](../13-制造输出/)、[08-PCB编辑器/03-设计规则与约束管理器](../08-PCB编辑器/03-设计规则与约束管理器/) | PCB 制造与贴片厂：工艺能力矩阵、命名约定、首选交付格式（IPC-2581/ODB++/Gerber） |

## 二、供应商档案 schema（yaml 示例）

```yaml
# lang/vendors/lcsc.yaml
id: lcsc
display_name: 立创商城（LCSC）
region: CN
type: distributor            # distributor | marketplace | broker
base_url: https://www.szlcsc.com
auth:
  scheme: api_key            # api_key | oauth2 | none
  storage: user              # user | enterprise（见 22-04 安全）
capabilities:                # 适配器声明支持的能力
  - search
  - stock
  - price
  - lead_time
  - lifecycle               # EOL / NRND
  - compliance              # RoHS / REACH
  - order
  - order_status
field_map:                   # 各家字段 → 统一 schema
  mpn: manufacturer_part_no
  stock: quantity
  price_unit: unit_price
rate_limit:
  strategy: token_bucket
  rps: 5
compliance_defaults:
  rohs: true
  conflict_minerals: declared
```

## 三、工厂档案 schema（yaml 示例）

```yaml
# lang/fabricators/jlcpcb.yaml
id: jlcpcb
display_name: JLCPCB
region: GLOBAL
capabilities:
  min_trace_width_mm: 0.127      # 5mil
  min_clearance_mm: 0.127         # 5mil
  min_annular_ring_mm: 0.1
  min_drill_mm: 0.2
  max_board_thickness_mm: 2.4
  hdi_levels: [1, 2, 3]
  min_solder_mask_sliver_mm: 0.075
  blind_buried_via: true
preferred_delivery_format: odb_pp   # ipc_2581 | odb_pp | gerber
gerber_naming:
  template: "{project}-{layer_code}.gbr"
  layer_codes:
    top_copper: GTL
    bottom_copper: GBL
    top_solder: GTS
panelization:
  min_panel_mm: [100, 100]
  v_cut: true
  mouse_bites: true
```

## 四、参考内置档案集（示例数据，非硬编码默认）

发行版内置以下"参考档案"作为开箱示例，位于 `lang/vendors/` 与 `lang/fabricators/`，**可被用户/工程级同名档案覆盖**：

- **供应商（国内）**：立创商城（LCSC）、华秋商城
- **供应商（国际）**：Mouser、DigiKey、Octopart（聚合）
- **工厂（国内）**：嘉立创（JLCPCB）、华秋
- **工厂（国际）**：Multek、其他按需

> 国内与国际对称列入；"参考"二字强调它们是示例配置而非产品绑定。社区经 [[18-扩展生态/01-插件系统]] 贡献新档案。

## 五、配置层级（覆盖优先级，低 → 高）

1. 发行版内置参考档案（`lang/...`）
2. 用户级档案（`~/.eda/vendors/`）
3. 工程级档案（`<project>/vendors/`）
4. 会话临时覆盖

工程可"锁定"到特定档案（防团队混用），与 [[04-GUI与编辑器框架/08-i18n与无障碍/03-本地化]] 的单位锁定同理。

## 六、与各域的关系

| 域 | 用法 |

| [08-03 设计规则约束](../08-PCB编辑器/03-设计规则与约束管理器/) | 规则预设从工厂档案的 `capabilities` 加载（如 `min_clearance`），不再硬编码"嘉立创 6/6mil" |

| [13-12 制造前检查](../13-制造输出/12-制造前检查/) | DFM/DFA/DFT 阈值按工厂档案 `capabilities` 比对 |

## 七、维护规则

1. **不硬编码**：代码/文档不得把具体厂商名作为"内置默认"，只可作"参考档案"列举。
2. **区域中立**：参考档案集国内/国际对称；区域断言（如"某地区工厂多用 X 格式"）写成档案字段（`preferred_delivery_format`），不写成普适设计断言。
3. **品牌名**：遵循 [[00-总览/04-术语表]] D4（嘉立创=公司、立创EDA=产品、立创商城=供应商、JLCPCB=制造品牌、华秋=公司/供应商）。
4. **可扩展**：新增厂商 = 新增一份 yaml + 适配器（供应商）或 仅 yaml（工厂能力），不需改核心代码。
