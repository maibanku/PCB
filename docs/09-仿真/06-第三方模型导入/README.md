# 09-06 第三方模型导入

> 所属 [[09-仿真]]。导入厂商 SPICE 模型（`.lib`/`.mod`/`.sub`/加密模型），自动解析引脚并映射到原理图符号，给出保真度报告。

## 目标（要实现什么）
- 解析 `.model` 与 `.subckt` 文本：抽取模型名、类型、引脚列表、参数集、`.ends` 边界。
- 支持厂商整库 `.lib` 批量导入（如 TI `transistors.lib`、ADI 运放库），按模型分条入库。
- **引脚映射器**：自动按 subckt 节点顺序猜测，UI 提供手工调整（节点 ↔ 原理图 Pin），保存为映射模板。
- 支持加密 ngspice 模型（厂商 `code=*` 加密）的加载与标注。
- 重复名检测（同一 `.model` 名多版本），给冲突报告 + 重命名/命名空间隔离方案。
- 保真度报告：导入前后参数对比、未知语法警告、未映射引脚清单。
- 导入向导：选库 → 解析预览 → 引脚映射 → 入库（进入 09-02）。

## 关键点
- **语法鲁棒性**：厂商 SPICE 方言（PSpice vs ngspice vs LTspice）差异大（如 `.param` 表达式、`^` 异或/幂），解析器宽容 + 不识别段降级为文本保留。
- **安全**：第三方 `.lib` 不应直接执行任意命令，过滤危险语句（如 `system` 调用），沙箱化导入。
- **可逆**：导入操作入命令栈，可撤销；保留原始文件副本以便重解析。

## 输入 / 输出
- **入**：用户提供的 `.lib`/`.mod`/`.cir` 文本、目标器件符号（来自 P6）。
- **出**：入库后的模型条目（写入 09-02）、引脚映射模板、保真度报告。

## 依赖
- **上游**：P6（目标器件符号/Pin 表）。（SPICE 文本解析在本子功能内自包含，不依赖 F3 总框架；P9 仅依赖 P7。）
- **下游**：09-02（仿真模型库入库）、09-01（实际仿真时引用）。
