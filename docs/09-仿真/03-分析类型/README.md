# 09-03 分析类型

> 所属 [[09-仿真]]。封装 ngspice 各类分析命令为可视化配置项，覆盖 DC/AC/瞬态/噪声/蒙特卡洛/最坏情况/参数扫描/失真/极零点等。

## 目标（要实现什么）
- **DC 工作点**（`.op`）：直流偏置、静态工作点电压/电流报告。
- **DC 扫描**（`.dc`）：扫描源/参数/温度，支持线性/对数 + 嵌套二级扫描。
- **AC 扫频**（`.ac`）：`DEC`/`OCT`/`LIN` 三种模式，输出幅频/相频。
- **瞬态**（`.tran`）：`tstep`/`tstop`/`tmax` 配置，支持 `uic` 初始条件。
- **噪声**（`.noise`）：指定输出节点与参考输入源，输出噪声谱密度。
- **蒙特卡洛**（`.mc`）与 **最坏情况**（`.worst`）：分布类型（均匀/高斯）、运行次数、`yield`/`yd` 统计。
- **参数扫描**（`.step`）：与上述分析正交组合，扫描器件参数/温度/模型参数。
- **极零点**（`.pz`）与 **失真**（`.disto`）：小信号稳定性辅助分析。

## 关键点
- **参数化 UI**：每类分析对应一个配置表单，背后翻译为 ngspice 命令字符串，避免用户手写 `.control` 出错。
- **批处理**：`.step` × `.mc` 组合可能产生上百条曲线，向量存储要按"扫描维度"多维索引（参考 Godot `ArrayMesh` 多维 attribute 思路）。
- **测量语句**：自动注入 `.measure`（如 `trise`、`vpp`、`bw_3db`），结果落入报告而非人工读波形。

## 输入 / 输出
- **入**：用户分析配置（UI 表单）、原理图激励源/探针标记（09-05）。
- **出**：ngspice 命令字符串（注入 09-01）、按分析类型组织的向量数据（供 09-04）。

## 依赖
- **上游**：09-05（激励源、探针定义）、09-02（模型参数）。
- **下游**：09-01（命令执行）、09-04（结果可视化）、E1（AI 异常解读）。
