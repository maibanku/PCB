# 09-05 原理图联动

> 所属 [[09-仿真]]。在原理图上放置激励源与探针，自动生成网表映射、绑定波形通道，实现"画图即仿真"零摩擦交互。

## 目标（要实现什么）
- 激励源库：`V`/`I` 源，含 `PULSE`/`SIN`/`EXP`/`PWL`/`SFFM`/`AM`/`AC`/`DC` 类型，参数化表单录入。
- 探针类型：电压探针（节点）、电流探针（支路）、差分探针（节点对）、功率探针。
- 节点 → 网表自动映射：原理图网络标号直通 ngspice 节点名，保留层级化展开后的全路径。
- 原理图高亮仿真节点（电流路径配色 / 电压梯度染色，类似 live simulation 着色）。
- 探针 → 波形通道自动绑定（在 04-波形查看器中按探针名分组）。
- 交叉探测：在波形上选点 → 原理图节点闪烁；在原理图选网络 → 波形高亮。

## 关键点
- **节点名一致性**：层次化设计中节点名易冲突（多页 `VCC`），需走全限定名（`/top/sub1/VCC`），与 P7 网表统一。
- **电流探针位置敏感**：ngspice 电流测量需指定器件引脚（如 `@Q1[c]`），UI 必须把"探针放在哪根导线上"翻译为正确语句。
- **激励源可视化**：PWL 等复杂源在原理图侧给缩略波形预览，降低配置错误。

## 输入 / 输出
- **入**：P7 原理图（器件/网络/层次块）、用户放置的激励源/探针。
- **出**：注入网表的激励源语句 + 探针 `save`/`print` 列表（供 09-01）、节点-探针映射表（供 04）。

## 依赖
- **上游**：P7（原理图编辑器/网表生成）、09-02（器件模型）。
- **下游**：09-01（网表整合）、09-04（波形通道绑定）、E1（AI 智能放置探针建议）。
