# 09-02 仿真模型库

> 所属 [[09-仿真]]。管理 SPICE `.model` / `.subckt` 模型，与 P6 元件库一体化绑定，支持多级库（本地/云/企业）、版本锁定与模型切换。

## 目标（要实现什么）
- 模型条目存储：模型名、类型（`NPN`/`NMOS`/`运放`/`数字门`/`子电路`）、`.model` 或 `.subckt` 文本、引脚顺序、默认参数集。
- 与 P6 元器件库**一体化绑定**：一个器件 = 符号 + 封装 + 3D + 参数 + **SPICE 模型**（蓝图 C1 设计基线）。
- 模型版本化 + 工程依赖锁定（工程绑定特定模型版本，保证仿真可复现）。
- 本地库 / 在线云端 / 企业私有库三级同步，支持权限与同步策略（借鉴 P6 库层级）。
- 参数化检索：按器件料号、按模型关键字（如 `2N3904`、`LM358`）模糊匹配。
- 一个器件支持多候选模型，提供"模型选择器"在原理图上切换（厂商 A/B 等效替代）。

## 关键点
- **引脚映射**：SPICE `.subckt` 节点顺序与原理图符号 Pin 不一致是历史老大难，库必须显式记录映射表（如符号 `1,2,3` → subckt `b,c,e`）。
- **加密模型**：厂商提供的加密 ngspice 模型（`protected`）需特殊加载，标注"加密/受限"。
- **冲突处理**：同名 `.model`（如多个 `2N2222`）走命名空间或 ID 区分，导入时给冲突报告。

## 输入 / 输出
- **入**：P6 器件库条目、外部 `.lib`/`.mod` 文本（09-06 导入）、用户模型编辑。
- **出**：ngspice 可 `.include` 的模型文本（供 09-01 网表引用）、模型元数据（供 UI 选择器）。

## 依赖
- **上游**：P6（元件库主表/版本机制）、09-06（第三方模型导入）。
- **下游**：09-01（网表 `.lib` 引用）、09-05（探针节点映射回符号）。
