# 09-04 波形查看器

> 所属 [[09-仿真]]。多迹波形显示与测量工具，支持游标、数学运算、FFT 与多窗口对比，对标 ngspice/GTKWave 体验。

## 目标（要实现什么）
- 多迹叠加与分离视图（split view），支持上千条曲线（蒙特卡洛批结果）流畅缩放（GPU 加速，借鉴 Godot `CanvasItem` 批渲染）。
- 游标（a/b cursor）+ 自动测量：峰峰值、周期、频率、上升/下降时间、相位差、RMS、均值。
- 数学通道：`+`、`-`、`*`、`/`、`deriv`、`integ`、`abs`、`log`、`fft`（参考 ngspice `math` 命令）。
- 坐标轴：线性/对数 X、线性/对数 Y；Bode 图（幅频 + 相频双轴）。
- FFT 频谱分析：窗函数（Hanning/Hamming/Blackman）、频谱峰值标注。
- 数据导出 CSV/PNG/SVG，多窗口对比（不同 run 之间叠绘）。
- 交叉探测：点击曲线点 → 高亮原理图节点（与 09-05 联动）。

## 关键点
- **大数据性能**：万点级曲线下，GPU LineStrip + LOD（缩放时降采样），避免每帧重算。
- **配色一致性**：曲线配色走主题色板（参考 dataviz 调色），色盲友好。
- **测量精度**：游标插值用线性/三次样条，避免读数偏差。

## 输入 / 输出
- **入**：09-01 回读的向量数据（含扫描维度）、用户测量/数学配置。
- **出**：可视化波形、测量报告（数值表）、导出文件（CSV/PNG/PDF）。

## 依赖
- **上游**：09-01（仿真向量）、09-03（分析维度元数据）。
- **下游**：用户（工程师查看验证）、E1（AI 异常波形标注与解读）。
