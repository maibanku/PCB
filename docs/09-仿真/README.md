# 09-仿真

> 对应 **Plan P9**（Phase 3 · 专业补强）。集成 ngspice 引擎，提供从原理图到波形的端到端电路仿真与验证能力，降低改板风险。

## 定位
- **做什么**：对接 ngspice 仿真引擎；管理 SPICE 模型库；提供 DC/AC/瞬态/噪声/蒙特卡洛/参数扫描等分析类型；多迹波形查看与测量；原理图激励源/探针联动；导入第三方 SPICE 模型。
- **不做什么**：不做 SI/PI 高速分析（属 P12）；不做电源完整性/眼图等专用分析；不做模拟/数模混合 IC 设计级仿真。
- **代码位置**：`eda/simulation`（见 [[00-总览/03-项目目录结构]]）
