# 04-04 可停靠Dock与面板

> 所属 [[04-GUI与编辑器框架]]。实现类 Godot/Visual Studio 的可拖拽停靠面板系统：Dock 可停靠到主窗口四边、可浮动、可分标签页、可隐藏，布局可保存切换。

## 目标（要实现什么）
- `DockManager`：管理主窗口的 Dock 区域（左/右/下/上/中心），拖拽预览高亮（半透明蓝框）
- `DockContainer`：可容纳多个 Dock 的容器，支持标签页切换、关闭、重排
- **停靠交互**：拖拽 Dock 标题栏 → 出现停靠区高亮 → 释放后吸附；支持拆出为独立浮动窗口
- **浮动窗口**：Dock 可拖出主窗口成独立顶层窗口，拖回重新吸附
- **中心区**：编辑器主画布（原理图/PCB 视口）独占中心，不被 Dock 挤压
- **预设布局**：原理图模式 / PCB 模式 / 库编辑器模式各自保存一套 Dock 布局，切换编辑器自动切换
- **多显示器**：浮动窗口可拖到副屏（依赖 `platform/DisplayServer` 多屏信息）
- **持久化**：布局序列化为 `.layout.toml`，启动时恢复（窗口尺寸 + Dock 状态 + 分隔条位置）
- **隐藏/显示**：菜单或快捷键切换 Dock 显隐（如 F2 切换左侧工程树）

## 关键点
- **借鉴 Godot 编辑器**：Godot 编辑器本身就是可停靠 Dock 系统，其 `editor/editor_node.h` 是直接参考
- **布局序列化**：Dock 状态、浮动窗口位置、分隔比例全部进 TOML，可分享给团队
- **拖拽稳定性**：跨平台拖拽事件（Win/Mac/Linux 鼠标捕获差异），保证吸附判定准确
- **响应式**：窗口缩放时 Dock 自动收缩，最小尺寸保护（不挤压到 0）

## 输入 / 输出
- **入**：用户拖拽事件、布局预设文件
- **出**：可定制的工作区，承载 [[05-属性Inspector]]、工程树、搜索结果、命令输出等

## 依赖
- **上游**：[[01-Control控件体系]]、[[02-布局与容器]]（SplitContainer/TabContainer）、`platform/DisplayServer`（多屏、拖拽）
- **下游**：所有编辑器面板（工程树、Inspector、库、DRC 结果、命令面板）
