# 04-08-03 本地化

> 所属 [[04-GUI与编辑器框架/08-i18n与无障碍]]。区域相关的数据格式化：数字、日期、货币、**单位（mm/mil/英寸，EDA 特有）**、locale 管理。翻译（文本）归 [[01-翻译系统]]，本子功能处理**非文本的区域格式**。

## 目标（要实现什么）
- **数字格式**：小数分隔符（`.` / `,`）、千分位、负数、科学计数按 locale；输入解析容忍 locale 写法。
- **日期/时间**：默认 ISO `YYYY-MM-DD`（工程友好、无歧义），可按 locale 切换显示；时间戳带时区。
- **货币**：供应链下单（[[21-供应链集成]]）金额格式与符号（¥ / $ / €），按目标市场。
- **★ 单位本地化（EDA 特有）**：mm / mil / 英寸切换**不仅影响显示，更影响输入解析**——
  - 输入框接受 `"1.5mm"`、`"60mil"`、`"0.0625in"` 自动识别并归一化；
  - 与单位系统联动（PCB 用 mm/mil，原理图用相对单位）；
  - 工程可锁定单位制（防止团队混用）。
- **locale 管理**：用户偏好 > 工程设置 > 系统检测，三层回退；locale 与语言可独立设置（如英文 UI + 公制单位）。
- **本地化库选型**：推荐 **ICU**（数字/日期/货币/复数/消息格式一体）；备选 boost.locale。运行时按 locale 格式化。

## 关键点
- **单位是 EDA 的 l10n 核心**：机械/PCB 领域 mm 与 mil 并存，输入解析错误会导致制造事故；单位与翻译独立（英文用户也可能用 mm）。
- **ISO 日期优先**：工程数据（文件名、日志、报告）用 ISO 日期，避免 `01/02/2026` 的美/欧歧义；UI 显示可按 locale。
- **ICU 统一**：数字、日期、货币、复数都用 ICU，避免多库拼接；与 [[01-翻译系统]] 的 MessageFormat 共享。
- **输入容忍**：单位输入框同时接受 `1.5mm` / `1,5mm`（欧） / `60mil`，归一化到内部 nm 存储（[[03-几何与命令栈/01-图元与坐标]]）。

## 输入 / 输出
- **入**：locale（用户/工程/系统）、单位偏好、原始数值
- **出**：区域格式化的数字/日期/货币/单位字符串、归一化的输入值
