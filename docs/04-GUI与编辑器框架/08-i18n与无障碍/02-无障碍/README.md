# 04-08-02 无障碍

> 所属 [[04-GUI与编辑器框架/08-i18n与无障碍]]。让编辑器对**键盘、屏幕阅读器、高对比度、缩放、减少动画**完全友好，对齐 WCAG 2.1 AA。企业/教育市场的硬门槛（F5 非功能要求），验收对照 [[22-工程化与非功能/03-无障碍WCAG]]。

## 目标（要实现什么）
- **WCAG 2.1 AA 对齐**：文本对比度 ≥ 4.5:1（正常文本）/ ≥ 3:1（大文本与 UI 组件边界）；非文本对比度 ≥ 3:1。
- **键盘全操作**：所有菜单/工具/Dock/Inspector/对话框可纯键盘到达——`Tab`/`Shift+Tab` 焦点遍历、快捷键直达、模态焦点陷阱（Tab 不跳出对话框）、`Esc` 关闭。
- **焦点可视指示**：当前焦点控件有明显高亮边框（2px 对比色），不依赖鼠标 hover。
- **跳过链接**：长导航支持跳过到主画布/主内容。
- **高对比度主题**：与 [[03-主题系统]] 协作提供高对比度变体；本域约束对比度阈值与边框可见性。
- **界面缩放 `ui_scale`**：0.8x ~ 2.0x 无极缩放，适配 4K/Retina 高 DPI；字号/图标/间距等比缩放，与系统 DPI 检测联动。
- **屏幕阅读器（AT API）**：UI 节点暴露 `accessibility_label` / `accessibility_role` / `accessibility_value` / `accessibility_state`，经平台 AT API 暴露：
  - Windows：UIAutomation（兼容 NVDA / JAWS / Narrator）
  - macOS：NSAccessibility（VoiceOver）
  - Linux：AT-SPI2（Orca）
- **减少动画**：尊重系统"减少动态效果"设置，关闭非必要过渡（保留状态指示）；与 [[03-主题系统]] 动画开关协作。
- **RTL 布局翻转**：锚点/容器在 RTL locale 下水平镜像（与翻译系统协作；详见 [[01-翻译系统]]）。

## 关键点
- **a11y 非可选**：WCAG 对齐是 ToG/企业/教育采购的硬门槛，不是"锦上添花"。
- **AT API 自研**：借鉴 Godot 的 `DisplayServer` accessibility 钩子，每平台一个后端；Control 节点统一暴露无障碍树。
- **画布无障碍特殊**：原理图/PCB 画布不是标准控件，需自定义无障碍语义（如"器件 U3，位于坐标...，已选中"），供屏幕阅读器朗读。
- **键盘与快捷键解耦**：键盘可达性归本域，具体键位映射归 [[07-快捷键体系]]。
- **缩放不破坏布局**：`ui_scale` 走渲染层统一缩放，不靠各控件自己调字号（避免错位）。

## 输入 / 输出
- **入**：用户偏好（缩放/对比度/减少动画）、系统 DPI 与辅助技术检测、控件无障碍属性
- **出**：暴露给 AT 的无障碍树、焦点高亮、缩放后的渲染
