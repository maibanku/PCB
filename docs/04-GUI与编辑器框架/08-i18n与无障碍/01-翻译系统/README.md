# 04-08-01 翻译系统

> 所属 [[04-GUI与编辑器框架/08-i18n与无障碍]]。`tr()` 查表翻译的运行时与工具链：源字符串抽取、资源文件、复数、上下文消歧、完整性度量、语言包管理。**术语 SSOT 为 [[00-总览/04-术语表]]**——本子功能只负责翻译机制，不负责译法裁定。

## 目标（要实现什么）
- **`tr()` API**：`tr("english source")` 查表返回当前 locale 译法；缺失时退回英文（**绝不显示 key**）。
  - source 取自术语表"英文 source"列（全小写），如 `tr("footprint")`、`tr("schematic")`。
  - 禁止硬编码中文字面量入 UI（CI 扫描阻断）。
- **资源格式**：主选 **`.po`（gettext）**——复数/上下文原生支持、Crowdin/Weblate 原生兼容、`xgettext` 工具链成熟；编译期转 `.mo` 或 `.json` 供运行时加载。
  - 目录约定：`lang/<locale>/LC_MESSAGES/eda.po`（如 `lang/zh-CN/LC_MESSAGES/eda.po`）。
- **复数形式**：`tr_n(singular, plural, count)` 等价 `ngettext`，按 **CLDR 复数规则**分发（中文无复数、英文 1/other、俄/阿/波多类）。
- **上下文消歧（msgctxt）**：`tr_ctxt(context, source)`，同一英文在不同 UI 语境译法不同时消歧。
  - 例：`"pad"` 在库编辑器=焊盘、在报告列名=Pad、在对话语句中可能不同。
- **翻译者注释**：`// @i18n-context: 出现在 DRC 报告中，指物理焊盘` 注释，抽取进 `.po` 的 `#. developer comments`，供译者理解语境。
- **抽取工具（CI）**：扫描所有 `tr()` / `tr_n()` / `tr_ctxt()` 调用，生成/更新 `.pot` 模板；与各 locale `.po` 比对，未翻译键列入覆盖率报告。
- **完整性度量**：每语言翻译覆盖率（已译 / 总键）；缺失键运行时计入遥测（可关）；发布前强制 ≥ 阈值（如 95%）。
- **语言包管理**：版本化（每发布分支一份）；社区贡献走 Weblate/Crowdin PR 审核；安装包内置中英，其余按需下载。
- **运行时切换**：切换语言后重渲染全部 UI 文本，**无需重启**（信号通知所有控件刷新）。
- **固有名词策略**：术语表 [[00-总览/04-术语表]] §三 清单（IPC-2581、Gerber、courtyard、BOM、DRC、Via、Pad 等）**不进 `tr()` 池**，代码直接字面量。

## 关键点
- **source 即 SSOT 锚点**：业务代码用英文 source 作 key，与术语表"英文 source"列、文档中文术语三者通过术语表映射，避免三方漂移。
- **`.po` 优于纯 `.json`**：gettext 生态的复数（`msg_plural`）、上下文（`msgctxt`）、翻译者注释、模糊标记（`#, fuzzy`）是生产 i18n 必需，纯 `.json` 需自己重新发明。
- **抽取必须在 CI**：不靠人工维护 `.po` 键清单；CI 抽取 + 覆盖率门禁防止"看似翻译实则漏键"。
- **术语一致性 CI**：校验 `.po` 译法与术语表 §四"中文术语"列一致（如 `footprint` 必须译"封装"，不得译"焊盘图形"）。
- **本地化库选型**：推荐 **ICU**（`MessageFormat` 统一复数/性别/选择 + 数字日期货币格式）；`.po` 作容器，运行时用 ICU 渲染。

## 输入 / 输出
- **入**：源码 `tr()` 调用、术语表 [[00-总览/04-术语表]]、各 locale `.po` 资源、用户语言偏好
- **出**：当前 locale 的 UI 文本、翻译覆盖率报告、CI 抽取的 `.pot` 模板
