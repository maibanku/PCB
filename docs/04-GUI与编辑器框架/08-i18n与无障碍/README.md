# 04-08 i18n与无障碍

> 所属 [[04-GUI与编辑器框架]]。实现国际化（中英为主，可扩展多语言）+ 无障碍能力（键盘全操作、高对比度、界面缩放、屏幕阅读器支持），对齐 WCAG 2.1 AA。

## 目标（要实现什么）
- **翻译系统**：`tr("English source")` 查表翻译，翻译资源 `.po` / `.json` 格式，运行时切换语言无需重启
- **中英双语**（首发），架构支持任意语言扩展（日/韩/德/西等预留）
- **数字/日期/单位本地化**：mm/mil 切换（与单位系统联动），日期格式按地区
- **界面缩放**：`ui_scale` 0.8x ~ 2.0x，适配 4K/Retina 高 DPI 屏，字号/图标/间距等比缩放
- **高对比度主题**：与 [[03-主题系统]] 协作，文本/背景对比度 ≥ 4.5:1（WCAG AA）
- **键盘全操作**：所有菜单/工具/Dock/Inspector 可键盘到达（Tab 遍历 + 快捷键），不用鼠标也能完成设计任务
- **焦点可视指示**：当前焦点控件有明显高亮边框
- **屏幕阅读器**：UI 节点支持 `accessibility_label` / `accessibility_role`，通过平台 AT API（UIAutomation / NVDA / VoiceOver）暴露
- **减少动画**：尊重系统"减少动态效果"设置，关闭非必要过渡动画

## 关键点
- **翻译源即文档**：业务代码用英文源字符串作为 key，翻译缺失时退回英文（不会显示 key）
- **字符串不留空**：所有 UI 文本走 `tr()`，禁止硬编码中文字面量
- **EDA 单位特殊**：mil/mm/英寸切换不仅是显示，更要影响输入解析（如 `"1.5mm"` 自动识别）
- **可访问性非可选**：WCAG 对齐是企业/教育市场的硬门槛（F5 非功能要求）

## 输入 / 输出
- **入**：翻译资源文件、用户语言/缩放/对比度偏好
- **出**：本地化的 UI 文本、AT API 暴露的无障碍树
