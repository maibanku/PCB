# 04-08 i18n与无障碍

> 所属 [[04-GUI与编辑器框架]]。国际化（i18n）+ 无障碍（a11y）+ 本地化（l10n）三子域的容器。让编辑器**可翻译、可访问、可适配区域**，对齐 WCAG 2.1 AA，支持中英首发、架构预留任意语言扩展。术语与翻译 key 的权威映射见 [[00-总览/04-术语表]]。

## 定位
- **做什么**：翻译系统（`tr()` + `.po` 资源 + 复数 + 上下文消歧 + 抽取工具）、无障碍（键盘/对比度/缩放/屏幕阅读器 AT API/RTL）、本地化（数字/日期/单位/货币区域格式）。
- **不做什么**：不做主题系统的视觉设计（归 [[03-主题系统]]，本域仅提供高对比度与对比度阈值约束）；不做快捷键映射逻辑（归 [[07-快捷键体系]]，本域仅要求键盘可达）；不裁定业务术语译法（归 [[00-总览/04-术语表]] SSOT）。
- **代码位置**：`scene/gui/i18n/`、`scene/gui/a11y/`、`scene/gui/l10n/`（见 [[00-总览/03-项目目录结构]]）

## 子功能清单
| 编号 | 子功能 | 说明 |
|------|--------|------|
| 01 | [翻译系统](01-翻译系统/) | `tr()` 查表、`.po` 资源、复数（CLDR）、msgctxt 上下文、抽取工具、语言包管理、ICU MessageFormat |
| 02 | [无障碍](02-无障碍/) | WCAG 2.1 AA、键盘全操作、焦点可视、高对比度、ui_scale 缩放、屏幕阅读器 AT API、RTL |
| 03 | [本地化](03-本地化/) | 数字/日期/货币/单位区域格式、mm-mil 联动、locale 三层回退、ICU 选型 |
