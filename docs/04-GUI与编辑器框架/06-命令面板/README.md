# 04-06 命令面板

> 所属 [[04-GUI与编辑器框架]]。实现类 VS Code / Godot 4 的命令面板：`Ctrl+Shift+P` 唤起，模糊搜索所有可执行命令（菜单项、工具动作、跳转器件、打开工程、切换设置），降低菜单挖掘成本。

## 目标（要实现什么）
- **全局唤起**：默认 `Ctrl+Shift+P`（可配置），输入框 + 实时结果列表
- **命令注册中心**：所有菜单/工具栏动作统一注册为 `Command`（id、显示名、快捷键、图标、分类、callback）
- **模糊匹配**：子序列匹配 + 拼音首字母（中文）+ 最近使用加权，键入 `bsr` 能找到"板框设计"
- **多模式前缀**：
  - `>` 命令（默认）
  - `@` 跳转器件/网络/位号（输入 `@R12` 直接定位 PCB 上的 R12）
  - `:` 跳转图页（`:2` 跳到第 2 页原理图）
  - `#` 设置项（`#theme dark` 直接切换暗色主题）
- **最近使用 / 频率排序**：常用命令优先显示
- **快捷键提示**：每条命令右侧显示当前快捷键（与 [[07-快捷键体系]] 联动）
- **鼠标可选**：上下键导航、回车执行、Esc 关闭
- **命令分组**：按编辑器模式过滤（原理图模式下不显示 PCB 专属命令）

## 关键点
- **统一命令模型**：菜单、工具栏、命令面板共用同一 `Command` 注册表，单一真相源
- **可扩展**：插件（F2）注册的命令自动进入面板
- **可访问性**：键盘全操作（无障碍前置），不用鼠标也能完成所有操作
- **性能**：万级命令下模糊匹配 ≤ 16ms（增量索引 + 缓存）

## 输入 / 输出
- **入**：命令注册表、用户输入
- **出**：命令执行回调（可能触发 UndoRedo / 视图跳转 / 设置变更）
