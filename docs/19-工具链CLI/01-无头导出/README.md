# 19-01 无头导出

> 所属 [[19-工具链CLI]]。提供无 GPU 依赖的命令行批量导出能力，一次性产出 Gerber/BOM/PDF/IPC-2581 及 ERC/DRC 报告，面向 CI/CD 流水线与企业自动化。

## 目标（要实现什么）
- 提供单一可执行 CLI，无头模式打开工程并批量导出：Gerber（RS-274X）+ Excellon + 坐标文件 + 钢网 + IPC-2581/ODB++
- 命令行触发 ERC（原理图）+ DRC（PCB）+ 一致性检查，产出结构化报告（JSON/HTML/JUnit XML）
- 支持 BOM 多格式导出（CSV/Excel/含供应链属性），可按输出模板批量产出装配图/制造图/钻孔图 PDF
- 支�� DXF 与 3D STEP 导出，拼板面板化（V-cut/工艺边/邮票孔）一键产出
- 提供退出码语义化（成功/规则失败/格式错误/缺库），CI 可直接据此 gate
- 提供确定性保证：相同工程+相同规则+相同库版本 → 字节级一致的输出（便于 diff 与回归）

## 关键点
- 无头渲染不能依赖 GPU：2D 矢量导出走 CPU 软件渲染路径；3D 走软件光栅化或可选 GPU
- 必须复用 [[18-扩展生态/02-脚本支持]] 的脚本运行时，允许 `--pre-script`/`--post-script` 钩子
- 库版本锁定是确定性前提，缺库/版本不匹配须显式失败而非静默使用缓存
- 输出路径/命名规则可配置，支持多板工程按板子分目录输出

## 输入 / 输出
- **入**：工程路径、规则集、库版本锁、输出模板、CLI 参数
- **出**：制造数据包（Gerber/钻孔/坐标/钢网/IPC-2581/BOM/PDF）、ERC/DRC 报告、退出码、构建日志
