# 19-02 版本控制钩子

> 所属 [[19-工具链CLI]]。提供 Git/其他 VCS 的 pre-commit / pre-push / server-side 钩子，在提交前自动运行 DRC/ERC 与一致性检查，阻断不合格工程进入仓库。

## 目标（要实现什么）
- 提供 `pre-commit` 与 `pre-push` 钩子脚本（Git 优先，兼容 husky/lefthook 等工具链）
- 提交前自动触发 ERC + DRC + 原理图↔PCB 一致性检查，违反阈值规则时非零退出码阻断提交
- 支持增量检查：仅校验本次 diff 涉及的图元/网络，避免全板 DRC 拖慢提交
- 提供服务端钩子（pre-receive）与 CI 流水线模板，使 PR 自动跑全量检查并产出报告评论
- 支持配置策略：警告级（提示但不阻断）、错误级（阻断）、白名单（如初期允许临时绕过并附 TODO）
- 与 [[17-协作与版本]] 的文本格式策略协同，保证 diff 可读且冲突可解

## 关键点
- 增量 DRC 是性能关键：依赖工程级 dirty tracking 与规则影响域分析
- 钩子需可绕过（`--no-verify`）但绕过须留审计痕迹（commit 元数据或 PR 标记），避免无声逃逸
- 服务端策略须可配置：开源仓库可宽松，企业仓库可严格
- 钩子安装向导：`eda cli hooks install`，自动检测 VCS 类型并安装对应钩子

## 输入 / 输出
- **入**：Git diff、工程文件、规则阈值配置、钩子策略
- **出**：阻断/放行决策、违规清单、PR 评论、审计日志
