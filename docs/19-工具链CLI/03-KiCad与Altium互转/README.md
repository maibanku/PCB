# 19-03 KiCad与Altium互转

> 所属 [[19-工具链CLI]]。提供命令行工程级互转工具，将 KiCad/Altium 工程及库批量转换为本品工程（或反向导出），服务于历史工程迁移与企业跨工具协作。

## 目标（要实现什么）
- 支持命令行批量转换：KiCad（.kicad_pro/.sch/.kicad_pcb）、Altium（.PrjPcb/.SchDoc/.PcbDoc）工程 ↔ 本品工程
- 同步迁移元件库：符号库/封装库/3D 模型，尽量保留参数与供应链属性
- 转换后自动产出迁移保真度报告：哪些元素完美转换、哪些需人工核对、哪些丢失（对应 [[16-格式兼容]] 总策略）
- 支持规则与约束映射：KiCad net class、Altium design rules → 本品约束管理器
- 提供反向导出（本品 → KiCad/Altium），便于与仍在使用旧工具的协作方对接
- 提供 dry-run 与 diff 模式，转换前后可图形化对比，避免"看似成功实则丢数据"

## 关键点
- 复用 [[16-格式兼容]] 的格式适配器，CLI 仅是命令行壳；不重写解析逻辑
- 私有格式（Altium 二进制）须有降级路径：无法解析时保留原始对象并标记，不静默丢弃
- 互转是"有损"过程，必须把保真度报告作为一等输出，而非可选附件
- 批量模式支持目录递归与并行，企业级历史库迁移可一夜跑完

## 输入 / 输出
- **入**：源工程目录/文件、格式适配器、映射规则配置、库依赖
- **出**：本品工程文件、迁移保真度报告（JSON/HTML）、需人工核对待办清单、转换日志

## 依赖
- **上游**：[[16-格式兼容]]（格式适配器）、P5（工程文件系统）、P6（元件库写入）
- **下游**：[[19-工具链CLI/01-无头导出]]（迁移后可直接走无头导出验证）
