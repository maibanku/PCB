# 19-工具链CLI

> 对应 **Plan P19**（Phase 4 · 生态与协作）。提供无头命令行工具，支撑 CI/CD 自动化、版本控制钩子与第三方格式互转。

## 定位
- **做什么**：提供命令行入口，支持无头导出 Gerber/BOM/PDF/ERC/DRC、版本控制提交前自动 DRC、以及 KiCad/Altium 工程的命令行互转，服务于 CI 流水线与自动化场景。
- **不做什么**：不承载交互式编辑体验（GUI 负责）；不替代核心渲染/规则引擎，仅做无头调用。
- **代码位置**：`tools/cli/`（见 [[00-总览/03-项目目录结构]]）

## 子功能清单
| 编号 | 子功能 | 说明 | 状态 |
|------|--------|------|------|
| 01 | [无头导出](01-无头导出/) | 命令行批量导出 Gerber/BOM/PDF，并产出 ERC/DRC 报告 | 待实现 |
| 02 | [版本控制钩子](02-版本控制钩子/) | 提交前自动触发 DRC，阻断不合格提交 | 待实现 |
| 03 | [KiCad与Altium互转](03-KiCad与Altium互转/) | 命令行工程级互转，面向迁移与协作 | 待实现 |

## 依赖
- **上游**：P11（ERC/DRC/DFX 规则引擎）、P13（制造文件导出）、P16（KiCad/Altium 格式适配器）
- **下游**：P22（CI 集成、回归测试、打包分发依赖 CLI）
